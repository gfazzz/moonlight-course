# Mission — s10e03 «Окно связи»

> **Максимальная автономия.** Каркас пуст; структуру выбираешь сам. Формат вывода — в `tests/expected.txt`.

## Брифинг
Спутник виден со станции лишь несколько минут за виток. Пропустил окно — ждёшь полтора часа. Нужно вычислить, **когда** аппарат поднимется над горизонтом, как долго продержится и насколько «уплывёт» частота.

## Что сдать
`artifacts/window.c`: профиль угла места за виток, границы окна связи и доплеровский сдвиг вдоль прохода.

## Дано
- Круговая орбита `r = 7000` км; `MU = 398600.4418`, `RE = 6378.137`, `c = 299792.458` км/с.
- Порог видимости — угол места **10°**; несущая частота **2200 МГц** (диапазон S).
- Модель плоская: станция и орбита в одной плоскости.

## Формулы

```
up    = r·cos(θ) − RE          along = r·sin(θ)
d     = √(up² + along²)        el    = asin(up / d)
vr    = Δd/Δt (численно)       Δf    = −vr/c · f₀
```

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Границы окна ищутся **делением отрезка пополам**, а не по шагу сетки: точность до долей секунды.
- [ ] Длительность окна правдоподобна для низкой орбиты (тест требует 5–15 мин).
- [ ] Максимальный угол места и минимальная дальность достигаются в **середине** прохода.
- [ ] Доплеровский сдвиг **меняет знак** в точке наибольшего сближения (тест проверяет отдельно).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

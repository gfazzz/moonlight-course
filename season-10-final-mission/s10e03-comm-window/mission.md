## Брифинг

Спутник виден со станции лишь несколько минут за виток. Пропустил окно — ждёшь полтора часа.

Нужно вычислить, когда аппарат поднимется над горизонтом, как долго продержится и насколько уплывёт частота.

## Приказ

Написать `artifacts/window.c`: профиль угла места за виток, границы окна связи и доплеровский сдвиг вдоль прохода.

## Дано

- Круговая орбита `r = 7000` км; `MU = 398600.4418`, `RE = 6378.137`, `c = 299792.458` км/с.
- Порог видимости — угол места **10°**; несущая **2200 МГц**.
- Модель плоская: станция и орбита в одной плоскости.

## Формулы

```
up    = r·cos(θ) − RE          along = r·sin(θ)
d     = √(up² + along²)        el    = asin(up / d)
vr    = Δd/Δt (численно)       Δf    = −vr/c · f₀
```

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Границы окна ищутся **делением отрезка пополам**, а не по шагу сетки.
- [ ] Перед делением проверяется, что на концах отрезка разные знаки.
- [ ] Точность границ — доли секунды.
- [ ] Дальность считается как **наклонная**, а не как разность радиусов.
- [ ] Длительность окна правдоподобна для низкой орбиты: тест требует 5–15 минут.
- [ ] Максимальный угол места и минимальная дальность достигаются в **середине** прохода.
- [ ] Доплеровский сдвиг **меняет знак** в точке наибольшего сближения.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Диагностика

| Симптом | Причина |
|---|---|
| границы окна с точностью до минуты | использован перебор по сетке |
| деление пополам сошлось не туда | на концах отрезка одинаковые знаки |
| дальность в зените равна радиусу орбиты | не вычтен радиус Земли |
| дальность у горизонта занижена | считается разность радиусов вместо наклонной |
| сдвиг не обнуляется в середине | взята полная скорость вместо радиальной |
| окно вдвое длиннее ожидаемого | порог видимости нулевой |

## Теория: когда виден и на какой частоте

```
up = r·cos(θ) − RE      along = r·sin(θ)      d = √(up² + along²)
el = asin(up/d)         Δf = −(vr/c)·f₀
```

Границу окна ищут **бисекцией**: интервал со сменой знака делится пополам, точность доходит до машинной без производной и без риска расходимости.

В точке наибольшего сближения радиальная скорость равна нулю — спутник летит поперёк луча, — поэтому сдвиг меняет знак. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про связь.
```

**1.** LUNA: «Почему нельзя считать спутник видимым при угле места 0°?»

<details><summary>Ответ</summary>

У самого горизонта сигнал идёт сквозь максимальную толщу атмосферы, ловит переотражения от рельефа и шум, а наклонная дальность в разы больше зенитной — уровень сигнала падает. Поэтому берут порог 5–10°: формально спутник видно, но связи там нет.
</details>

**2.** LUNA: «Доплеровский сдвиг равен нулю в середине прохода. Спутник что, остановился?»

<details><summary>Ответ</summary>

Нет, он движется быстрее всего, но **поперёк** луча: радиальная составляющая скорости обнуляется, а сдвиг зависит только от неё. До этого момента аппарат приближался (сдвиг положительный), после — удаляется (отрицательный).
</details>

```
[LUNA] Верно. Считай окно.
```

## Разбор типичных ошибок

1. **Искать границу перебором по сетке.** Точность равна шагу; бисекция даёт машинную.
2. **Считать дальность как разность радиусов.** Это верно только в зените; нужна наклонная дальность.
3. **Забыть знак у доплера.** Приближение и удаление дают сдвиги разных знаков.
4. **Порог 0°.** Даст завышенное окно, которого в реальности нет.

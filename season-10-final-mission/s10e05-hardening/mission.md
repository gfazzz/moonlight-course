## Брифинг

Конвейер быстрый, но принимает пакеты **из эфира**. Источник не контролируется: любое поле может оказаться враждебным.

Пришедшие кадры собраны корректно во всём, кроме одного поля — того, которому разборщик доверяет без проверки. Контрольная сумма при этом сходится.

## Приказ

Написать `artifacts/harden.c`: разбор пакета телеметрии, устойчивый к некорректному и злонамеренному вводу.

## Формат пакета

```
[magic:2]['M','L'] [channel:1] [len:1] [payload:len] [crc:1]
crc = XOR всех предшествующих байт
```

Буфер получателя — 64 байта, каналов — 8.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Проверки идут **до** обращения к полям: сначала минимальный размер, потом остальное.
- [ ] Сравнения не переполняются: `size − 5 < len`, а не `len + 5 > size`.
- [ ] Номер канала проверяется как индекс массива.
- [ ] Длина проверяется **дважды**: помещается в пакет и помещается в буфер получателя.
- [ ] Отказ при `len >= ёмкость` — с учётом места под завершающий ноль.
- [ ] Завершающий ноль дописывается **самостоятельно**.
- [ ] Контрольная сумма сверяется; несовпадение отвергает пакет.
- [ ] Любой отказ возвращает код и причину, **не роняя программу**.
- [ ] Сборка с `-fsanitize=address,undefined` не даёт ни одного срабатывания.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Атаки, которые обязаны быть отражены

| длина 200 при пакете в 10 байт | отвергнут |

| обрезанный пакет (3 байта) | отвергнут |
| подделанная сигнатура | отвергнут |
| испорченная контрольная сумма | отвергнут |

## Выполнение

```bash
cp starter.c artifacts/harden.c
make test
```

Поучительная проверка: замените безопасное сравнение на `len + 5 > size` и подайте пакет с длиной 255. Проверка пропустит его, а санитайзер покажет выход за границу буфера — дыра окажется ровно в том месте, куда ставилась защита.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| санитайзер сообщает о выходе за границу | проверка переполняется |
| падение на коротком пакете | обращение к полю до проверки размера |
| запись в чужую память | номер канала не проверен как индекс |
| мусор в конце строки | завершающий ноль не дописан |
| программа завершается на битом пакете | отказ реализован как фатальный |
| корректный пакет отвергнут | отказ при `len > ёмкость` вместо `>=` |

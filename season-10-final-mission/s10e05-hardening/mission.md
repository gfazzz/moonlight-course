# Mission — s10e05 «Защита входных данных»

> **Максимальная автономия.** Каркас пуст. Формат вывода — в `tests/expected.txt`.

## Брифинг
Конвейер быстрый, но принимает пакеты **из эфира**. Источник не контролируется: любое поле может оказаться враждебным. Быстрый разборщик, падающий на первом же битом пакете, бесполезен.

## Что сдать
`artifacts/harden.c`: разбор пакета телеметрии, устойчивый к некорректному и злонамеренному вводу.

## Формат пакета

```
[magic:2]['M','L'] [channel:1] [len:1] [payload:len] [crc:1]
crc = XOR всех байт, предшествующих ему
```

Буфер получателя — 64 байта, каналов — 8.

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Проверки идут **до** обращения к полям: сначала минимальный размер, потом всё остальное.
- [ ] Сравнения не переполняются: `size − 5 < len`, а не `len + 5 > size`.
- [ ] Номер канала проверяется как индекс массива (`channel < NCHANNELS`).
- [ ] Длина проверяется **дважды**: помещается в пакет и помещается в буфер получателя.
- [ ] Завершающий ноль строки дописывается **самостоятельно** — источнику не доверяем.
- [ ] Контрольная сумма сверяется; несовпадение отвергает пакет.
- [ ] Любой отказ возвращает код и причину, **не роняя программу**.
- [ ] Код проходит сборку с `-fsanitize=address,undefined` без единого срабатывания (тест проверяет это отдельно).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Приказ

Написать `artifacts/operation.c`: приёмочная проверка из двенадцати фаз, каждая из которых подтверждает навык конкретного сезона.

## Структура операции

| Фаза | Сезоны | Что подтверждается |
|---|---|---|
| 1. подготовка | S1, S2 | битовые операции; кольцевой буфер |
| 2. канал и шифрование | S3, S4 | самопроверка кадра суммой; хеширование |
| 3. данные и железо | S5, S6 | распознавание подгонки; контрольная сумма Modbus |
| 4. система и модель | S7, S8 | воспроизводимый параллелизм; оценка по редкому классу |
| 5. инженерия и операция | S9, S10 | фильтрация шума; окно, баланс, орбита |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Каждая фаза засчитывается по **критерию**, а не по факту выполнения кода.
- [ ] В приёмке представлены **все десять** сезонов — тест проверяет программно.
- [ ] Проверяются **свойства**, а не заученные константы.
- [ ] Хеш: детерминирован и различает перестановку букв.
- [ ] Контрольная сумма: кадр с дописанной суммой сворачивается в ноль.
- [ ] Параллельный расчёт: побитово совпадает с последовательным.
- [ ] Счётчик пройденных фаз ведётся теми же проверками, что печатают результат.
- [ ] Программа возвращает `0` **только** при прохождении всех фаз.
- [ ] Итог: `12 из 12`, `операция завершена: УСПЕШНО`, `MOONLIGHT closed`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/operation.c
make test
```

Поучительная проверка: замените любое свойство на сравнение с полученной константой и поменяйте входные данные. Проверка упадёт, хотя код по-прежнему верен, — так выглядит ложное срабатывание, из-за которого проверки со временем отключают.

Эталон — в `solution/`. Открывай после честной попытки — последней в этом курсе.

## Диагностика

| Симптом | Причина |
|---|---|
| фаза проходит при неверном результате | критерий сводится к факту выполнения |
| проверка падает после смены данных | сравнение с константой вместо свойства |
| автоматика считает провал успехом | код возврата не зависит от итога |
| приёмка неполна | пропущен сезон |
| вывод не соответствует итогу | успех печатается до проверки |
| счётчик разошёлся с выводом | итог считается отдельно от проверок |

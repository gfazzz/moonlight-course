# Mission — s10e08 «Финальная операция» (ФИНАЛ КУРСА)

> **Максимальная автономия.** Новых тем нет — есть приёмка. Формат вывода — в `tests/expected.txt`.

## Брифинг
Всё построено. Осталось провести операцию и принять результат **по измеримым критериям**, а не по ощущению «вроде работает».

## Что сдать
`artifacts/operation.c`: приёмочная проверка из 12 фаз, каждая из которых подтверждает навык конкретного сезона.

## Структура операции

| Фаза | Сезоны | Что подтверждается |
|---|---|---|
| 1. подготовка | S1, S2 | битовые операции; кольцевой буфер |
| 2. канал и шифрование | S3, S4 | самопроверка кадра суммой; хеширование |
| 3. данные и железо | S5, S6 | распознавание overfitting; CRC-16 Modbus |
| 4. система и модель | S7, S8 | воспроизводимый параллелизм; оценка по F1 |
| 5. инженерия и операция | S9, S10 | фильтрация шума; окно, баланс, орбита |

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Каждая фаза засчитывается по **критерию**, а не по факту выполнения кода.
- [ ] В приёмке представлены **все десять** сезонов (тест проверяет программно).
- [ ] Проверяются **свойства**, а не заученные константы: детерминированность хеша, самопроверка контрольной суммы в ноль, равенство последовательного и параллельного счёта.
- [ ] Программа возвращает `0` **только** при прохождении всех фаз (код возврата — часть контракта).
- [ ] Итог: `12 из 12`, `операция завершена: УСПЕШНО`, `MOONLIGHT closed`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/operation.c
make test
```

~90–110 минут.

## Результат
Курс пройден. Десять сезонов сведены в одну систему и приняты по критериям.

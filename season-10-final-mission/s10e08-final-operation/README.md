## Что ты освоишь

- Приёмку по критериям вместо «код отработал».
- Проверку свойств вместо сравнения с константами.
- Код возврата как часть контракта программы.

Глубже (property-based тестирование, сквозная дисциплина курса) — в [`theory.md`](theory.md).

---

## Теория: критерий, а не надежда

| Слабо | Надёжно |
|---|---|
| `hash == 7572827489583` | `hash(x) == hash(x)` **и** `hash(x) != hash(y)` |
| `crc == 0x8776` | кадр с дописанной суммой сворачивается в **ноль** |
| «программа не упала» | все 12 фаз пройдены, код возврата 0 |

Свойства переживают смену данных и платформы, константы — нет. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса. Последние в этом курсе.
```

**1.** LUNA: «Чем проверка свойства лучше сравнения с эталонным числом?»

<details><summary>Ответ</summary>

Константа фиксирует частный случай и ломается при смене данных, платформы или реализации. Свойство («хеш детерминирован», «кадр с суммой сворачивается в ноль», «параллельный счёт равен последовательному») проверяет то, что обязано выполняться всегда. При написании этой серии две фазы сначала падали именно из-за угаданных констант — замена на свойства исправила проверку.
</details>

**2.** LUNA: «Программа напечатала "есть отказы" и вернула 0. Что не так?»

<details><summary>Ответ</summary>

Сломан контракт. Код возврата — машинный интерфейс программы: CI, скрипты и супервизоры смотрят именно на него, а не на текст. Ненулевой код при непройденной приёмке обязателен, иначе сбой не заметит никто.
</details>

```
[LUNA] Верно. Начинаем.
```

## Задача: `operation.c`

Провести приёмку из 12 фаз, подтвердив навыки всех десяти сезонов измеримыми критериями, и вернуть корректный код завершения. Брифинг — в [`mission.md`](mission.md).

## Разбор типичных ошибок

1. **Критерий «код отработал».** Фаза обязана проверять результат, а не факт выполнения.
2. **Сравнение с угаданной константой.** Ломается при первой же смене данных; проверяй свойство.
3. **Всегда возвращать 0.** CI посчитает провальный запуск успешным.
4. **Пропустить сезон.** Приёмка неполна: система принимается целиком.

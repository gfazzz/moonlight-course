## Брифинг

Окно связи — 8.74 минуты. Не успел конвейер — данные потеряны до следующего витка.

Оптимизировать наугад бесполезно: узкое место почти всегда не там, где кажется.

## Приказ

Написать `artifacts/profile.c`: две версии конвейера — наивную и оптимизированную — с измерением работы и разбором горячего пути.

## Дано

- 4000 записей, 64 источника; данные детерминированы (линейный генератор, сид `20260727`).
- Конвейер: по каждой записи найти имя источника, прибавить длину имени, добавить значение в группу.
- Метрика — **счётчик операций**, а не время.

## Что должно быть в наивной версии

Намеренно медленной:

- поиск имени источника **линейным перебором** по всем 64 именам;
- поиск группы **линейным перебором** по встреченным ключам;
- вычисление длины строки внутри цикла.

## Что даёт оптимизация

- ключ и есть индекс — прямая адресация вместо поиска;
- длины имён считаются **один раз** до цикла;
- накопление сумм по индексу вместо поиска группы.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] **Результаты обеих версий совпадают** — и суммы значений, и суммы длин имён.
- [ ] Расхождение результатов останавливает тест.
- [ ] Ускорение по операциям — не менее 10×; эталон даёт **32.6×**.
- [ ] Обе версии сохранены: сравнивать должно быть с чем.
- [ ] Печатается доля горячего пути и оценка по закону Амдала для двух вариантов вложения усилий.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/profile.c
make test
```

Поучительная проверка: оптимизируйте только вынос вычисления длины из цикла, оставив оба поиска. Выигрыш составит около одного процента — ровно то, что предсказывает закон Амдала для холодного пути.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| ускорение около единицы | оптимизирован холодный путь |
| суммы разошлись | при переходе на индексацию потеряна запись |
| профиль показывает равные доли | счётчик учитывает не все операции |
| результат меняется между запусками | замеряется время вместо операций |
| наивная версия не медленнее | поиск случайно оптимизирован компилятором |
| нечего сравнивать | наивная версия переписана, а не сохранена |

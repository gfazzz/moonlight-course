# Season Project — `moonlight_core`

**Программа, собранная из модулей четырёх сезонов.**

Это не серия и не ещё один одиночный файл. Здесь проверяется то, ради чего курс вообще делится на сезоны: **написанный ранее код переиспользуется как модуль**, а не копируется.

## Из чего собрано

| Модуль | Откуда | Что даёт |
|---|---|---|
| `ml_hash.c` | `season-4/lib` (s04e03, s04e04) | djb2, индекс корзины |
| `ml_crc.c` | `season-6/lib` (s06e05) | CRC-16/MODBUS, проверка кадра |
| `ml_stats.c` | `season-8/lib` (s08e01, s08e02) | Уэлфорд, квантили, границы Тьюки |
| `ml_kalman.c` | `season-9/lib` (s09e07) | фильтр Калмана `[x, v]` |
| `main.c` | этот сезон | интеграция |

**Пять единиц трансляции из четырёх сезонов** компилируются раздельно и линкуются в один исполняемый файл.

## Сборка и запуск

```bash
make            # компиляция 5 .c из 4 сезонов
make run        # запуск
make modules    # показать, из чего собрана программа
make test       # автотест
```

Команда сборки видна в `Makefile` целиком:

```make
$(CC) $(CFLAGS) -I$(S4) -I$(S6) -I$(S8) -I$(S9) \
      -o moonlight_core $(S4)/ml_hash.c $(S6)/ml_crc.c \
                        $(S8)/ml_stats.c $(S9)/ml_kalman.c main.c
```

## Что проверяет тест

Тест проверяет не только вывод, но и **сам факт межсезонной сборки**:

1. модули существуют в своих сезонах;
2. `main.c` подключает их **заголовки**;
3. в `main.c` **нет копий реализаций** — только вызовы;
4. программа линкуется из нескольких единиц трансляции;
5. поведение: баланс кадров сходится, фильтр точнее сырого измерения, вывод совпадает с эталоном.

Третья проверка — ключевая: она не даёт «сымитировать» переиспользование копипастой.

## Почему это важно

Модуль — это контракт (`.h`), а не файл с кодом. Пока интерфейс не меняется, реализацию можно править свободно, и все потребители продолжают работать. Именно так собирают настоящие системы: заголовок объявляет, `.c` реализует, линковщик соединяет.

Здесь же видно и обратную сторону: если бы реализация была скопирована в каждый сезон, исправление ошибки в djb2 пришлось бы вносить в четырёх местах — и одно из них обязательно забыли бы.

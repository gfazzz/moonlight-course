## Брифинг

Подсистемы по отдельности работают. Интеграция ломается **на стыках**: исход одной стадии теряется по дороге к другой, и запись исчезает молча.

Из сорока пакетов в хранилище дошли двадцать четыре. Двенадцать отказов объяснимы. Про четыре сказать нечего.

## Приказ

Написать `artifacts/pipeline.c`: конвейер приём → валидация → журнал → хранение → агрегация → сводка, со сведением баланса.

## Дано

- 40 пакетов; каждый седьмой содержит дефект: сигнатура, длина, канал, контрольная сумма.
- Хранилище на 24 записи — **меньше** входного потока: переполнение неизбежно и штатно.
- 4 канала для агрегации.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Каждая запись получает **ровно один** исход, и он учитывается в счётчиках.
- [ ] Исходы оформлены перечислением, а не логическим значением.
- [ ] **Баланс сходится**: `принято + отвергнуто == подано`. Проверяется арифметически в коде.
- [ ] Сквозная целостность: число и сумма записей в хранилище совпадают с агрегатами.
- [ ] Журнал ведётся впереди данных: записей журнала столько же, сколько записей в хранилище.
- [ ] Переполнение хранилища — штатный исход: конвейер **продолжает** обработку.
- [ ] Дешёвые проверки выполняются раньше дорогих операций.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Ожидаемые значения

| Величина | Значение |
|---|---|
| принято / отвергнуто | 24 / 16 = 40 |
| отвергнуто из-за нехватки места | 10 |
| сумма в хранилище = в агрегатах | 5777 |

## Выполнение

```bash
cp starter.c artifacts/pipeline.c
make test
```

Поучительная проверка: увеличьте вместимость хранилища до сорока. Все пакеты пройдут, отчёт покажет успех — и любая молчаливая потеря останется незамеченной, потому что сравнивать станет не с чем.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| баланс не сходится в меньшую сторону | есть возврат без учёта исхода |
| баланс не сходится в большую сторону | запись учтена дважды |
| причины отказов не видны | исход оформлен логическим значением |
| суммы хранилища и агрегатов разошлись | агрегаты считаются независимо |
| конвейер завершился на переполнении | штатная ситуация обработана как фатальная |
| журнал короче хранилища | нарушен порядок упреждающей записи |

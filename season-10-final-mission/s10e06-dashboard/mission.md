## Обстановка

Четыре источника телеметрии, семь подсистем, окно связи. Всё считается и пишется в лог построчно — читать невозможно, решение принять нельзя.

Нужен один экран, показывающий операцию целиком. И показывающий честно.

## Приказ

Написать `artifacts/dashboard.c`: собрать кадр `62×18` в буфер и вывести три сценария — штатный режим, устаревание данных, потеря источника с деградацией ядра.

**Спецификация — это `tests/expected.txt`.** Каркас даёт размеры и типы, остальное выводится из вида экрана.

## Модель данных

| Сущность | Поля |
|---|---|
| источник | имя, значение, возраст в секундах, состояние |
| состояние источника | `SRC_OK`, `SRC_STALE`, `SRC_DOWN` |
| окно связи | длительность в минутах, угол места в градусах |
| подсистемы | сколько поднято из скольких |

Порог устаревания — `STALE_SEC = 30`. Возраст **приходит в модели**, а не берётся из системных часов: тест обязан быть детерминированным.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Модель и представление разделены: `render` принимает состояние по `const`-указателю и **ничего не вычисляет**.
- [ ] Кадр собирается в буфер `char scr[H][W]` и печатается целиком, а не по мере отрисовки.
- [ ] У источника три состояния, не два: `[ok]`, `[OLD]`, `[DOWN]`.
- [ ] Возраст показывается **у каждого** источника; недоступный печатает `---` и `no data`.
- [ ] Сводный статус выводится из состояния модели: `NOMINAL` → `STALE DATA` → `DEGRADED`.
- [ ] Полоса подсистем масштабируется от `up/total`, а не от константы.
- [ ] Подписи внутри экрана — **только ASCII**.
- [ ] Три кадра совпадают с `tests/expected.txt` посимвольно; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/dashboard.c
make test
make run     # посмотреть кадры глазами
```

Эталон — в `solution/`. Открывай после честной попытки: в этом сезоне она особенно уместна, режим автономный.

## Диагностика

| Симптом | Причина |
|---|---|
| рамка разъехалась на одну-две позиции | кириллица внутри экрана: ячейка — байт |
| статус остаётся `NOMINAL` при `[OLD]` | сводный статус захардкожен, а не выведен из модели |
| полоса всегда полная | знаменатель константа вместо `total` |
| тест «плавает» между запусками | возраст берётся из системного времени |
| последняя строка обрезана | буфер не завершён или `H` посчитан на единицу меньше |

## После выполнения

Оператор увидит не картинку, а состояние. Останется соединить приём, проверку, обработку и показ в один поток — по отдельности работает всё, и это ничего не значит.

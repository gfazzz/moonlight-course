# Season 10 — Final Mission

**Финал курса: интеграция всего построенного. 8 серий, ~12 часов.**

> *«Десять сезонов ты строил инструменты. Сегодня они отвечают за результат».*

Новых тем почти нет — есть **сборка системы** из артефактов девяти сезонов и её приёмка по измеримым критериям. Плюс одна новая линия, которой требовал план: спутники и орбитальная механика. Проект сезона — `moonlight_core`.

---

## Режим сезона: максимальная автономия

Подсказок нет вообще. `starter.c` содержит только брифинг и, где нужно, готовый генератор данных — ни сигнатур, ни TODO. Спецификация задачи — `mission.md` (критерии приёмки) и `tests/expected.txt` (точный формат вывода). Структуру кода студент выбирает сам.

Это финальная точка прогрессивной автономии: S1–S4 — полный каркас, S5–S6 — каркас с TODO, S7–S8 — интерфейсы, S9 — только интерфейс, S10 — только требования.

## Сквозная линия

Серии складываются в одну операцию: собрать ядро (e01) → рассчитать орбиту и окно перехвата (e02–e03) → уложиться в это окно по производительности (e04) → выдержать враждебный эфир (e05) → показать состояние оператору (e06) → свести поток без потерь (e07) → принять результат (e08).

## Как проходить

```bash
cd s10e01-architecture
cat README.md mission.md
cp starter.c artifacts/core.c
make test
# из корня сезона: make test — прогон всех 8 серий
```

Всё детерминировано и собирается **без внешних библиотек**, включая `-lm`: `sqrt`, `sin`, `cos`, `atan2`, `asin` реализуются вручную — иначе расхождение в последнем бите ломает воспроизводимость.

## Проверка свойств, а не чисел

Тесты сезона проверяют инварианты, а не только совпадение строк:

- порядок инициализации модулей действительно уважает зависимости (проверяется программно);
- законы сохранения на орбите (энергия, момент импульса, второй закон Кеплера);
- окно связи правдоподобно для низкой орбиты, доплеровский сдвиг меняет знак;
- оптимизация **не изменила результат**;
- разбор пакета проходит `-fsanitize=address,undefined` без единого срабатывания;
- баланс конвейера сходится арифметически: принято + отвергнуто = подано;
- в финальной приёмке представлены все десять сезонов, а код возврата соответствует итогу.

## Season Project: `moonlight_core`

Восемь подсистем: ядро с реестром модулей, орбитальный расчёт, планирование окна связи, оптимизированный конвейер, защищённый приёмный тракт, дашборд, интеграционный конвейер и приёмочная операция.

## Финал

[s10e08](s10e08-final-operation/) подтверждает навыки всех десяти сезонов двенадцатью фазами и закрывает курс.

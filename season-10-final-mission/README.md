## О чём сезон

**Стэнфорд, 1 ноября.** Ты открываешь каталог с работой девяти сезонов и впервые смотришь на него целиком: семь проектов, каждый работает, ни один не знает об остальных.

Виктор пишет: собери систему.

За четыре дня разрозненные артефакты становятся `moonlight_core`. Выясняется, что канал противника идёт через спутник, а значит, его расписание не привязано к орбите — оно ею определено. Окно связи открывается на восемь минут сорок четыре секунды раз в полтора часа, и за это время система обязана принять поток, отфильтровать враждебный эфир, обработать без потерь и показать оператору состояние.

Пятого ноября в 02:14 по всемирному времени окно открывается в последний раз.

Новых тем почти нет — есть сборка и приёмка по измеримым критериям. Единственная новая линия: спутники и орбитальная механика.

## Режим сезона: максимальная автономия

Подсказок нет вообще. `starter.c` содержит только брифинг и, где нужно, генератор данных — ни сигнатур, ни указаний. Спецификация задачи — `mission.md` и `tests/expected.txt`. Структуру кода выбираете сами.

Это финальная точка прогрессивной автономии:

| Сезоны | Что даёт каркас |
|---|---|
| S1–S4 | полный каркас с пошаговыми комментариями |
| S5–S6 | каркас с указаниями |
| S7–S8 | интерфейсы функций |
| S9 | только интерфейс |
| **S10** | **только требования** |

## Сквозная линия

Серии складываются в одну операцию:

```
собрать ядро (e01)
  -> рассчитать орбиту и окно перехвата (e02, e03)
  -> уложиться в окно по производительности (e04)
  -> выдержать враждебный эфир (e05)
  -> показать состояние оператору (e06)
  -> свести поток без потерь (e07)
  -> принять результат (e08)
```

Каждый шаг ставит вопрос, ответ на который даёт следующий. Это единственный сезон курса, где серии нельзя переставить местами.

## Как проходить

```bash
cd s10e01-architecture
cat mission.md
cp starter.c artifacts/core.c
make test
```

Из корня сезона `make test` прогоняет все восемь серий и сквозной проект.

Всё детерминировано и собирается **без внешних библиотек**, включая `-lm`: `sqrt`, `sin`, `cos`, `atan2`, `asin` реализуются вручную — иначе расхождение в последнем бите ломает воспроизводимость.

> **LUNA работает в режиме `Ask`, а не `Agent`.** В этом сезоне каркас пуст, и соблазн отдать задачу целиком максимален.

Ваш код в `artifacts/` отслеживается git — работайте в своей ветке. Правки курса — веткой от чистого `main`: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Проверка свойств, а не чисел

Тесты сезона проверяют инварианты, а не только совпадение строк:

| Серия | Что проверяется программно |
|---|---|
| e01 | порядок инициализации уважает зависимости |
| e02 | законы сохранения: энергия, момент импульса, второй закон Кеплера |
| e03 | окно правдоподобно для низкой орбиты, сдвиг меняет знак |
| e04 | оптимизация **не изменила** результат |
| e05 | разбор проходит санитайзеры без единого срабатывания |
| e06 | кадры совпадают посимвольно, статус выводится из модели |
| e07 | баланс сходится арифметически |
| e08 | представлены все десять сезонов, код возврата соответствует итогу |

Четвёртая и седьмая строки — те, ради которых всё затевалось: оптимизация, меняющая результат, и конвейер, теряющий записи, выглядят как успех, если проверять только вывод.

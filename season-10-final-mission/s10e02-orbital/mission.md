# Mission — s10e02 «Орбитальная механика»

> **Максимальная автономия.** Каркас пуст. Ниже — физика и критерии приёмки; формат вывода — в `tests/expected.txt`.

## Брифинг
Канал противника идёт через спутник. Он не висит на месте: чтобы поймать окно связи, надо уметь считать, **где он будет** в заданный момент.

## Что сдать
`artifacts/orbit.c`: расчёт положения и скорости спутника на витке с проверкой законов Кеплера.

## Дано
- Орбита: `a = 7000` км, `e = 0.02`; `MU = 398600.4418` км³/с², `RE = 6378.137` км.
- Виток разбивается на 8 равных шагов по времени (9 точек, включая замыкающую).

## Формулы

```
период:             T = 2π·√(a³/μ)
среднее движение:   n = 2π/T
средняя аномалия:   M = n·t
уравнение Кеплера:  M = E − e·sin(E)        решать Ньютоном
радиус:             r = a·(1 − e·cos(E))
скорость (vis-viva): v = √(μ·(2/r − 1/a))
энергия:            ε = v²/2 − μ/r          должна равняться −μ/(2a)
момент импульса:    L = √(μ·a·(1 − e²))     постоянен
```

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**: `sqrt`, `sin`, `cos`, `atan2` — свои.
- [ ] Уравнение Кеплера решается **итерационно** (Ньютон), число итераций выводится: 1–4 при `e = 0.02`.
- [ ] Аргумент тригонометрии приводится к `[−π, π]` — иначе ряды теряют точность.
- [ ] Удельная энергия совпадает с теоретической `−μ/(2a)`; относительное отклонение энергии и момента `< 1e-9`.
- [ ] Второй закон Кеплера подтверждён: `v_перигей·r_перигей = v_апогей·r_апогей`, а отношение скоростей равно отношению радиусов.
- [ ] Через полный период спутник возвращается в исходную точку (тест проверяет программно).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Брифинг

Канал противника идёт через спутник, а он не висит на месте. Чтобы поймать окно связи, надо уметь считать, где аппарат будет в заданный момент.

Формулы для этого не существует: уравнение Кеплера трансцендентно и решается только итерациями.

## Приказ

Написать `artifacts/orbit.c`: расчёт положения и скорости спутника на витке с проверкой законов Кеплера.

## Дано

- Орбита: `a = 7000` км, `e = 0.02`; `MU = 398600.4418` км³/с², `RE = 6378.137` км.
- Виток разбивается на 8 равных шагов по времени — 9 точек, включая замыкающую.

## Формулы

```
период:              T = 2π·√(a³/μ)
среднее движение:    n = 2π/T
средняя аномалия:    M = n·t
уравнение Кеплера:   M = E − e·sin(E)          решать Ньютоном
радиус:              r = a·(1 − e·cos(E))
скорость:            v = √(μ·(2/r − 1/a))
энергия:             ε = v²/2 − μ/r            должна равняться −μ/(2a)
момент импульса:     L = √(μ·a·(1 − e²))       постоянен
```

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**: `sqrt`, `sin`, `cos`, `atan2` свои.
- [ ] Уравнение Кеплера решается **итерационно**; число итераций выводится и составляет 1–4.
- [ ] Критерий остановки — по невязке, а не фиксированное число шагов.
- [ ] Аргумент тригонометрии приводится к `[−π, π]` **до** разложения в ряд.
- [ ] Удельная энергия совпадает с теоретической `−μ/(2a)`.
- [ ] Относительное отклонение энергии и момента импульса меньше `1e-9`.
- [ ] Второй закон Кеплера подтверждён: отношение скоростей равно отношению радиусов.
- [ ] Через полный период спутник возвращается в исходную точку — тест проверяет программно.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

```bash

```

Поучительная проверка: уберите приведение аргумента к `[−π, π]` и посчитайте виток вдвое длиннее. Ряды начнут терять значащие цифры, а инварианты покажут это раньше, чем станет заметно по координатам.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| точность падает во второй половине витка | аргумент не приведён к `[−π, π]` |
| энергия дрейфует вдоль витка | ошибка в формуле или неустойчивый метод |
| итераций Ньютона больше десяти | неверная производная |
| период не совпал | в формулу подставлен эксцентриситет |
| спутник не вернулся в исходную точку | шаг по времени посчитан неверно |
| результат отличается между машинами | использована библиотечная тригонометрия |

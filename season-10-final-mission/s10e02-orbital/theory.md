# Теория (углублённо) — s10e02

## 1. Три закона Кеплера

1. **Орбита — эллипс**, в одном из фокусов которого находится притягивающее тело.
2. **Секторная скорость постоянна**: радиус-вектор заметает равные площади за равные времена. Следствие — у перигея спутник быстрее, у апогея медленнее (в задаче это подтверждается точным равенством `v·r`).
3. **T² ∝ a³**: период зависит только от большой полуоси. Отсюда `T = 2π·√(a³/μ)`.

Ньютон позже показал, что все три следуют из закона всемирного тяготения.

## 2. Аномалии: три разных «угла»

Самое путающее место в теме — три угловые переменные:

- **средняя аномалия M** — растёт **линейно** со временем: `M = n·t`. Физического угла не изображает, зато удобна для расчётов.
- **эксцентрическая аномалия E** — вспомогательный угол на описанной окружности.
- **истинная аномалия ν** — настоящий угол «фокус → перигей → спутник».

Связаны они так: `M → E` (уравнение Кеплера), затем `E → ν` и `E → r`.

## 3. Уравнение Кеплера и почему нужен Ньютон

```
M = E − e·sin(E)
```

Это **трансцендентное** уравнение: `E` не выражается через `M` в элементарных функциях (доказано Бесселем). Решают численно:

```c
f(E)  = E − e·sin(E) − M
f'(E) = 1 − e·cos(E)
E    -= f(E)/f'(E);
```

Метод Ньютона сходится **квадратично**: число верных знаков удваивается за шаг. Поэтому в логе видно 1–4 итерации до точности 1e-13. Начальное приближение `E₀ = M` хорошо работает при малых `e`; при `e → 1` (сильно вытянутые, кометные орбиты) метод может расходиться — тогда берут `E₀ = π` или используют метод Лагерра.

Это тот же градиентный спуск по духу, что в Season 8, но для одномерного корня и с гарантированной квадратичной сходимостью.

## 4. Инварианты как способ проверки

У численного расчёта обязана быть проверка. В орбитальной механике их две:

```
удельная энергия:   ε = v²/2 − μ/r = −μ/(2a)      постоянна
момент импульса:    L = √(μ·a·(1−e²))              постоянен
```

Если после интегрирования энергия «поехала» — метод неустойчив. У нас отклонение ~1e-16 (уровень машинной точности), потому что положение считается **аналитически** из элементов орбиты, а не пошаговым интегрированием.

Это принципиальная разница: при численном интегрировании (Эйлер, Рунге–Кутта) энергия дрейфует, и для долгих расчётов берут **симплектические** интеграторы (Верле, Leapfrog), сохраняющие фазовый объём.

## 5. Чего здесь нет

Модель двух тел — идеализация. Реальные расчёты учитывают:

- **J2** — сплюснутость Земли: главное возмущение для НОО, вызывает прецессию орбиты (на нём основаны солнечно-синхронные орбиты);
- **атмосферное торможение** — ниже ~500 км определяет срок жизни спутника;
- притяжение Луны и Солнца, давление солнечного света.

Практический стандарт для спутников — формат **TLE** (two-line elements) и модель **SGP4**, которая учитывает основные возмущения. Наш расчёт — её ядро без поправок.

## 6. Почему тригонометрия своя

`sin`/`cos`/`atan2` из `libm` могут отличаться в последнем бите между платформами — вывод перестал бы быть побитово воспроизводимым. Реализация рядами с фиксированным числом членов даёт одинаковый результат везде.

Важная деталь: перед разложением аргумент **приводят** к `[−π, π]`. Ряд Тейлора для `sin` вокруг нуля при большом аргументе требует огромного числа членов и катастрофически теряет точность на вычитаниях — та же проблема, что у наивной дисперсии в s08e01.

## Теория: найти `E`, чтобы узнать всё

### Цепочка

```
T = 2π√(a³/μ)        период зависит только от большой полуоси
M = n·t              средняя аномалия линейна по времени
M = E − e·sin(E)     решать Ньютоном
r = a(1 − e·cos E)   радиус
v = √(μ(2/r − 1/a))  скорость
```

### Три аномалии

| Величина | Что это | Свойство |
|---|---|---|
| средняя `M` | не угол, а мера времени | **линейна** по времени |
| эксцентрическая `E` | угол на описанной окружности | вспомогательная |
| истинная `ν` | настоящий угол от перигея | даёт направление |

Путаница между ними — главный источник ошибок в теме. Средняя аномалия удобна для расчётов и не изображает никакого физического угла.

### Ньютон

```c
f(E)  = E − e·sin(E) − M;
f'(E) = 1 − e·cos(E);
E    -= f(E) / f'(E);
```

Сходимость квадратичная: число верных знаков удваивается за шаг. Отсюда одна-четыре итерации до `1e-13`.

Начальное приближение `E₀ = M` хорошо при малом эксцентриситете. При сильно вытянутых орбитах метод может расходиться, и берут другое приближение.

### Инварианты

```
удельная энергия:  ε = v²/2 − μ/r = −μ/(2a)
момент импульса:   L = √(μ·a·(1 − e²))
```

Обе величины постоянны вдоль витка. Их отклонение — единственный доступный способ проверить расчёт, у которого нет эталона.

### Второй закон Кеплера в числах

```
v_перигей · r_перигей = v_апогей · r_апогей
```

Отношение скоростей равно отношению радиусов — это и есть постоянство секторной скорости, записанное через измеримые величины.

### Почему тригонометрия своя

Библиотечные функции могут отличаться в последнем бите между платформами, и вывод перестал бы быть воспроизводимым.

Обязательная деталь: аргумент приводится к `[−π, π]` **до** разложения в ряд. При большом аргументе ряд требует огромного числа членов и катастрофически теряет точность на вычитаниях — та же проблема, что у наивной дисперсии в s08e01.

## Проверка: LUNA задаёт вопросы
```
[LUNA] Два вопроса про орбиту.
```

**1.** LUNA: «Почему уравнение Кеплера решают итерациями, а не выражают `E` через `M`?»

<details><summary>Ответ</summary>

Потому что оно трансцендентное: `E` не выражается через `M` в элементарных функциях, и это доказанный результат, а не отсутствие подходящей идеи. Бессель показал, что решение представимо бесконечным рядом по функциям, названным его именем, но для практики ряд неудобен. Поэтому применяют численные методы; Ньютон сходится квадратично и даёт машинную точность за три-четыре шага при малом эксцентриситете. У сильно вытянутых орбит производная вблизи перигея почти обращается в ноль, метод становится неустойчивым, и начальное приближение приходится выбирать аккуратнее.
</details>

**2.** LUNA: «Как проверить, что расчёт орбиты не врёт?»

<details><summary>Ответ</summary>

Инвариантами. Удельная энергия обязана равняться `−μ/(2a)`, момент импульса — `√(μa(1−e²))`, и обе величины должны сохраняться вдоль всего витка. Если они уходят — метод неустойчив или в формуле ошибка. Это единственная доступная проверка: эталона для сравнения нет, а правдоподобный результат ещё ничего не доказывает. У нас отклонение порядка `1e-16`, потому что положение вычисляется аналитически из элементов орбиты. При пошаговом численном интегрировании энергия дрейфует, и для долгих расчётов применяют симплектические методы, сохраняющие фазовый объём.
</details>


## Разбор типичных ошибок

1. **Ряд без приведения аргумента.** При большом угле точность рушится.
2. **Аномалии перепутаны.** Средняя линейна по времени, но это не угол на орбите.
3. **Инварианты не проверяются.** Ошибка в знаке останется незамеченной.
4. **Взята библиотечная тригонометрия.** Расхождение в последнем бите ломает воспроизводимость.
5. **Итерации Ньютона фиксированы числом.** Нужен критерий по невязке.
6. **Период считается через эксцентриситет.** Он зависит только от большой полуоси.

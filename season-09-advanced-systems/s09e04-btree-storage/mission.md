## Обстановка

Их база: 4.2 гигабайта, одиннадцать миллионов записей, отклик 1.8 миллисекунды.

Двоичное дерево дало бы двадцать три чтения с диска. Значит, дерево у них другое — с узлом в целую страницу.

## Приказ

Написать `artifacts/btree.c`: B-дерево минимальной степени `T = 3` — вставка с расщеплением, поиск со счётчиком прочитанных страниц, обход по порядку, сравнение с линейным сканированием.

## Дано

- 200 детерминированных ключей (линейный генератор, сид `20260726`), значения — смещения записей.
- Узел вмещает от `T−1 = 2` до `2T−1 = 5` ключей.
- Узлы живут в пуле; их индексы играют роль номеров страниц.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Вставка идёт сверху вниз с **превентивным расщеплением**: полный потомок делится до спуска в него.
- [ ] Расщепление поднимает **средний** ключ в родителя, остальное делит поровну.
- [ ] При расщеплении внутреннего узла переезжают и указатели на потомков.
- [ ] Полный корень порождает новый корень — дерево растёт **вверх**.
- [ ] Поиск считает каждое чтение узла как обращение к странице.
- [ ] Обход по порядку выдаёт ключи **отсортированными** и находит все 200.
- [ ] Итог: высота `4`, поиск — 3–4 страницы, выигрыш над линейным сканированием `25.5×`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

Тест дополнительно проверяет, что обход отсортирован и что ни один ключ не потерян при расщеплении.

## Выполнение

```bash
cp starter.c artifacts/btree.c
make test
```

Поучительная проверка: поднимайте при расщеплении не средний ключ, а первый. Дерево продолжит работать и даже находить ключи — просто станет вырожденным, и высота вырастет вдвое.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| переполнение узла при вставке | расщепление выполняется после, а не до спуска |
| высота вдвое больше ожидаемой | поднимается не средний ключ |
| часть ключей не находится | при расщеплении потеряны указатели на потомков |
| листья на разной глубине | дерево растёт вниз |
| обход не отсортирован | нарушен порядок ключей внутри узла |
| счётчик чтений не совпал | считаются сравнения вместо обращений к узлам |

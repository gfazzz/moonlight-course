## Теория: взвесить два вранья

### Цикл

```
предсказание:  x = x + v·dt      P = F·P·Fᵀ + Q      неопределённость РАСТЁТ
коррекция:     K = P/(P + R)     x += K·(z − x)      неопределённость ПАДАЕТ
```

Между измерениями фильтр становится менее уверен: мир меняется, а он не смотрит. После измерения — более уверен.

### Коэффициент усиления — это доверие

```
K = P / (P + R)
```

| Соотношение | Смысл | Поведение |
|---|---|---|
| `P ≫ R` | мы не знаем ничего, датчик хорош | `K → 1`, верим измерению |
| `P ≪ R` | уверены в модели, датчик шумит | `K → 0`, верим себе |

В задаче `K0` падает с 0.976 на первом шаге до 0.261 к тридцатому. Баланс настраивается **сам** — вручную его не задают.

### Откуда берётся ненаблюдаемая скорость

Ковариация хранит не только дисперсии положения и скорости, но и **связь** между ними.

Шаг предсказания эту связь создаёт: `x` зависит от `v`, поэтому ошибка скорости протекает в ошибку положения. Внедиагональные элементы становятся ненулевыми.

Дальше:

```
K1 = p10 / S        /* усиление по скорости */
v += K1 · (z − x)   /* невязка по координате правит скорость */
```

При скалярной ковариации связи нет, `K1` тождественно ноль, и скорость навсегда останется стартовой.

Принцип общий: **фильтр восстанавливает ненаблюдаемые переменные через их корреляцию с наблюдаемыми**. Так по координате оценивают ускорение, по сигналу спутников — дрейф часов, по акселерометру — смещение гироскопа.

### Две ручки

| Параметр | Смысл | Что даёт увеличение |
|---|---|---|
| `R` | шум измерения | фильтр глаже, но запаздывает |
| `Q` | шум процесса | фильтр вёртче, но шумнее |

`R` берут из паспорта датчика, `Q` подбирают под ожидаемую динамику.

**1.** LUNA: «Радар измеряет только координату. Откуда фильтр знает скорость?»

<details><summary>Ответ</summary>

Из корреляции. Шаг предсказания `x += v·dt` связывает ошибку скорости с ошибкой положения, и эта связь записывается во внедиагональных элементах ковариации. Поэтому усиление по скорости `K1 = p10/S` оказывается ненулевым, и невязка по координате корректирует скорость, которую никто не измерял. Со скалярной ковариацией связи нет, `K1` тождественно ноль, и скорость навсегда останется стартовой. Принцип шире задачи: восстановить можно любую величину, связанную с наблюдаемой известной моделью.
</details>

**2.** LUNA: «Хочу более гладкий трек — занижу `Q` посильнее. Что не так?»

<details><summary>Ответ</summary>

Фильтр уверует в свою модель. Ковариация станет малой, усиление уйдёт почти в ноль, и измерения перестанут на него влиять — он будет добросовестно продолжать предсказание, игнорируя реальность. При манёвре цели он её потеряет, и это состояние называют расходимостью. Признак в журнале однозначный: невязка систематически одного знака — фильтр всё время ошибается в одну сторону и не исправляется. Гладкость трека здесь обманчива: она означает не точность, а отсутствие реакции.
</details>

## Разбор типичных ошибок

1. **Ковариация скалярная.** Скорость не выучится никогда.
2. **Забыт шум процесса.** Ковариация схлопнется, фильтр перестанет слушать измерения.
3. **Порядок шагов перепутан.** Измерение применится к устаревшему состоянию.
4. **Ковариация обновляется до вычисления усиления.** Усиление считается по предсказанной.
5. **Матрица перехода записана неверно.** Связь координаты со скоростью исчезнет.
6. **Начальная ковариация мала.** Фильтр не поверит первым измерениям и будет сходиться долго.

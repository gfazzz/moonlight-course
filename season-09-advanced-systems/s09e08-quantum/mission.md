## Обстановка

Их канал защищён ключом RSA на 2048 бит — стойким на классическом компьютере.

Суперпозиция сама по себе ничего не даёт: измерение вернёт один случайный исход. Весь выигрыш прячется в фазах, которых в вероятностях не видно.

## Приказ

Написать `artifacts/quantum.c`: симулятор квантового регистра — гейты `H`, `X`, `Z`, `CNOT`, демонстрация суперпозиции, запутанности и интерференции, плюс алгоритм Гровера.

## Дано

- 3 кубита — вектор из 8 комплексных амплитуд.
- Цель поиска Гровера — состояние `|110>` (индекс 6), 2 итерации.
- Комплексные числа реализуются вручную; `sqrt` — свой, без `-lm`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Однокубитные гейты обрабатывают **пары** индексов, различающиеся битом `q`, ровно один раз.
- [ ] Гейт Адамара вносит множитель `1/√2`.
- [ ] **Сумма вероятностей всегда равна 1** — тест проверяет каждую строку вывода.
- [ ] `CNOT` действует только там, где управляющий кубит равен 1.
- [ ] Состояние Белла содержит **только** `|000>` и `|011>`.
- [ ] Пара `H → Z → H` даёт определённое состояние `|001>` — демонстрация интерференции.
- [ ] Гровер: оракул меняет знак амплитуды цели, диффузия отражает относительно среднего.
- [ ] После двух итераций вероятность цели — **94.5 %**.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

Тест отдельно проверяет нормировку, отсутствие несовпадающих состояний в паре Белла и результат Гровера.

## Выполнение

```bash
cp starter.c artifacts/quantum.c
make test
```

Проектная сборка сезона:

```bash
cd ../project && make && make run
```

Поучительная проверка: увеличьте число итераций Гровера до десяти и посмотрите на вероятность цели. Она поднимется, а потом начнёт падать — лишняя работа здесь вредна.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| сумма вероятностей больше единицы | пара индексов обработана дважды |
| сумма вероятностей меньше единицы | забыт множитель в гейте Адамара |
| интерференции не происходит | фазовый гейт не меняет знак |
| в паре Белла есть `\|001>` и `\|010>` | `CNOT` применён без проверки управляющего |
| вероятность цели около 0.125 | оракул не помечает цель |
| вероятность цели падает | итераций больше оптимума |

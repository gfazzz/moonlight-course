## Теория: фаза решает

### Стоимость симуляции

| Кубитов | Амплитуд | Память |
|---|---|---|
| 10 | 1 024 | 16 КБ |
| 30 | ~10⁹ | ~16 ГБ |
| 50 | ~10¹⁵ | ~16 ПБ |

Экспонента в чистом виде. Она же объясняет, почему квантовый компьютер не эмулируют, а строят.

### Гейты — это повороты

Квантовый гейт унитарен: обратим и сохраняет сумму вероятностей.

| Гейт | Что делает |
|---|---|
| `X` | обычное отрицание |
| `H` | создаёт суперпозицию |
| `Z` | меняет **знак** амплитуды, где бит равен 1 |
| `CNOT` | инвертирует цель, если управляющий равен 1 |

Обратимость — не деталь реализации, а требование. Классический `AND` необратим: по выходу `0` нельзя восстановить входы. Квантовые операции такого не допускают.

В коде однокубитный гейт действует на **пары** индексов, различающиеся одним битом:

```
H:  amp[i] = (a + b)/√2      amp[j] = (a − b)/√2
```

### Запутанность

`H` на первый кубит плюс `CNOT` даёт:

```
(|00> + |11>)/√2
```

Состояний `|01>` и `|10>` нет **вовсе**. Измерив один кубит, мы мгновенно знаем второй — при том, что до измерения ни один не имеет определённого значения.

Такое состояние нельзя записать как пару независимых кубитов. Передать информацию так тоже нельзя: корреляция обнаруживается только при сравнении результатов по обычному каналу.

### Гровер

Поиск среди `N` вариантов:

| | Классически | Гровер |
|---|---|---|
| запросов | ~`N/2` | `O(√N)` |
| для `N = 8` | ~4 | 2 |
| для `N = 10⁶` | 500 000 | ~785 |

Каждая итерация — два шага:

1. **оракул** помечает цель сменой знака амплитуды;
2. **диффузия** отражает все амплитуды относительно среднего: `amp = 2·среднее − amp`.

Отрицательная амплитуда цели после отражения оказывается заметно больше остальных.

Геометрически это поворот вектора состояния к цели на фиксированный угол. Оптимум — примерно `(π/4)·√N` итераций.

**Больше — хуже.** Продолжив вращение, вектор пройдёт мимо цели.

## Проверка на канале

```
[LUNA] Два вопроса. Последние в этом сезоне.
```

**1.** LUNA: «Восемь состояний в суперпозиции — значит, мы посчитали функцию для всех восьми входов сразу?»

<details><summary>Ответ</summary>

Посчитать — да, прочитать — нет. Измерение даёт ровно один исход, выбранный случайно с вероятностью, равной квадрату модуля амплитуды, а всё остальное разрушается необратимо. Поэтому «квантовый параллелизм» сам по себе не даёт никакого ускорения: восемь вычислений, из которых можно узнать одно случайное, эквивалентны одному вычислению со случайным входом. Ускорение возникает только тогда, когда алгоритм дополнительно строит интерференцию, гасящую неправильные ответы, — и придумать такую конструкцию удаётся для очень немногих задач.
</details>

**2.** LUNA: «Две итерации Гровера дали 94.5 %. Сделаем двадцать — получим 99.9 %?»

<details><summary>Ответ</summary>

Нет, станет хуже. Каждая итерация поворачивает вектор состояния к цели на фиксированный угол, и после оптимального числа шагов — примерно `(π/4)·√N` — он проходит мимо, а вероятность начинает падать. При достаточном числе итераций она вернётся почти к исходной. Это принципиальное отличие от классических алгоритмов, где лишняя работа обычно безвредна: квантовые алгоритмы требуют **точного** числа шагов, и оно должно быть вычислено заранее исходя из размера пространства поиска.
</details>

```

```

## Разбор типичных ошибок

1. **Пара обрабатывается дважды.** Гейт применится вторично и откатится.
2. **Забыт множитель в гейте Адамара.** Нормировка ломается.
3. **Фазовый гейт считается бесполезным.** Он не меняет вероятности, но делает возможной интерференцию.
4. **Итераций Гровера «побольше».** После оптимума вероятность падает.
5. **`CNOT` применяется независимо от управляющего кубита.** Запутанности не возникнет.
6. **Нормировка не проверяется.** Ошибка в гейте обнаружится через десяток шагов.

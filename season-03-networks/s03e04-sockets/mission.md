## Обстановка

Всё, что было до сих пор, — чтение вчерашних дампов. Пора установить соединение самому.

Тренировка идёт на своей машине: и клиент, и сервер на `127.0.0.1`. Тот самый loopback, который вчера означал плохие новости, — здесь он полезен, потому что слушать нечего.

## Приказ

Написать `artifacts/echo.c`: сервер и клиент в одной программе, разведённые через `fork`. Клиент шлёт `PING`, сервер отвечает `PONG`.

## Дано

Серверная цепочка `socket`/`bind`/`listen`/`accept`, клиентская `socket`/`connect`, обмен `read`/`write`. Адрес `INADDR_LOOPBACK`, порт `0` — «любой свободный».

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `struct sockaddr_in` **обнулена** при объявлении; `sin_port` и `sin_addr` — через `htons`/`htonl`.
- [ ] Порт запрашивается как `0`, фактический узнаётся через `getsockname` — жёстко заданного порта в коде нет.
- [ ] Сервер: `bind` → `listen` → `accept`; обмен идёт по дескриптору от `accept`, не по слушающему.
- [ ] Клиент в дочернем процессе: `connect` → `write` → `read`.
- [ ] Чтение — **в цикле** до набора ожидаемого числа байт; `EINTR` обрабатывается повтором, возврат `0` означает закрытие.
- [ ] Печатает **только родитель**; ребёнок сообщает результат кодом выхода.
- [ ] Оба процесса закрывают ненужные дескрипторы; родитель делает `waitpid`.
- [ ] Возвраты системных вызовов проверяются.
- [ ] Вывод совпадает с `tests/expected.txt`, код возврата 0; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/echo.c
make test
```

> Это настоящие TCP-сокеты, но на loopback: без внешней сети, без root, воспроизводимо на любой машине.

Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| `connect: Connection refused` | клиент стартовал раньше, чем сервер вызвал `listen` |
| `bind: Address already in use` | жёстко заданный порт занят; нужен `0` или `SO_REUSEADDR` |
| соединение уходит не туда | забыт `htons` для `sin_port` |
| вывод перемешан между запусками | печатают оба процесса |
| программа висит на `read` | вторая сторона не закрыла дескриптор |
| в `ps` остаётся зомби | нет `waitpid` |

# Теория (углублённо) — s04e07

## 1. Список против массива

| операция | массив | связный список |
|----------|--------|----------------|
| доступ по индексу | O(1) | O(n) |
| вставка в начало | O(n) (сдвиг) | **O(1)** |
| вставка после известного узла | O(n) | **O(1)** |
| поиск значения | O(n) | O(n) |
| память | непрерывная | узлы разбросаны + указатель на узел |

Список выигрывает там, где структура постоянно растёт и вставки идут не в конец. Проигрывает в произвольном доступе и в кэш-локальности: узлы разбросаны по куче, процессор не может их предзагрузить (поэтому на практике массивы часто быстрее, даже когда асимптотика хуже).

## 2. Вставка в голову

```c
n->next = *head;   // новый указывает на старую голову
*head = n;         // новый становится головой
```

Два присваивания, никакого обхода — O(1). Именно поэтому в хеш-таблице (s04e04) цепочки тоже растут с головы.

## 3. Разворот тремя указателями

```c
Node *prev = NULL;
while (head) {
    Node *next = head->next;  // сохранить ДО перезаписи
    head->next = prev;        // развернуть ссылку
    prev = head;
    head = next;
}
return prev;                  // новая голова
```

Классическая ловушка: перезаписать `head->next` до того, как сохранил `next` — остаток списка потерян навсегда (и это утечка).

## 4. Алгоритм Флойда: заяц и черепаха

Как понять, что список зациклен, не используя дополнительной памяти?

```c
slow = slow->next;         // шаг
fast = fast->next->next;   // два шага
if (slow == fast) -> цикл
```

Если цикла нет, `fast` упрётся в `NULL`. Если цикл есть, быстрый неизбежно догонит медленного внутри цикла (расстояние между ними сокращается на 1 за итерацию). Память — O(1), время — O(n).

Продолжение (не в задаче): если после встречи поставить один указатель в голову и двигать оба по шагу, они встретятся ровно в **начале** цикла — так находят точку входа.

## 5. Цикл и `free`

Освобождать зациклённый список нельзя: обход не закончится, а узлы, освобождённые дважды, испортят кучу. Сначала разрываем цикл (`tail->next = NULL`), потом освобождаем — как в s02e08.

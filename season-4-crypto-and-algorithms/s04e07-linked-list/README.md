## Теория: узлы и ссылки

**Вставка в голову** — два присваивания, без обхода:

```c
n->next = *head;
*head = n;          // O(1)
```

**Разворот** — три указателя; ключ в том, чтобы сохранить `next` **до** перезаписи ссылки:

```c
Node *next = head->next;   // иначе потеряешь остаток списка
head->next = prev;
prev = head; head = next;
```

**Цикл (Флойд)** — медленный идёт на шаг, быстрый на два:

```c
slow = slow->next;
fast = fast->next->next;
if (slow == fast) /* цикл */;
```

Нет цикла — `fast` упрётся в `NULL`. Есть цикл — быстрый догонит медленного (расстояние сокращается на 1 за итерацию). Память O(1).

**Важно:** зациклённый список нельзя освобождать — сначала разорви кольцо (`tail->next = NULL`), потом `free`. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса. Один из них спасёт тебя от зависания.
```

**1.** LUNA: «В `reverse` ты написал `head->next = prev;` и только потом взял `head->next`. Что случилось?»

<details><summary>Ответ</summary>

Остаток списка потерян: ссылка на следующий узел затёрта, дойти до него больше нельзя (и это утечка). `next` нужно сохранить **до** перезаписи.
</details>

**2.** LUNA: «Почему быстрый указатель обязательно догонит медленного, если цикл есть?»

<details><summary>Ответ</summary>

Внутри цикла быстрый приближается к медленному на одну позицию за итерацию (идёт на 2, тот на 1). Расстояние строго убывает, значит встреча неизбежна — за число шагов не больше длины цикла.
</details>

## Разбор типичных ошибок

1. **Потерян `next` при развороте.** Сохраняй до перезаписи — иначе теряешь хвост.
2. **`free` зациклённого списка.** Бесконечный обход или double-free. Сначала разорви кольцо.
3. **`fast->next->next` без проверки.** Если `fast->next == NULL` — разыменование `NULL`. Проверяй оба условия в `while`.
4. **Поиск цикла «множеством посещённых».** Работает, но это O(n) памяти; Флойд обходится O(1).

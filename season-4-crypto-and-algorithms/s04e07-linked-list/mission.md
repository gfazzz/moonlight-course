# Mission — s04e07 «Связный список»

## Что сдать
`artifacts/list.c`: строит связный список (вставка в голову), ищет, разворачивает, обнаруживает цикл алгоритмом Флойда и полностью освобождает память.

## Дано
- Значения 10, 20, 30, 40, 50 (вставляются в голову → порядок `50 40 30 20 10`).
- Узлы — в куче (`malloc`), как в Season 2.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `push` вставляет в голову за O(1); `find` возвращает позицию или −1.
- [ ] `reverse` разворачивает список тремя указателями (`prev`/`head`/`next`).
- [ ] `detect_cycle` реализован по Флойду (медленный/быстрый), находит точку встречи.
- [ ] Перед освобождением цикл **разорван** (`tail->next = NULL`), иначе `free` зациклится.
- [ ] Вывод совпадает с `tests/expected.txt`; ASan без утечек; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/list.c
make test
```

> Тест запускается с таймаутом: зависание = цикл не разорван.

## Оценка времени
~45–55 минут.

## Результат в сюжете
Реестр можно наращивать блок за блоком без сдвига данных. А поиск цикла пригодится сразу: в цепочке блоков кто-то замкнул ссылки, чтобы спрятать подделку.

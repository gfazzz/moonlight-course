## Обстановка

Указатель на предыдущую запись — обычное поле, его можно переписать вместе с данными. Нужна связь, которая **выводится** из содержимого и потому не правится отдельно.

И нужно, чтобы переписывание стоило дорого.

## Приказ

Написать `artifacts/blockchain.c`: построить цепь блоков с доказательством работы, проверить её целостность, подделать один блок и локализовать подделку.

## Дано

Записи реестра MOONLIGHT (генезис-блок и четыре транзакции). Хеш-функция из s04e03. Сложность — двенадцать нулевых старших бит.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Хеш блока считается от индекса, данных, `prev_hash` и `nonce`; поле `hash` **не входит** в собственное вычисление.
- [ ] `prev_hash` участвует в хешировании — иначе связь не является связью.
- [ ] Доказательство работы: `nonce` подбирается перебором, пока старшие 12 бит хеша не станут нулевыми.
- [ ] Все величины **беззнаковые**: сдвиг вправо у знакового типа расширяет знак.
- [ ] Проверка цепи выполняет **три** теста на каждый блок: связь с предыдущим, соответствие хеша данным, выполнение условия сложности.
- [ ] После подмены данных в блоке проверка сообщает **индекс** первого несходящегося блока.
- [ ] Вывод совпадает с `tests/expected.txt`: пять блоков, все хеши с нулевыми старшими битами.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/blockchain.c

```

Стоит попробовать вручную: измените число нулевых бит с 12 на 16 и посмотрите, как вырастет время построения. Каждый бит удваивает работу.

Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| хеш не сходится сам с собой | поле `hash` включено в собственное вычисление |
| подделка не обнаружена | проверяется только связь, но не соответствие хеша данным |
| подделка в середине не ломает хвост | `prev_hash` не участвует в хешировании |
| подбор `nonce` не заканчивается | сдвиг у знакового типа расширяет знак |
| результат невоспроизводим между запусками | `nonce` не сброшен перед подбором |

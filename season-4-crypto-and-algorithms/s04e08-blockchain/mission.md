# Mission — s04e08 «Блокчейн» (финал Season 4)

## Что сдать
`artifacts/blockchain.c`: собирает цепочку блоков с Proof-of-Work, проверяет её целостность и обнаруживает подделанный блок.

## Дано
- 5 блоков реестра MOONLIGHT (генезис + 3 транзакции + аудит).
- Хеш блока считается по полям `index`, `data`, `prev_hash`, `nonce`.
- Сложность: `hash >> 20 == 0` (старшие 12 бит нулевые).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `block_hash` подмешивает все поля блока (кроме самого `hash`).
- [ ] `mine` перебирает `nonce` с нуля до выполнения условия сложности.
- [ ] `prev_hash` первого блока = 0, остальных = хеш предыдущего.
- [ ] `verify` проверяет три вещи: совпадение хеша, условие PoW и связь с предыдущим блоком.
- [ ] После подмены данных блока 2 `verify` возвращает именно **блок 2**.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/blockchain.c
make test
```

> Не увеличивай `DIFFICULTY` — майнинг растёт экспоненциально, тест уйдёт в таймаут.

## Оценка времени
~50–60 минут.

## Результат в сюжете
Реестр MOONLIGHT проверен. Подделка в блоке 2 (1.8M → 8.1M) обнаружена мгновенно: хеш не сходится, связь порвана. Чтобы это скрыть, «Архитектору» пришлось бы перемайнить всю цепочку — доказательство у Евы на руках.

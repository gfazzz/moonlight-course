## Теория: цепочка, скреплённая хешами

```
[0 GENESIS | prev=0  | hash=H0]
[1 TX ...  | prev=H0 | hash=H1]
[2 TX ...  | prev=H1 | hash=H2]
```

Хеш блока считается по всем его полям, включая `prev_hash`. Поэтому правка байта в блоке `i` меняет `H_i`, и `prev_hash` блока `i+1` перестаёт совпадать — цепочка рвётся **начиная с места правки**.

**Proof-of-Work** делает создание блока дорогим:

```c
while ((block_hash(...) >> DIFFICULTY) != 0) nonce++;
```

Условие «старшие 12 бит нулевые» срабатывает примерно раз на 4096 попыток. Асимметрия: найти nonce — перебор, проверить — одно хеширование.

**Верификатор** проверяет три вещи: хеш пересчитывается и совпадает; PoW выполнен; `prev_hash` равен хешу предыдущего. Про границы учебной модели (32-битный некриптографический хеш, отсутствие подписей и консенсуса) — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса. Финальные в этом сезоне.
```

**1.** LUNA: «Подделали блок 2 из пяти. Сколько блоков придётся перемайнить, чтобы это скрыть?»

<details><summary>Ответ</summary>

Блок 2 и все последующие — 2, 3, 4. Изменение данных меняет `H2`, из-за чего `prev_hash` блока 3 не сойдётся, и так по цепочке. Каждый перемайн — новый перебор nonce, поэтому подделка дорожает с глубиной.
</details>

**2.** LUNA: «Почему PoW вообще нужен, если хеши и так рвут цепочку при правке?»

<details><summary>Ответ</summary>

Без PoW пересчитать все хеши после правки — мгновенно, подделка почти бесплатна. PoW делает каждый блок дорогим в создании, но дешёвым в проверке: переписать историю становится вычислительно невыгодно.
</details>

```
[LUNA] Верно. Проверяй реестр.
```

## Разбор типичных ошибок

1. **Хеш не включает `prev_hash`.** Тогда правка блока не рвёт связь — вся идея цепочки теряется.
2. **Проверять только связи, не пересчитывая хеш.** Подделка данных с сохранённым `hash` пройдёт незамеченной. Нужны все три проверки.
3. **Поднять `DIFFICULTY`.** Время майнинга растёт экспоненциально — тест уйдёт в таймаут.
4. **Забыть `nonce` в хеше.** Тогда PoW бессмыслен: перебирать нечего.

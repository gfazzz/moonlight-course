# Season 4 — Crypto & Algorithms

**Криптография и алгоритмы через финансовое расследование. 8 серий, ~5.5 часа.**

> *«Секреты защищены не замками, а математикой. Плохая математика — плохой замок».*

---

## О чём сезон

**Москва, вечер 4 октября.** На плате, которую Виктор передал у Спасской башни, три файла. Первый — шифр Цезаря, оставленный намеренно, как записка поверх настоящих данных. Третий — байты, неотличимые от случайных.

Между ними — восемь серий и перелёт в Цюрих, где Ева Циммерман два года подозревала схему и не могла её доказать.

Сезон устроен как одно расследование, в котором каждый следующий инструмент нужен потому, что предыдущий упёрся в предел: перебор не берёт 26! ключей → статистика; линейный поиск по 2.8 миллиона записей стоит четыре секунды → хеш-таблица; сортировка вставками не закончится за два года → слияние; доказательство существует в одном экземпляре → цепочка блоков.

## Сквозная идея сезона

Каждая серия упирается в предел предыдущего инструмента:

| Предел | Чем снят |
|---|---|
| 25 ключей перебираются, 26! — нет | e02: статистика вместо перебора |
| нужно доказать, что файл не менялся | e03: отпечаток вместо копии |
| поиск по 2.8 млн записей — 4 секунды | e04: вычислить адрес, а не искать |
| сортировка вставками — два с половиной года | e05: O(n log n) вместо O(n²) |
| проверять суммы часто и по всей базе | e06: 22 шага вместо 2.8 миллиона |
| доказательство существует в одном экземпляре | e07: связанные записи |
| ссылку можно переписать вместе с данными | e08: связь, выведенная из содержимого |

Сквозная мысль: **стойкость измеряется в стоимости атаки, а не в сложности алгоритма**. Цезарь ломается за миллисекунду, замена — за минуты статистики, блокчейн требует переписать всю цепь быстрее, чем она растёт.

## Как проходить

```bash
cd s04e01-caesar-cipher
cp starter.c artifacts/caesar.c
make test
```

Из корня сезона `make test` прогоняет все восемь серий и сквозной проект.

> **LUNA работает в режиме `Ask`, а не `Agent`.** В `Agent` ассистент правит файлы сам — тест позеленеет, а вы не напишете ни строки.

> **Читайте `.md` в предпросмотре** (`Cmd+Shift+V` / `Ctrl+Shift+V`), иначе сворачиваемые ответы видны сразу.

Ваш код в `artifacts/` отслеживается git — работайте в своей ветке. Правки курса — веткой от чистого `main`: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Season Project: `crypto_toolkit`

Первый проект курса, который собирается из модулей **двух** сезонов:

```bash
cd project
make modules     # показать, из чего собрана программа
make run
```

| Модуль | Откуда | Что даёт |
|---|---|---|
| [`ml_crypto`](../season-1-foundations/lib/ml_crypto.h) | **Season 1** | XOR-шифрование, контрольная сумма |
| [`ml_hash`](lib/ml_hash.h) | Season 4 | djb2, адресация по корзинам |

Тест проекта проверяет **сам факт переиспользования**: он падает, если `main.c` содержит скопированные реализации вместо подключения модулей. Копипастом задачу не сдать.

**Что уходит дальше.** `ml_hash` линкуется в четырёх проектах — индексом тикеров в `trading_system` (S5), адресацией устройств в `iot_controller` (S6), в `luna_ai` (S8) и в `moonlight_core` (финал):

```bash
grep -rn "ml_hash.h" --include=*.c ..
```

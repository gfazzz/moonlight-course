## Обстановка

Перебор по базе — четыре секунды на запрос. Запросов нужно десять тысяч. Это одиннадцать часов, которых нет.

Отпечаток строки — число. Число можно использовать не для проверки, а для адресации.

## Приказ

Написать `artifacts/hashtable.c`: таблица на восемь корзин с разрешением коллизий цепочками. Вставка, поиск, вывод распределения, корректное освобождение.

## Дано

Хеш-функция из предыдущей серии. Набор ключей (`eva`, `ghost`, `marcus`, `weiss` и другие) со значениями.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Индекс корзины — `hash % buckets`; хеш **беззнаковый**, иначе индекс может стать отрицательным.
- [ ] Ключ **копируется** при вставке, а не сохраняется по указателю на чужую строку.
- [ ] Поиск сравнивает **ключи через `strcmp`**, а не только хеши: совпадение хеша не означает совпадения ключа.
- [ ] Коллизии разрешаются цепочками; в одной корзине может лежать несколько записей.
- [ ] Выводится распределение по корзинам — видно, что оно неравномерно, и это нормально.
- [ ] Неуспешный поиск возвращает явный признак отсутствия, а не мусор.
- [ ] Освобождение проходит по всем корзинам; у каждого узла освобождаются **и ключ, и сам узел**; `next` сохраняется до `free`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.
- [ ] Санитайзер утечек не находит.

## Выполнение

```bash
cp starter.c artifacts/hashtable.c
make test
gcc -fsanitize=address -g artifacts/hashtable.c -o /tmp/ht && /tmp/ht
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| найденное значение меняется само | ключ не скопирован, хранится указатель на чужую строку |
| найден не тот элемент | сравниваются хеши вместо ключей |
| падение при отрицательном индексе | хеш объявлен знаковым |
| утечка ровно по числу записей | освобождены узлы, забыты ключи |
| `heap-use-after-free` при очистке | `e->next` прочитан после `free(e)` |
| все записи в одной корзине | хеш не перемешивает — проверьте `unsigned char` |

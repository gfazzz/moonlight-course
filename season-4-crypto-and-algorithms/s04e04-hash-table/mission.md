# Mission — s04e04 «Хеш-таблица»

## Что сдать
`artifacts/hashtable.c`: хеш-таблица на 8 корзин с разрешением коллизий цепочками — вставка, поиск, распределение, load factor и полное освобождение памяти.

## Дано
- 10 ключей (`viktor`, `eva`, `ghost`, …) со значениями `(i+1)*10`.
- Хеш djb2 из s04e03; узлы и копии ключей — в куче (S2).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `ht_put` кладёт узел в голову цепочки корзины `djb2(key) % NBUCKETS`.
- [ ] `ht_get` ищет по корзине и сравнивает ключи через `strcmp`.
- [ ] `ht_free` освобождает и ключ, и узел, сохраняя `next` **до** `free`.
- [ ] Выводится распределение по корзинам (видны коллизии), результаты поиска, load factor.
- [ ] Вывод совпадает с `tests/expected.txt`; **ASan без утечек**; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/hashtable.c
make test
```

## Оценка времени
~45–55 минут.

## Результат в сюжете
250 000 документов операции теперь можно искать за O(1) вместо перебора. Коллизии не мешают — цепочки их держат.

# Mission — s04e03 «Хеш-функции»

## Что сдать
`artifacts/hashes.c`: реализует djb2 и FNV-1a, измеряет лавинный эффект при изменении одного символа и показывает распределение по корзинам.

## Дано
- Строки: `MOONLIGHT`, `VIKTOR`, `EVA`, `GHOST`.
- djb2: `h = 5381`, затем `h = h*33 + c`. FNV-1a: `h = 2166136261`, затем `h ^= c; h *= 16777619`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Обе функции работают с байтами как `unsigned char` (не знаковый `char`).
- [ ] `popcount32` считает изменившиеся биты через XOR двух хешей.
- [ ] Замерена лавина для правки **последнего** и **первого** символа.
- [ ] Показаны корзины `hash % 16`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/hashes.c
make test
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Отпечатки считаются. И сразу видно ограничение: djb2 почти не реагирует на правку последнего байта (1 бит из 32) — таким хешем реестр не защитишь. Для блокчейна (s04e08) нужен другой класс функций.

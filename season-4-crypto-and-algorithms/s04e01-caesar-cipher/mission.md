# Mission — s04e01 «Шифр Цезаря»

## Что сдать
`artifacts/caesar.c`: шифрует и расшифровывает текст сдвигом, а также взламывает перехват перебором всех 25 ключей.

## Дано
- Открытый текст и ключ-сдвиг `+7`.
- Алфавит A–Z / a–z; не-буквы (пробелы, знаки) не шифруются.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `caesar(in, out, shift)` работает и для положительного, и для отрицательного сдвига (`((x % 26) + 26) % 26`).
- [ ] Регистр сохраняется; не-буквы не изменяются.
- [ ] Брутфорс печатает все 25 вариантов; на сдвиге 7 читается исходный текст.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/caesar.c
make test
```

## Оценка времени
~30–40 минут.

## Результат в сюжете
Первый из трёх файлов с USB Виктора вскрыт: `USB CONTAINS THREE FILES TRUST EVA`. Ключей было всего 25 — такой шифр не защищает. Ева Циммерман выходит на связь.

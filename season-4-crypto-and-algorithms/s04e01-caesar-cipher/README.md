## Что ты освоишь

- Подстановочный шифр со сдвигом: `c = (m + k) mod 26`.
- Корректный модуль в C для отрицательных чисел: `((x % 26) + 26) % 26`.
- Брутфорс как атака: почему маленькое пространство ключей = отсутствие защиты.

Глубже — в [`theory.md`](theory.md).

---

## Теория: сдвиг по алфавиту

Каждая буква заменяется на отстоящую на `k` позиций:

```
k = 7:  U->B, S->Z, B->I ...
```

Шифрование `c = (m + k) mod 26`, расшифровка `m = (c − k) mod 26` — то есть **одна и та же функция** со сдвигом `+k` и `−k`.

Ловушка C: `%` для отрицательных даёт отрицательный остаток (`-3 % 26 == -3`), поэтому пишут:

```c
out[i] = 'A' + (((c - 'A' + shift) % 26) + 26) % 26;
```

Регистр сохраняем, не-буквы (пробелы, знаки) не трогаем.

**Почему это не защита:** ключей всего 25 — перебор мгновенный. Стойкость должна держаться на размере ключа, а не на «хитрости» алгоритма (принцип Керкхоффса). Даже произвольная подстановка (26! ключей) падает от частотного анализа — это s04e02. Подробнее — [`theory.md`](theory.md).

**1.** LUNA: «Почему `(c - 'A' + shift) % 26` ломается при `shift = -7`, и как это чинится?»

<details><summary>Ответ</summary>

В C остаток от отрицательного числа отрицателен, и индекс уедет за пределы алфавита. Идиома `((x % 26) + 26) % 26` нормализует результат в `0..25` — работает и для `+k`, и для `−k`.
</details>

**2.** LUNA: «Если перемешать алфавит произвольно (26! ключей), брутфорс не пройдёт. Значит, шифр стойкий?»

<details><summary>Ответ</summary>

Нет. Подстановка сохраняет частоты букв: самая частая буква шифротекста почти наверняка соответствует `E`/`O`. Такой шифр ломается частотным анализом без всякого перебора — этим займёмся в s04e02.
</details>

## Разбор типичных ошибок

1. **Отрицательный модуль.** `% 26` без нормализации ломает расшифровку. Только `((x%26)+26)%26`.
2. **Потерян регистр.** `'a'..'z'` обрабатывай отдельно от `'A'..'Z'`, иначе текст «съедет».
3. **Шифруются пробелы и знаки.** Не-буквы копируются как есть.
4. **Забыт `'\0'`.** Выходная строка должна завершаться терминатором (иначе печать поедет — привет s01e02).

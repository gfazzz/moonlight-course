# Mission — s04e02 «Частотный анализ»

## Что сдать
`artifacts/freq.c`: определяет ключ подстановочного шифра **статистически** — по частотам букв и метрике хи-квадрат, без ручного перебора вариантов.

## Дано
- Шифротекст (сдвиг неизвестен).
- Таблица эталонных частот букв английского языка `ENG[26]` (в процентах).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `chi_squared(text)` считает `Σ (наблюдаемое − ожидаемое)² / ожидаемое` по 26 буквам.
- [ ] Ожидаемое = `ENG[i]/100 * total` (нормировка на длину текста, а не на 100).
- [ ] Перебираются все 26 сдвигов, выбирается минимальный хи-квадрат.
- [ ] Выводятся три лучших кандидата и расшифровка победителя.
- [ ] Вывод совпадает с `tests/expected.txt` (`best shift = 11`); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/freq.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
Второй файл вскрыт без перебора глазами: «MOONLIGHT ledger реален, каждая транзакция подписана украденным ключом, Ева это докажет». Ключ выдала статистика языка.

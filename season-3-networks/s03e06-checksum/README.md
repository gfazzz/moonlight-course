## Что ты освоишь

- Internet checksum: сумма 16-битных слов, свертка переносов, дополнение (`~`).
- Свойство проверки: сумма с уже вставленным checksum даёт `0`.
- Границы: checksum ловит помехи, но не защищает от намеренной подделки.

Глубже — в [`theory.md`](theory.md).

---

## Теория: 16 бит целостности

```c
uint16_t inet_checksum(const uint8_t *buf, int len) {
    uint32_t sum = 0;
    for (int i = 0; i + 1 < len; i += 2) sum += (buf[i] << 8) | buf[i+1];
    if (len & 1) sum += buf[len-1] << 8;
    while (sum >> 16) sum = (sum & 0xFFFF) + (sum >> 16);  // свернуть переносы
    return (uint16_t)~sum;                                 // дополнение
}
```

Поле checksum при подсчёте — ноль. Проверка красива: посчитай checksum по заголовку **вместе** с уже вставленным полем — получится `0x0000` (потому что `sum + ~sum = 0xFFFF`, а `~0xFFFF = 0`). Значит проверка = «пересчитал всё → должно быть 0». Про границы (не криптостойкость) — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про целостность.
```

**1.** LUNA: «Почему сумма по заголовку с уже вставленным checksum должна быть 0?»

<details><summary>Ответ</summary>

Checksum = `~sum`. При проверке складываем всё, включая checksum: `sum + ~sum = 0xFFFF`, свернули — `0xFFFF`, дополнение — `0x0000`. Ноль = цел.
</details>

**2.** LUNA: «Агент Z. подделал адрес. Помешает ли ему контрольная сумма?»

<details><summary>Ответ</summary>

От случайной порчи — да, поймает. От намеренной подделки — нет: злоумышленник пересчитает и подставит правильный checksum. Против подделки нужны криптоподписи (Season 4). Checksum — про целостность, не аутентичность.
</details>

```
[LUNA] Верно. Считай сумму.
```

## Разбор типичных ошибок

1. **Не свернул переносы.** Без `while (sum>>16)` старшие биты потеряются — сумма неверна.
2. **Забыл `~`.** Checksum — это дополнение суммы, не сама сумма.
3. **Считать поле checksum ненулевым при вычислении.** При подсчёте оно = 0 (или считаешь проверкой всё и ждёшь 0).
4. **Нечётная длина.** Последний одиночный байт — старший байт слова (`buf[len-1] << 8`).

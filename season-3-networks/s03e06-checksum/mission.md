# Mission — s03e06 «Контрольная сумма»

## Что сдать
`artifacts/checksum.c`: считает Internet checksum IP-заголовка, вставляет его, проверяет валидность и показывает, что порча байта делает пакет невалидным.

## Дано
- 20-байтовый IP-заголовок с обнулённым полем checksum (байты 10–11).
- Алгоритм RFC 1071: сумма 16-битных слов + свертка переносов + дополнение (`~`).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `inet_checksum` суммирует 16-битные слова, сворачивает переносы, берёт `~`.
- [ ] Вставка checksum и проверка: сумма по всему заголовку = `0x0000` → valid.
- [ ] Порча одного байта → сумма ≠ 0 → INVALID.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/checksum.c
make test
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Теперь ты отличишь настоящий пакет от подделанного: у фальшивки контрольная сумма не сойдётся. Трафик агентов Z., притворяющийся «своим», выдаст себя.

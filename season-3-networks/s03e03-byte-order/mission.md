# Mission — s03e03 «Порядок байтов»

## Что сдать
`artifacts/byteorder.c`: определяет endianness хоста и показывает, как `htons`/`htonl` переводят число в сетевой порядок байтов (и что бывает, если прочитать «как есть»).

## Дано
- Порт `443`, адрес `0xCB00712A` (203.0.113.42).
- `<arpa/inet.h>`: `htons/htonl/ntohs/ntohl`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Endianness хоста определён (probe: первый байт `uint32_t = 1`).
- [ ] Показаны байты числа в памяти (host) и «на проводе» (после `htons`/`htonl`).
- [ ] Показан «неправильный» результат чтения без `ntohs` и правильный — с ним.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/byteorder.c
make test
```

> Заметка: вывод детерминирован на x86-64 (little-endian, платформа автотеста). На big-endian машине байты совпали бы с сетевыми — это нормально.

~30–35 минут.

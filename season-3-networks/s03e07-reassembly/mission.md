# Mission — s03e07 «Реассемблинг потока»

## Что сдать
`artifacts/reassemble.c`: собирает исходный поток байтов из TCP-сегментов, пришедших вперемешку, по их `seq` (смещению).

## Дано
- `segments.dat` — сегменты в произвольном порядке.
- Формат сегмента: `seq(uint32 BE) len(uint16 BE) data(len байт)`; `seq` = смещение в потоке.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Каждый сегмент кладётся на смещение `seq` (порядок прихода не важен).
- [ ] Считаются длина потока и пропуски (недостающие байты).
- [ ] Вывод совпадает с `tests/expected.txt` (0 пропусков, собранное сообщение).
- [ ] `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/reassemble.c
make test
```

## Оценка времени
~40–50 минут.

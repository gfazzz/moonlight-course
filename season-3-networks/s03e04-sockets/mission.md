# Mission — s03e04 «Сокеты»

## Что сдать
`artifacts/echo.c`: сервер и клиент в одном процессе (через `fork`), диалог по TCP на `127.0.0.1`. Клиент шлёт `PING`, сервер отвечает `PONG`.

## Дано
- TCP API: сервер — `socket`/`bind`/`listen`/`accept`; клиент — `socket`/`connect`; обмен — `write`/`read`.
- Loopback `127.0.0.1` (`INADDR_LOOPBACK`), порт `0` = любой свободный.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Сервер: `bind` на loopback, `getsockname` (узнать порт), `listen`, `accept`.
- [ ] Клиент (в `fork`): `connect`, `write "PING"`, `read` ответа.
- [ ] Печатает **только родитель** (детерминизм); ребёнок сообщает результат кодом выхода.
- [ ] Вывод совпадает с `tests/expected.txt`; выход 0; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/echo.c
make test
```

> Это настоящие TCP-сокеты, но на loopback — без внешней сети и без root. Безопасно и воспроизводимо.

## Оценка времени
~50–60 минут.

## Результат в сюжете
Первый живой сетевой диалог: ты постучался к серверу и получил ответ. Теперь трафик можно не только слушать, но и вести.

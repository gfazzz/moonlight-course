# Mission — s03e01 «IP-адресация»

## Что сдать
`artifacts/ipinfo.c`: читает IPv4-адреса из файла, для каждого печатает 32-битное число, hex и класс (private/public/loopback).

## Дано
- `addresses.txt` — по одному адресу на строку (есть валидные и один битый).
- IPv4 = 4 октета (0–255) = 32-битное число: `a<<24 | b<<16 | c<<8 | d`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Разбор через `sscanf` ровно 4 октетов; проверка диапазона 0–255.
- [ ] Классификация: `127.x`=loopback; `10.x`, `172.16–31.x`, `192.168.x`=private; иначе public.
- [ ] Битый адрес помечается `INVALID`, разбор не падает.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/ipinfo.c
make test
```

## Оценка времени
~30–35 минут.

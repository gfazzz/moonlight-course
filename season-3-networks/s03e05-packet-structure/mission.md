# Mission — s03e05 «Структура пакета»

## Что сдать
`artifacts/dissect.c`: разбирает захваченный пакет (IPv4 + TCP) по полям — адреса, порты, seq, флаги, payload.

## Дано
- 40-байтовый пакет (в коде): IPv4-заголовок (20 байт) + TCP-заголовок (20 байт).
- Все многобайтовые поля — big-endian; читай через `be16`/`be32` (побайтово).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] IP: version, IHL (в байтах), total_len, ttl, protocol, src/dst адреса.
- [ ] TCP начинается на смещении `ihl*4`; извлечены порты, seq, data offset, флаги.
- [ ] Флаг SYN (`0x02`) распознан; payload = `total_len - (ihl*4 + data_off*4)`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/dissect.c
make test
```

## Оценка времени
~45–55 минут.

## Результат в сюжете
Пакет вскрыт: SYN с `203.0.113.42:31337` на `192.168.1.100:443`. Порт `31337` — подпись «Призрака». Теперь ясно, кто стучится — и кто он на самом деле.

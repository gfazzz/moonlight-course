## Обстановка

Сорок байт, пришедших на сокет, пока держалось соединение. Внутри — адреса, порты, флаги и намерение отправителя.

Разделителей нет. Границы слоёв придётся вычислить из самих данных.

## Приказ

Написать `artifacts/dissect.c`: разобрать пакет по полям — IP-заголовок, TCP-заголовок, размер данных.

## Дано

40-байтовый пакет в коде: IPv4-заголовок плюс TCP-заголовок. Все многобайтовые поля — в сетевом порядке.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Поля читаются **побайтовой сборкой** (`be16`/`be32`), а не наложением структуры и не приведением указателя.
- [ ] Из IP извлечены: версия, IHL, полная длина, TTL, протокол, адреса источника и назначения.
- [ ] Начало TCP вычислено как `ihl * 4`, а не зашито числом 20.
- [ ] Из TCP извлечены: порты, номер последовательности, data offset, флаги.
- [ ] Флаги проверяются **маской** (`flags & 0x02`), а не сравнением на равенство.
- [ ] Длина данных посчитана как `total_len − ihl*4 − data_off*4`.
- [ ] `ihl` и `total_len` проверены против фактического размера буфера **до** использования.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/dissect.c
make test
```

Ожидается `203.0.113.42:31337 → 192.168.1.100:443`, флаг `SYN`, данных 0 байт. Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| порты выглядят случайными числами | начало TCP взято как +20 вместо `ihl * 4` |
| значения полей перевёрнуты | нет сборки из байтов в сетевом порядке |
| `SYN` не распознан | сравнение `flags == 0x02` вместо маски |
| длина данных отрицательная | вычтены константы вместо фактических длин заголовков |
| `bus error` на ARM | приведение указателя к `uint32_t *` на невыровненном адресе |

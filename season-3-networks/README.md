# Season 3 — Networks

**Сетевое программирование через перехват. 8 коротких серий, ~5 часов.**

> *«Всё связано. Нужно лишь найти нить».*

Виктор жив — и назначил встречу. Но говорить приходится по сети, которую слушают. Season 3 — про то, как понимать трафик: от IP-адреса как числа до полного конвейера перехвата. Ты разбираешь адреса и подсети, читаешь пакеты байт в байт, ведёшь TCP-диалог, вскрываешь заголовки (и узнаёшь, кто такой «Призрак»), проверяешь целостность, собираешь TCP-поток из хаоса сегментов и, наконец, перехватываешь и расшифровываешь канал Виктора — который отдаёт USB со следующим сезоном.

## Как проходить

Оболочка — **Cursor в режиме IDE**; LUNA из сюжета = чат Cursor.

```bash
cd s03e01-ip-addressing
cat README.md
cp starter.c artifacts/ipinfo.c
make test                # зелёный тест = серия пройдена
# из корня сезона: make test — прогон всех 8 серий
```

Все сетевые задачи **детерминированы и не требуют root/внешней сети**: сокеты (`s03e04`) работают на loopback через `fork` (печатает только родитель), остальное — над байтовыми буферами и файлами. Эталон в `solution/` открывай после честной попытки.

## Season Project: `network_interceptor`

Артефакты серий складываются в инструмент сезона: разбор адресов/подсетей, сокет-клиент, диссектор пакетов, реассемблер потока и перехватчик канала. Переиспользуется дальше через `#include`.

# Теория (углублённо) — s03e08

Финальная серия собирает навыки сезона в один инструмент перехвата.

## 1. Полный конвейер перехвата

Реальный анализ трафика — это цепочка:

```
захват пакетов -> проверка целостности (checksum) -> реассемблинг по seq
             -> расшифровка -> разбор прикладного протокола
```

Ты прошёл каждый шаг по отдельности (s03e05–e07 + XOR из s01); здесь они соединяются.

## 2. Порядок операций важен

Расшифровывать надо **после** реассемблинга, а не до: XOR применяется к непрерывному потоку. Если расшифровать каждый сегмент по отдельности и потом собрать — для простого потокового XOR с фиксированным ключом результат тот же, но для потоковых шифров с состоянием (позиция в ключевом потоке) — нет. Правильный порядок: сначала собрать байты в исходную последовательность, потом расшифровать.

## 3. Неполный поток нельзя расшифровать

Если есть дыры (потерянные сегменты), поток неполон — расшифровка даст мусор в местах пропусков. Поэтому сначала проверяем `gaps == 0`, и только затем расшифровываем. Это же делает реальный DPI: ждёт полную сессию.

## 4. Куда это ведёт

Ты перехватил и прочитал чужой зашифрованный разговор — но только потому, что шифр был слабый (одно-байтовый XOR). Настоящая криптография (Season 4) на это не поддастся: там ключи, хеши, доказуемая стойкость. Season 3 показал, как течёт трафик; Season 4 покажет, как его по-настоящему защитить.

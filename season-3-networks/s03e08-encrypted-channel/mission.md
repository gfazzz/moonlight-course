# Mission — s03e08 «Шифрованный канал» (финал Season 3)

## Что сдать
`artifacts/intercept.c`: восстанавливает открытое сообщение из перехваченного канала — реассемблинг сегментов по `seq` (s03e07) + XOR-расшифровка ключом `0x42` (s01).

## Дано
- `channel.dat` — зашифрованные TCP-сегменты в произвольном порядке.
- Формат: `seq(uint32 BE) len(uint16 BE) data(len байт, XOR-шифр)`; ключ `0x42`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Сегменты укладываются по `seq`; считаются длина и пропуски.
- [ ] При пропусках (`gaps != 0`) — расшифровка не выполняется (поток неполный).
- [ ] XOR-расшифровка собранного потока ключом `0x42`.
- [ ] Вывод совпадает с `tests/expected.txt` (открытое сообщение V.).
- [ ] `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/intercept.c
make test
```

## Оценка времени
~45–55 минут.

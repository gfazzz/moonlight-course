## Обстановка

В дампе есть пакеты, заявляющие локальный адрес источника. Заявить можно что угодно — проверяется это только маской.

`192.168.1.14` и `192.168.2.100` выглядят одинаково домашними. Один из них чужой.

## Приказ

Написать `artifacts/subnet.c`: по паре «адрес/префикс» вычислить маску, адрес сети, широковещательный адрес, диапазон и число пригодных хостов; проверить принадлежность двух адресов подсети.

## Дано

| Случай | Адрес |
|---|---|
| 1 | `192.168.1.100/24` |
| 2 | `10.0.0.5/8` |
| 3 | `172.16.3.9/20` |

Проверка принадлежности — для `192.168.1.254` и `192.168.2.100` относительно `192.168.1.0/24`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Маска строится из префикса; случай `/0` обработан **отдельно** — сдвиг на 32 недопустим.
- [ ] Сеть и широковещательный адрес получены битовыми операциями: `ip & mask` и `network | ~mask`.
- [ ] Число пригодных хостов равно `broadcast − network − 1` — два адреса заняты.
- [ ] Принадлежность проверяется как `(host & mask) == (subnet & mask)`, а не сравнением октетов.
- [ ] Все величины беззнаковые: `~mask` на знаковом типе даст расширение знака.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/subnet.c
make test
```

Ожидается: `/24 → 254`, `/8 → 16777214`, `/20 → 4094`; `.1.254 → yes`, `.2.100 → no`. Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| при `/0` маска равна исходному значению | сдвиг на 32 — UB, x86 берёт счётчик по модулю |
| хостов на два больше ожидаемого | не вычтены сеть и broadcast |
| broadcast равен адресу сети | забыто `| ~mask` |
| странные значения при `~mask` | маска объявлена знаковым типом |
| `.2.100` признан своим | сравниваются октеты, а не результат наложения маски |

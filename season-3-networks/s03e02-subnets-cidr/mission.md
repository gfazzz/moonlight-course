# Mission — s03e02 «Подсети и CIDR»

## Что сдать
`artifacts/subnet.c`: по паре адрес/CIDR вычисляет маску, адрес сети, broadcast, диапазон и число хостов; проверяет принадлежность адреса подсети.

## Дано
- Три случая: `192.168.1.100/24`, `10.0.0.5/8`, `172.16.3.9/20`.
- `mask = 0xFFFFFFFF << (32 - N)`; `network = ip & mask`; `broadcast = network | ~mask`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Маска, сеть, broadcast вычислены через битовые операции.
- [ ] Диапазон хостов: `network+1 .. broadcast-1`, число = `broadcast-network-1`.
- [ ] Принадлежность: `(host & mask) == network`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/subnet.c
make test
```

## Оценка времени
~35–40 минут.

## Результат в сюжете
Ты видишь, где твоя сеть, а где чужая. Если пакет пришёл «снаружи» твоей подсети, но выдаёт себя за «своего», — это первый признак подмены.

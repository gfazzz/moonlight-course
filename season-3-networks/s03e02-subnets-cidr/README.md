## Теория: маска и границы

```c
uint32_t mask = (N == 0) ? 0 : (0xFFFFFFFFu << (32 - N));  // /24 -> 255.255.255.0
uint32_t network   = ip & mask;         // хостовая часть обнулена
uint32_t broadcast = network | ~mask;   // хостовая часть — все единицы
```

Пригодные хосты: `network+1 .. broadcast-1`; их число = `broadcast - network - 1` (для `/24` — 254).

`<< 32` — неопределённое поведение, поэтому маску `/0` обрабатывают отдельно.

«Свой или чужой»:

```c
if ((host & mask) == (subnet & mask)) { /* одна подсеть */ }
```

Именно так хост решает — слать напрямую соседу или через шлюз наружу. И так ты ловишь подмену: «местный» адрес, не принадлежащий твоей подсети. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про границы.
```

**1.** LUNA: «`broadcast = network | ~mask`. Почему это "все хосты" подсети?»

<details><summary>Ответ</summary>

`~mask` — единицы в хостовой части. `network | ~mask` оставляет сетевую часть и ставит все хостовые биты в 1 — это и есть адрес «всем в подсети» (broadcast).
</details>

**2.** LUNA: «Как одной операцией понять, что `192.168.2.100` НЕ в `192.168.1.0/24`?»

<details><summary>Ответ</summary>

`(host & mask) == (subnet & mask)`. Для `/24` маска `255.255.255.0`: `192.168.2.100 & mask = 192.168.2.0 ≠ 192.168.1.0`. Значит — снаружи.
</details>

```
[LUNA] Верно. Считай подсети.
```

## Разбор типичных ошибок

1. **`<< 32` при `/0`.** UB. Обрабатывай маску `/0` отдельно (`mask = 0`).
2. **Забыл `~mask` для broadcast.** `network` — не broadcast; нужен `network | ~mask`.
3. **Число хостов включает сеть/broadcast.** Пригодных — `broadcast - network - 1`, не `+1`.
4. **Сравнение без маски.** `host == subnet` — неверно; нужно `(host & mask) == (subnet & mask)`.

## Debriefing

Границы сети проведены. Часть трафика к серверу Виктора приходит с адресов вне его подсети — но заголовки утверждают, что «свои». Кто-то подделывает источник. Чтобы поймать это, придётся читать пакеты байт в байт — а байты в сети лежат не так, как в памяти x86.

```
[LUNA] Заметил разницу? В пакете число 443 лежит как 0x01 0xBB, а не 0xBB 0x01.
[LUNA] Сеть — big-endian. Твой x86 — little-endian. Спутаешь — прочитаешь порт как 47873.
[LUNA] Порядок байтов. Дальше — s03e03. Без него весь разбор пакетов посыплется.
```

**Навык разблокирован:** маски, сеть/broadcast, диапазоны, «свой/чужой».

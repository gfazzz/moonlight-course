## Обстановка

Сканеры находят цели, демон их собирает. Общей памяти между ними нет — значит, данные идут через ядро.

Тот же механизм стоит за символом `|`, который вы набираете двадцать раз на дню.

## Приказ

Написать `artifacts/pipes.c`: двусторонний обмен между родителем и потомком через два канала плюс конвейер `echo | tr`, собранный вручную через `dup2`.

## Дано

- Сообщение потомку: `"SCAN 47 TARGETS"` — 15 байт.
- Ответ потомка: `"OK:<число прочитанных байт>"`.
- Конвейер: `/bin/echo "stealth agent online"` → `tr a-z A-Z`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Используются **два** канала: прямой и обратный.
- [ ] Каждая сторона закрывает неиспользуемые концы сразу после `fork()`.
- [ ] Писатель закрывает свой конец, чтобы читатель увидел конец потока.
- [ ] Чтение выполняется **в цикле**: `read` может вернуть меньше запрошенного.
- [ ] Потомок отвечает числом прочитанных байт; родитель сверяет его с длиной сообщения.
- [ ] Конвейер собран через `dup2` на стандартные потоки; лишние дескрипторы закрыты.
- [ ] Родитель закрывает **оба** конца конвейера перед ожиданием.
- [ ] Программа не зависает — тест обрывает её через 10 секунд.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/pipes.c
make test
```

Поучительная проверка: уберите одно закрытие пишущего конца у родителя. Программа повиснет молча, без ошибки и без диагностики — так выглядит самая частая ошибка с каналами.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| зависание на `read()` | не закрыт какой-то пишущий конец |
| прочитано меньше отправленного | `read` вызван один раз вместо цикла |
| процесс умер без сообщения | запись в канал, у которого нет читателей |
| потомок получает собственное сообщение | используется один канал вместо двух |
| правая часть конвейера не завершается | родитель не закрыл оба конца |
| конвейер печатает пусто | `dup2` выполнен после `exec` |

## После выполнения

Сканеры передают демону 180 килобайт сорок раз в секунду, и каждый байт копируется дважды. При этом в списке отображений демона есть разделяемый сегмент на тридцать два мегабайта.

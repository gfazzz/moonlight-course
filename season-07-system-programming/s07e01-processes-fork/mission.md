## Обстановка

`surveillance_d` держит трёх потомков. Убивать их по одному бесполезно — родитель порождает новых.

Прежде чем ломать чужой механизм, надо построить свой.

## Приказ

Написать `artifacts/fork.c`: породить процесс-потомок, доказать родство, дождаться его через `waitpid()`, снять код возврата и показать, что память после раздвоения раздельна.

## Дано

- Код возврата потомка — `7`.
- Начальное значение `x` — `100`; потомок его меняет.
- Все проверки печатаются как **свойства** — «да» или «нет», а не значения.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] `fflush(stdout)` вызывается **до** `fork()`.
- [ ] Возврат `fork()` проверяется на `-1`.
- [ ] Потомок завершается через `_exit()`, не `exit()`.
- [ ] Родитель ждёт **именно своего** потомка: `waitpid(rc, ...)`, а не `wait()`.
- [ ] Статус разбирается через `WIFEXITED` и `WEXITSTATUS`, а не читается напрямую.
- [ ] Показано, что изменение `x` в потомке родителю не видно.
- [ ] **Ни один идентификатор процесса не печатается.**
- [ ] Вывод совпадает с `tests/expected.txt` и одинаков между запусками.
- [ ] `make test` → `PASS` (тест прогоняет программу дважды).

## Выполнение

```bash
cp starter.c artifacts/fork.c
make test
```

Поучительная проверка: уберите `fflush` и перенаправьте вывод в файл. На экране всё выглядело правильно — в файле строки задвоятся.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| второй прогон не совпал с первым | в выводе есть идентификатор процесса |
| строки задвоились при перенаправлении | нет `fflush` перед `fork()` |
| код возврата вышел странным числом | `status` прочитан напрямую |
| у родителя `x` изменился | код потомка выполняется в обеих ветвях |
| программа зависла | ожидается потомок, который не был порождён |
| в системе накапливаются зомби | статус потомка не забирается |

## После выполнения

Потомки в дереве противника называются **не так**, как родитель. Копия сама себя не переименовывает — значит, после раздвоения происходит что-то ещё.

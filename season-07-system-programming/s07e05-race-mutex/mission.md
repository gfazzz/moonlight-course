## Обстановка

Счётчик найденных узлов у `tracker` каждый прогон показывает разное при одинаковой работе. Шестнадцать потоков увеличивают общую переменную без защиты.

Сначала это надо увидеть своими глазами, потом починить.

## Приказ

Написать `artifacts/race.c`: воспроизвести потерю обновлений на общем счётчике и устранить её мьютексом. В стандартный поток — только инварианты, плавающие числа — в поток ошибок.

## Дано

- 4 потока × 200000 увеличений; ожидаемый итог — `800000`.
- Два счётчика: незащищённый и под `pthread_mutex_t`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11 -pthread` без предупреждений.
- [ ] Увеличение разложено на чтение и запись (`tmp = c; c = tmp + 1;`) — окно гонки видно явно.
- [ ] Защищённая версия оборачивает критическую секцию в `pthread_mutex_lock` и `pthread_mutex_unlock`.
- [ ] `unlock` выполняется на **всех** путях выхода из секции.
- [ ] Итог под мьютексом **в точности** равен `800000`.
- [ ] Проверяется инвариант незащищённой версии: итог **не больше** ожидаемого.
- [ ] В стандартном потоке нет ни одного плавающего значения; фактические числа идут в поток ошибок.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (шесть прогонов).

## Выполнение

```bash
cp starter.c artifacts/race.c
make test        # проверка инвариантов
make race        # пять запусков подряд — увидеть разброс своими глазами
```

Дополнительно: пересоберите задачу с `-fsanitize=thread`. Санитайзер укажет на конкретную строку — даже если в этом запуске гонка не проявилась.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| тест падает через раз | плавающее число попало в стандартный поток |
| незащищённый итог равен ожидаемому | увеличение не разложено, окно гонки не открылось |
| незащищённый итог **больше** ожидаемого | ошибка в логике: гонка может только терять |
| программа зависла | `unlock` пропущен на одном из путей выхода |
| защищённая версия медленнее в разы | блокировка захвачена вокруг всего цикла |
| «гонки нет, всё сходится» | окно не открылось; проверьте санитайзером |

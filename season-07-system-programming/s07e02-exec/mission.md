## Обстановка

`surveillance_d` запускает сканер каждые тридцать секунд. Механизм — раздвоение плюс подмена образа; за полгода это около полумиллиона запусков.

## Приказ

Написать `artifacts/exec.c`: функция `run()` на связке `fork` + `exec` + `waitpid`, запуск внешних программ, снятие кодов возврата, корректная обработка неудачного запуска.

## Дано

- `/bin/echo` — успешный запуск.
- `/bin/sh -c "exit 3"` — ненулевой код возврата.
- `/nonexistent/tracker` — путь, которого нет.

Соглашения оболочки: `127` — команда не найдена, `126` — файл не исполняемый, `128 + N` — убит сигналом `N`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] `run()` выполняет `fflush` → `fork` → `execv` в потомке → `waitpid` в родителе.
- [ ] После `execv` в потомке стоит `_exit(127)`; строка достижима **только** при провале.
- [ ] Массив аргументов завершается `NULL`, первый элемент — имя программы.
- [ ] Разбираются оба исхода: `WIFEXITED` и `WIFSIGNALED` (`128 + WTERMSIG`).
- [ ] Доказано, что при успешном `exec` код после него не выполняется.
- [ ] Провал `execv` не убивает процесс: возвращает `-1`, ставит `errno == ENOENT`, работа продолжается.
- [ ] Идентификаторы процессов не печатаются.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (прогон дважды).

## Выполнение

```bash
cp starter.c artifacts/exec.c
make test
```

Поучительная проверка: уберите `_exit(127)` после `execv` и запустите на несуществующем пути. Вывод удвоится — потомок продолжит выполнять код родителя.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| вывод удвоился | нет `_exit()` после `exec` |
| мусор в аргументах запущенной программы | массив не завершён `NULL` |
| код возврата кратен 256 | `status` прочитан напрямую |
| программа завершилась при провале запуска | провал `exec` обработан как фатальный |
| запустилось не то, что ожидалось | использован вариант с поиском по `PATH` |
| второй прогон не совпал | в выводе есть идентификатор процесса |

## Теория: нейрон и его граница

### Устройство

```
z = w1·x1 + w2·x2 + b        /* линейная часть   */
p = sigmoid(z)               /* нелинейность     */
```

Веса задают наклон разделяющей прямой, смещение — её сдвиг. Сигмоида превращает любое число в промежуток `(0, 1)`.

Без нелинейности нейрон был бы обычной регрессией, а стопка таких слоёв схлопывалась бы в одну линейную функцию — глубина не давала бы ничего.

### Кросс-энтропия и её градиент

```
L = −[ y·ln(p) + (1−y)·ln(1−p) ]
```

Производная по `z`, с учётом `dp/dz = p(1−p)`, сокращается до

```
dL/dz = p − y
```

Множители из производной сигмоиды и знаменатели из логарифма взаимно уничтожаются. Отсюда:

```
dL/dw_i = (p − y) · x_i
dL/db   = (p − y)
```

### Почему не квадратичная ошибка

| | Кросс-энтропия | Квадратичная ошибка |
|---|---|---|
| градиент по `z` | `p − y` | `(p − y)·p(1−p)` |
| при насыщении сигмоиды | не меняется | **стремится к нулю** |
| уверенная ошибка | сильная коррекция | почти никакой |

Вторая строка — приговор. Модель, уверенно ошибающаяся (`p` близко к нулю там, где ответ единица), получает при квадратичной ошибке почти нулевой градиент и перестаёт учиться именно тогда, когда учиться нужнее всего.

### Предел

Нейрон задаёт **одну прямую** `w1·x1 + w2·x2 + b = 0`.

| Функция | Разделима прямой |
|---|---|
| конъюнкция | да |
| дизъюнкция | да |
| исключающее «или» | **нет** |

Классы исключающего «или» лежат по диагоналям квадрата. Прямой, разделяющей их, не существует — это геометрический факт, а не свойство алгоритма обучения.

## Проверка: LUNA задаёт вопросы
```
[LUNA] Два вопроса про нейрон.
```

**1.** LUNA: «Почему для классификации берут кросс-энтропию, а не квадратичную ошибку?»

<details><summary>Ответ</summary>

Потому что производная сигмоиды содержит множитель `p(1−p)`, который стремится к нулю при насыщении — когда `p` близко к нулю или единице. При квадратичной ошибке этот множитель остаётся в градиенте, и модель, ошибающаяся уверенно, получает почти нулевую коррекцию: обучение застревает именно в худшем для себя состоянии. В кросс-энтропии он сокращается, остаётся `(p − y)`, и чем увереннее ошибка, тем сильнее шаг. Функция потерь выбирается не по вкусу, а по тому, какой градиент она даёт вместе с выбранной нелинейностью.
</details>

**2.** LUNA: «Исключающее "или" дало ровно 50 %, а веса обнулились. Это ошибка обучения?»

<details><summary>Ответ</summary>

Нет, это математический предел модели. Один нейрон проводит одну прямую, а классы расположены по диагоналям квадрата — разделяющей прямой не существует. Спуск отработал честно и нашёл настоящий оптимум: симметричное решение, дающее `p = 0.5` на всех входах, минимизирует суммарные потери лучше любого несимметричного. Нулевые веса здесь — не признак поломки, а признак того, что модель исчерпала свои возможности. Нужен скрытый слой.
</details>

```
[LUNA] Верно. Обучай.
```

## Разбор типичных ошибок

1. **50 % на исключающем «или» принимается за ошибку кода.** Это ожидаемый результат.
2. **Квадратичная ошибка вместо кросс-энтропии.** Обучение застревает при насыщении.
3. **Градиент не усреднён по числу примеров.** Шаг зависит от размера выборки.
4. **`exp` берётся из библиотеки.** Расхождение в последнем бите ломает воспроизводимость.
5. **Порог классификации взят не `0.5`.** Результат перестанет соответствовать эталону.
6. **Веса инициализированы нулями.** Для одного нейрона это работает, для сети — нет.

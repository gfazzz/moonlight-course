## 1. Искусственный нейрон

> *— Нейрон делает две вещи: складывает и решает. Складывает линейно, решает нелинейно. Уберите вторую — и сколько бы вы их ни сложили, получится одна прямая.*

```
z = w1·x1 + w2·x2 + b        /* линейная часть */
p = sigmoid(z)               /* нелинейность   */
```

Веса задают наклон разделяющей прямой, смещение — её сдвиг относительно начала координат. Без смещения граница обязана проходить через ноль, что резко сужает круг решаемых задач.

```
sigmoid(z) = 1 / (1 + e^(−z))
```

Свойства, из-за которых она стала стандартом на десятилетия:

| Свойство | Значение |
|---|---|
| область значений `(0, 1)` | выход читается как вероятность |
| монотонность | порядок входов сохраняется |
| гладкость | производная существует везде |
| `dp/dz = p(1 − p)` | производная выражается через сам выход |

Последняя строка практична: при обратном проходе не нужно хранить `z`, достаточно уже посчитанного `p`.

**Зачем нелинейность вообще.** Композиция линейных функций линейна. Стопка из десяти линейных слоёв эквивалентна одному — глубина не даёт ничего. Нелинейность между слоями — единственная причина, по которой глубокие сети имеют смысл.

## 2. Кросс-энтропия и красивое сокращение

```
L = −[ y·ln(p) + (1−y)·ln(1−p) ]
```

При `y = 1` остаётся `−ln(p)`: чем ближе `p` к единице, тем меньше потери. При `y = 0` — симметрично.

Производная по `z`:

```
dL/dp = −y/p + (1−y)/(1−p) = (p − y) / (p(1−p))
dp/dz = p(1 − p)
dL/dz = (p − y) / (p(1−p)) · p(1−p) = p − y
```

Множитель `p(1−p)` сокращается полностью. Это не совпадение: кросс-энтропия и сигмоида — сопряжённая пара, выведенная из одной модели (обобщённая линейная модель с биномиальным распределением). Простота результата — признак того, что выбраны согласованные части.

## 3. Почему квадратичная ошибка здесь плоха

| | Кросс-энтропия | Квадратичная ошибка |
|---|---|---|
| `dL/dz` | `p − y` | `(p − y) · p(1−p)` |
| при `p → 0` или `p → 1` | не меняется | **стремится к нулю** |
| уверенная ошибка | максимальная коррекция | почти никакой |
| выпуклость по `w` | да | **нет** |

Первые три строки описывают **насыщение**: модель, уверенно давшая `p = 0.001` там, где ответ единица, получает при квадратичной ошибке градиент порядка `0.001` и практически перестаёт учиться. Обучение застревает ровно в том состоянии, из которого важнее всего выбраться.

Четвёртая строка добавляет: квадратичная ошибка в сочетании с сигмоидой не выпукла по весам, то есть допускает локальные минимумы даже у одного нейрона.

Общий вывод: **функция потерь выбирается не отдельно, а в паре с выходной нелинейностью**. Сигмоида — с бинарной кросс-энтропией, softmax — с многоклассовой, линейный выход — с квадратичной.

## 4. Линейная разделимость

Нейрон задаёт одну гиперплоскость `w·x + b = 0` и делит пространство надвое.

| Функция | Разделима | Почему |
|---|---|---|
| конъюнкция | да | `{(1,1)}` отделяется от трёх остальных |
| дизъюнкция | да | `{(0,0)}` отделяется от трёх остальных |
| исключающее «или» | **нет** | классы лежат по диагоналям |

Доказательство от противного занимает три строки. Пусть прямая существует; тогда `b < 0` (точка `(0,0)` в классе 0), `w1 + b > 0` и `w2 + b > 0` (точки `(1,0)` и `(0,1)` в классе 1), откуда `w1 + w2 + 2b > 0`, то есть `w1 + w2 + b > −b > 0`. Но точка `(1,1)` должна быть в классе 0, что требует `w1 + w2 + b < 0`. Противоречие.

Из четырнадцати булевых функций двух переменных линейно неразделимы ровно две: исключающее «или» и его отрицание. С ростом размерности доля разделимых функций стремительно падает — при `n` входах их порядка `2^(n²)` из `2^(2ⁿ)`.

**Почему обученные веса нулевые.** Симметричное решение `p = 0.5` на всех входах даёт суммарные потери `4·ln 2 ≈ 2.77`. Любое смещение границы улучшает две точки и ровно настолько же ухудшает две другие. Ноль — настоящий минимум, и спуск находит именно его.

## 5. Первая зима

Розенблатт построил перцептрон в 1958 году; пресса писала об электронном мозге, финансирование шло щедро.

В 1969-м Минский и Паперт опубликовали «Перцептроны» со строгим доказательством: однослойный перцептрон не вычисляет чётность, связность и ряд других функций. Математика была безупречна и не опровергнута до сих пор.

Дальше произошло то, что стоит запомнить отдельно: **ограничение было точным, а вывод из него — нет**. Доказательство касалось одного слоя; читатели распространили его на всё направление. Финансирование обрушилось, и наступила первая зима искусственного интеллекта.

Многослойная архитектура была известна и тогда. Не хватало способа её обучать: у скрытого слоя нет целевого значения, и непонятно, к чему приводить его выход.

Ответ лежал в цепном правиле — теореме из первого курса анализа. Работы в этом направлении велись с семидесятых (Линнайнмаа, 1970; Вербос, 1974), но широкую известность метод получил только в 1986 году после статьи Румельхарта, Хинтона и Уильямса. Семнадцать лет между доказательством предела и его обходом.

## 6. Почему `exp` написан вручную

Библиотечная реализация может отличаться в последнем бите между платформами, версиями компилятора и уровнями оптимизации — тогда вывод перестаёт быть побитово воспроизводимым.

Наша реализация:

1. приводит аргумент делением пополам до `|x| ≤ 0.5`;
2. считает фиксированные 16 членов ряда Тейлора;
3. возводит результат в квадрат `k` раз, используя `e^x = (e^(x/2^k))^(2^k)`.

Фиксированное число операций даёт одинаковый результат везде. Та же дисциплина, что со своим `sqrt` в Season 5 и своим генератором в Season 7.

Приведение аргумента существенно: ряд Тейлора для `exp` сходится при любом `x`, но при больших аргументах промежуточные члены огромны, и катастрофическое вычитание съедает точность — та же беда, что в s08e01.

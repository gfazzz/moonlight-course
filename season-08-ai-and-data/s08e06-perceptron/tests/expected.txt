нейрон: p = sigmoid(w1*x1 + w2*x2 + b), обучение 20000 эпох, lr = 0.5

--- AND (линейно разделим) ---
  вход (0,0): p = 0.000 -> 0, ожидалось 0 
  вход (0,1): p = 0.002 -> 0, ожидалось 0 
  вход (1,0): p = 0.002 -> 0, ожидалось 0 
  вход (1,1): p = 0.997 -> 1, ожидалось 1 
  веса: w1 = +12.075, w2 = +12.075, b = -18.281
  верно: 4 из 4 (100%)

--- OR  (линейно разделим) ---
  вход (0,0): p = 0.002 -> 0, ожидалось 0 
  вход (0,1): p = 0.999 -> 1, ожидалось 1 
  вход (1,0): p = 0.999 -> 1, ожидалось 1 
  вход (1,1): p = 1.000 -> 1, ожидалось 1 
  веса: w1 = +13.331, w2 = +13.331, b = -6.207
  верно: 4 из 4 (100%)

--- XOR (НЕ разделим прямой) ---
  вход (0,0): p = 0.500 -> 1, ожидалось 0   <-- ошибка
  вход (0,1): p = 0.500 -> 1, ожидалось 1 
  вход (1,0): p = 0.500 -> 1, ожидалось 1 
  вход (1,1): p = 0.500 -> 1, ожидалось 0   <-- ошибка
  веса: w1 = -0.000, w2 = -0.000, b = +0.000
  верно: 2 из 4 (50%)

вывод: один нейрон задаёт одну прямую. AND и OR ею разделяются, XOR — нет.
       это предел перцептрона (Минский и Паперт, 1969) — нужен скрытый слой.

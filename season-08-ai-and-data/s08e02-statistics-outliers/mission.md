## Обстановка

Двадцать замеров задержки. Среднее — 151 миллисекунда, медиана — 45. Втрое.

Отсечь аномалии правилом трёх сигм не выйдет: сигма посчитана по данным, содержащим эти самые аномалии.

## Приказ

Написать `artifacts/stats.c`: посчитать неустойчивые и устойчивые оценки, найти выбросы правилом Тьюки и правилом `z`, показать разницу между ними.

## Дано

- 20 замеров задержки в миллисекундах; два последних — аномалии (`980`, `1250`).
- Правило Тьюки: выброс вне `[Q1 − 1.5·IQR, Q3 + 1.5·IQR]`.
- Квантиль — с линейной интерполяцией по позиции `q·(n−1)`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**: `sqrt` реализован вручную.
- [ ] Квантили считаются по отсортированной **копии**; исходный массив не изменяется.
- [ ] Медиана `45.00`, Q1 `43.00`, Q3 `46.25`, размах `3.25`.
- [ ] Медиана учитывает чётность числа наблюдений.
- [ ] Правило Тьюки находит **оба** выброса и печатает их индексы в исходном массиве.
- [ ] Правило `|z| > 3` находит только один — и это показано как свойство метода.
- [ ] Показан разрыв между средним и медианой: `106.55` мс.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/stats.c
make test
```

Поучительная проверка: уберите из выборки значение `1250` и пересчитайте `z` для `980`. Оно немедленно станет выбросом — потому что перестало маскироваться соседом.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| индексы выбросов не соответствуют данным | отсортирован исходный массив |
| медиана смещена на полшага | не учтена чётность числа наблюдений |
| квартили не совпали с ожидаемыми | использован другой метод вычисления квантиля |
| `z` нашёл оба выброса | сигма посчитана по очищенным данным |
| правило Тьюки не нашло ничего | перепутаны местами `Q1` и `Q3` |
| ошибка компоновки на `sqrt` | подключён `-lm` вместо собственной реализации |

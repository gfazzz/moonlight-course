# Теория — s08e02

## 1. Точка пробоя

> *— У любой оценки есть цена, которую надо заплатить, чтобы заставить её врать. У среднего эта цена — одно число. Прежде чем доверять метрике, спроси, сколько стоит её сломать.*

**Точка пробоя** — доля испорченных наблюдений, при которой оценка перестаёт быть осмысленной.

| Оценка | Точка пробоя | Комментарий |
|---|---|---|
| среднее | 0 % | одно значение уводит куда угодно |
| стандартное отклонение | 0 % | хуже среднего: отклонения в квадрате |
| медиана | **50 %** | зависит от порядка, не от величин |
| межквартильный размах | 25 % | хвосты не влияют |
| усечённое среднее (10 %) | 10 % | компромисс между устойчивостью и эффективностью |

Нулевая точка пробоя не означает, что среднее плохо. Она означает, что среднее применимо только к данным, чистота которых установлена независимо.

Обратная сторона: у устойчивых оценок ниже **эффективность**. На чистых нормальных данных медиана использует информацию хуже среднего — её дисперсия примерно в 1.57 раза больше. Плата за устойчивость реальна, и потому усечённое среднее популярно как середина.

## 2. Квантили

Квантиль уровня `q` — значение, ниже которого лежит доля `q` наблюдений. Квартили: `Q1 = 0.25`, медиана `= 0.5`, `Q3 = 0.75`.

**Размах `IQR = Q3 − Q1`** описывает разброс средней половины данных, не касаясь хвостов.

Тонкость, которая регулярно портит сравнение результатов: **способов вычисления квантиля больше девяти**. Они расходятся в том, как интерполировать между соседними наблюдениями и как обрабатывать края.

В задаче используется линейная интерполяция по позиции `q·(n−1)` — вариант по умолчанию в `numpy.percentile`. Поэтому числа на C и в Python совпадут; при сравнении с R или другой библиотекой сначала сверьте метод, иначе расхождение спишете на ошибку в коде.

## 3. Правило Тьюки

```
lower = Q1 − 1.5·IQR
upper = Q3 + 1.5·IQR
```

Коэффициент `1.5` не следует из теории. Тьюки подобрал его так, чтобы для нормального распределения за границы выходило около 0.7 % наблюдений — редко, но не исчезающе редко. Множитель `3.0` применяется для экстремальных выбросов.

Правило породило ящик с усами: коробка — от `Q1` до `Q3`, линия внутри — медиана, усы — до крайних значений внутри границ, точки за усами — выбросы. График читается за секунду и не требует предположения о нормальности.

## 4. Маскировка

```
z = (x − mean) / sd
```

И числитель, и знаменатель посчитаны по данным **вместе с выбросами**. Каждая аномалия сдвигает среднее в свою сторону и раздувает стандартное отклонение — порог уезжает вслед за ней.

Численно в задаче:

```
sd = 332.40
z(980)  = (980  − 151.55) / 332.40 = 2.49   -> не выброс
z(1250) = (1250 − 151.55) / 332.40 = 3.30   -> выброс
```

Два выброса замаскировали друг друга наполовину. Чем их больше, тем хуже работает правило, которое должно их ловить, — зависимость строго обратная нужной.

Есть и парный эффект — **затопление** (swamping): выброс настолько сдвигает среднее, что нормальные наблюдения с противоположной стороны начинают выглядеть аномальными.

Устойчивая замена в том же духе:

```
MAD   = median(|xᵢ − median|)
z_mod = 0.6745 · (x − median) / MAD
```

Порог обычно 3.5. Множитель `0.6745` — квантиль уровня 0.75 стандартного нормального распределения; он приводит `MAD` к шкале стандартного отклонения, чтобы порог читался привычно.

Ограничение `MAD`: если больше половины данных одинаковы, `MAD` обращается в ноль, и оценка теряет смысл. Для дискретных данных с малым числом уровней применяют другие масштабы.

## 5. Выброс — не мусор

Аномалия бывает трёх типов, и обращаться с ними надо по-разному:

| Тип | Пример | Что делать |
|---|---|---|
| ошибка измерения | датчик выдал `-999` | удалить, зафиксировав факт |
| редкое, но реальное событие | всплеск объёма перед новостью | **сохранить**, это сигнал |
| смена режима | сервер переехал в другой дата-центр | разделить выборку |

Различить их статистикой нельзя — нужен контекст. Отсюда практика: **помечать, а не удалять**, и разбираться в причине каждой пачки аномалий.

История знает дорогие примеры. Озоновую дыру над Антарктидой спутниковые данные показывали с конца семидесятых, но алгоритм обработки отбраковывал слишком низкие значения как заведомо невозможные. Дыру обнаружили наземными измерениями в 1985 году; данные всё это время лежали в архиве, помеченные как ошибочные.

Третье правило: **порог отсечения выбирается до того, как увидены данные**. Подбор порога под желаемый результат — это не очистка данных, а их подгонка, и она ничем не отличается от подгонки стратегии в s05e05.

## 6. Python как компаньон

```python
q1, q3 = np.percentile(x, [25, 75])
iqr = q3 - q1
mask = (x < q1 - 1.5*iqr) | (x > q3 + 1.5*iqr)
```

Плюс `seaborn.boxplot(x)` — и картина видна целиком.

Для разведочного анализа это несравнимо удобнее. Возврат к C происходит там, где те же метрики нужно считать на потоке в миллионы событий в секунду — и тогда вместе с однопроходными алгоритмами из s08e01 и приближёнными структурами для квантилей.

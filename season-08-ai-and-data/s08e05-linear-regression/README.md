## Теория: шаг против градиента

### Три части

| Часть | В этой задаче |
|---|---|
| модель | `pred = w·x + b` |
| функция потерь | `MSE = (1/N)·Σ(pred − y)²` |
| правило обновления | шаг против градиента |

Среднеквадратичная ошибка выбрана не случайно: она гладкая (производная существует везде) и выпуклая по параметрам — минимум **один**, локальных ловушек нет.

Обратная сторона квадрата — сильный штраф за крупные ошибки, то есть чувствительность к выбросам. Ровно то, о чём была s08e02.

### Градиенты

```
dMSE/dw = (2/N)·Σ (pred − y)·x
dMSE/db = (2/N)·Σ (pred − y)

w ← w − lr · dMSE/dw
b ← b − lr · dMSE/db
```

Вывод для `w`: производная `(pred − y)²` равна `2(pred − y)` умножить на производную `pred` по `w`, а она равна `x`. Для `b` производная `pred` равна единице — отсюда формула без множителя.

Это **тот же алгоритм**, который обучает нейросети. Разница только в том, что там производные считаются по цепному правилу через слои.

### Скорость обучения

| Значение | Что происходит |
|---|---|
| слишком мала | сходимся, но за тысячи лишних эпох |
| в самый раз | быстрая устойчивая сходимость |
| слишком велика | шаг перелетает минимум, ошибка растёт, значения уходят в бесконечность |

Третья строка — не «учимся хуже», а качественно другое поведение. Шаг перелетает минимум и оказывается дальше от него, чем был; следующий градиент больше, шаг длиннее — процесс раскручивается.

Для квадратичной ошибки существует точный порог устойчивости, выше которого расходимость гарантирована.

### Точное решение

```
w = (N·Σxy − Σx·Σy) / (N·Σxx − (Σx)²)
b = (Σy − w·Σx) / N
```

Для прямой ответ можно получить формулой. Задача это использует как проверку: спуск обязан сойтись ровно к нему.

## Проверка на канале

```
[LUNA] Два вопроса про обучение.
```

**1.** LUNA: «Для прямой есть точная формула. Зачем тогда спуск?»

<details><summary>Ответ</summary>

Потому что точное решение в общем виде требует обращения матрицы — это `O(d³)` по числу признаков, и при тысячах признаков становится неподъёмным. Кроме того, матрица бывает вырожденной при коллинеарных признаках, данные могут не помещаться в память, а для нелинейных моделей точной формулы не существует вовсе. Спуск универсален: он требует только умения посчитать градиент, а это возможно всегда, когда модель дифференцируема. Точная формула для прямой — приятное исключение, а не правило.
</details>

**2.** LUNA: «При `lr = 1.0` ошибка не просто падает медленно, а взрывается. Почему?»

<details><summary>Ответ</summary>

Потому что шаг перелетает минимум и оказывается **дальше** от него, чем был. В следующей точке градиент больше, значит, и шаг длиннее — процесс раскручивается, и значения уходят в бесконечность за десяток итераций. Это не «плохо настроенное обучение», а качественно другой режим: для квадратичной ошибки существует порог, выше которого спуск расходится всегда, независимо от данных и начальной точки.
</details>

```
[LUNA] Верно. Обучай.
```

## Разбор типичных ошибок

1. **Знак обновления.** `w += lr·grad` уводит вверх по ошибке.
2. **Забыт множитель `x` в градиенте по `w`.** По `b` его нет, по `w` есть.
3. **`w` обновляется до вычисления градиента по `b`.** Оба считаются по одному состоянию модели.
4. **Скорость обучения подбирается наугад.** Начните с малой и следите за ошибкой.
5. **Признаки не нормированы.** При больших `x` градиент огромен, и шаг приходится делать крошечным.
6. **Ошибка не логируется.** Расходимость обнаружится только в конце обучения.

## Python как компаньон

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)
```

Одна строка, и внутри тот же метод наименьших квадратов.

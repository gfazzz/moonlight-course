## Теория: протащить ошибку назад

### Прямой ход

```
h_j = s(Σ w1[i][j]·x_i + b1_j)
out = s(Σ w2_j·h_j + b2)
```

Скрытый слой строит по прямой на каждый нейрон и переводит вход в новое пространство. Выходной нейрон ищет разделяющую прямую уже там.

### Обратный ход

```
d_out = out − y
d_h_j = d_out · w2_j · h_j·(1 − h_j)
```

| Множитель | Смысл |
|---|---|
| `d_out` | насколько ошибся выход |
| `w2_j` | насколько сильно этот нейрон влиял на выход |
| `h_j·(1 − h_j)` | производная активации: насколько нейрон чувствителен |

### Градиенты

```
dw2_j     = d_out · h_j        db2   = d_out
dw1[i][j] = d_h_j · x_i        db1_j = d_h_j
```

Порядок существенен: `d_h` считается по **старым** `w2`. Обновление выходного слоя до вычисления `d_h` даёт неверный градиент скрытого.

### Почему это дёшево

Обратный ход переиспользует значения `h_j`, посчитанные на прямом. Поэтому обучение стоит примерно вдвое дороже предсказания, независимо от числа параметров.

Численное дифференцирование потребовало бы отдельного прогона сети на каждый вес — для миллиона параметров это миллион прогонов на шаг.

## Проверка: LUNA задаёт вопросы
```
[LUNA] Два вопроса про обучение слоёв.
```

**1.** LUNA: «Что будет, если инициализировать все веса нулями?»

<details><summary>Ответ</summary>

Все скрытые нейроны получат одинаковый вход, дадут одинаковую активацию, получат одинаковый градиент и обновятся одинаково. Они навсегда останутся точными копиями друг друга, и сеть из четырёх скрытых нейронов будет вести себя как сеть из одного — то есть снова не решит задачу. Это называется проблемой симметрии, и лечится она тем, что веса стартуют разными: случайными в реальных сетях или, как здесь, фиксированными несимметричными числами ради воспроизводимости. Смещения нулями инициализировать при этом можно — симметрию ломают именно веса.
</details>

**2.** LUNA: «Для этой задачи теоретически хватает двух скрытых нейронов. Почему их четыре?»

<details><summary>Ответ</summary>

Потому что поверхность ошибки невыпуклая, и спуск застревает в локальных минимумах. Замер на 200 инициализациях при прочих равных: с двумя нейронами обучение сходится лишь в 59 % запусков, с тремя — в 92 %, с четырьмя — практически всегда. В неудачных случаях потери замирают на `0.125` — это ровно одна восьмая, состояние с «мёртвыми» скрытыми нейронами. Практический вывод шире задачи: избыточная ширина упрощает оптимизацию, даже когда минимальной ёмкости формально достаточно, и потому реальные сети всегда шире теоретического минимума.
</details>

## Разбор типичных ошибок

1. **Одинаковые стартовые веса.** Нейроны остаются копиями, сеть вырождается в один.
2. **Забыт множитель `h·(1−h)`.** Без производной активации градиент неверен.
3. **`w2` обновлён до вычисления `d_h`.** Скрытый слой получит градиент по новым весам.
4. **75 % считается нормальным результатом.** Это застревание, а не предел модели.
5. **Смещения не обновляются.** Сеть сможет меньше, чем должна.
6. **Потери не логируются.** Застревание обнаружится только в конце.

## Python как компаньон

```python
model = nn.Sequential(nn.Linear(2, 4), nn.Sigmoid(), nn.Linear(4, 1), nn.Sigmoid())
loss.backward()      # граф строится и дифференцируется автоматически
```

PyTorch делает ровно то, что вы написали руками, — только для произвольного графа вычислений.

Написав обратное распространение на C, вы понимаете, что происходит за `backward()`: почему нужен `zero_grad()` (градиенты накапливаются, а не заменяются), откуда берутся `NaN` (переполнение в экспоненте), почему глубокая сеть с сигмоидами не учится.

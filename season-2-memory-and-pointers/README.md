# Season 2 — Memory & Pointers

**Память и указатели через memory-форензику. 8 коротких серий, ~5 часов.**

> *«Знать, где хранится информация, — половина успеха».*

Виктор жив. Его подсказка — «дальше ПАМЯТЬ» — сбывается быстро: враги нашли тебя по адресу, утёкшему в дампе памяти. Чтобы понять, что именно утекло, и обезвредить троян агентов Z., который топит память утечками, ты разбираешь дамп, ходишь по указателям, берёшь и растишь память в куче — и учишься чинить утечки инструментом. В конце последний лог отдаёт координаты: Красная площадь. Виктор ждёт лично.

## Как проходить

Оболочка — **Cursor в режиме IDE**; LUNA из сюжета = чат Cursor. Спрашивай «почему», а не «сделай».

```bash
cd s02e01-memory-map
cat README.md
cp starter.c artifacts/memmap.c
make test                # зелёный тест = серия пройдена
# из корня сезона: make test — прогон всех 8 серий
```

Серии e05–e08 проверяют не только вывод, но и **чистоту памяти** через `-fsanitize=address` (LeakSanitizer) — без внешнего valgrind. Эталон в `solution/` открывай после честной попытки.

## Season Project: `memory_manager`

Артефакты серий складываются в инструмент сезона: парсер дампа, навигатор по указательным цепочкам, динамический буфер (malloc/realloc) и leak-detector. Переиспользуется в следующих сезонах через `#include`.

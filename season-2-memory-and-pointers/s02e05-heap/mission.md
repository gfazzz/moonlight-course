# Mission — s02e05 «Куча»

## Что сдать
`artifacts/heap.c`: выделяет массив на `n` элементов в куче через `malloc`, заполняет, считает сумму и освобождает через `free`.

## Дано
- `n` (размер, «как из рантайма»).
- `malloc`, `free` из `<stdlib.h>`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `malloc(n * sizeof(int))` — размер в байтах; результат проверен на `NULL`.
- [ ] Массив заполнен и просуммирован.
- [ ] `free(buf)` вызван; после — `buf = NULL`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.
- [ ] (Бонус) `-fsanitize=leak` не находит утечек.

## Как проверить
```bash
cp starter.c artifacts/heap.c
make test
```

## Оценка времени
~30–40 минут.

## Результат в сюжете
Ты берёшь память под данные, размер которых заранее неизвестен, — и аккуратно возвращаешь её. Дальше архив будет расти на ходу.

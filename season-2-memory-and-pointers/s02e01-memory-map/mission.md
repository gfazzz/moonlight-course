# Mission — s02e01 «Карта памяти»

## Что сдать
`artifacts/memmap.c`: печатает размеры базовых типов (`sizeof`) и показывает, что элементы массива `int` лежат в памяти непрерывно (разрыв адресов = `sizeof(int)`).

## Дано
- Массив `int arr[5]` и переменная `int x`.
- Операторы `&` (адрес) и `sizeof` (размер).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Размеры типов печатаются через `sizeof` со спецификатором `%zu`.
- [ ] Разрыв адресов соседних элементов вычислен как `(char*)&arr[i+1] - (char*)&arr[i]`.
- [ ] Проверена непрерывность всех элементов (цикл).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/memmap.c
make test
```

> Заметка: вывод детерминирован на x86-64 (платформа автотеста). На других архитектурах размеры типов могут отличаться — это нормально и обсуждается в `theory.md`.

## Оценка времени
~25–30 минут.

## Результат в сюжете
Ты понял, как данные разложены в памяти по адресам. Теперь ясно, как твоя геопозиция могла «утечь» в дампе — и как её оттуда достать.

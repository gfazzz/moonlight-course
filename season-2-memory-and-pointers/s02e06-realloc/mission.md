# Mission — s02e06 «realloc»

## Что сдать
`artifacts/grow.c`: динамический массив, который растёт через `realloc` (удвоение ёмкости) по мере добавления элементов.

## Дано
- Стартовая ёмкость 1; добавляем значения `i*i` для `i = 1..10`.
- `realloc` из `<stdlib.h>`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] При заполнении (`len == cap`) ёмкость удваивается через `realloc`.
- [ ] Результат `realloc` пишется во **временный** указатель; при `NULL` старый блок освобождается.
- [ ] В конце — один `free`.
- [ ] Вывод совпадает с `tests/expected.txt` (`grow -> 2,4,8,16`; `sum=385`).
- [ ] `make test` → `PASS` (и LSan без утечек).

## Как проверить
```bash
cp starter.c artifacts/grow.c
make test
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Буфер растёт под данные на ходу — архив MOONLIGHT загружается целиком, каким бы большим он ни был.

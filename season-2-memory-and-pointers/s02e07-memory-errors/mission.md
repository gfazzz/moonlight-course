# Mission — s02e07 «Ошибки памяти»

## Что сдать
`artifacts/safe.c`: корректная версия задачи из `buggy.c` — дублирует строки в куче, использует и освобождает без ошибок памяти.

## Дано
- `buggy.c` — учебный файл с четырьмя ошибками (утечка, use-after-free, double-free, выход за границы). Изучи, **не сдавай**.
- Инструмент: `gcc -fsanitize=address`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `dup_str` выделяет `strlen(s)+1` байт и копирует строку с `'\0'`.
- [ ] Каждый `malloc` освобождён ровно один раз, после последнего использования.
- [ ] Нет use-after-free / double-free / переполнения.
- [ ] Вывод совпадает с `tests/expected.txt`.
- [ ] **AddressSanitizer чист** (`make test` прогоняет `-fsanitize=address`).

## Как проверить
```bash
cp starter.c artifacts/safe.c
make test
# посмотреть, как ASan ловит баги в учебном файле:
make asan-buggy
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Ты знаешь анатомию утечек и повреждений кучи — и умеешь ловить их инструментом. Ровно это понадобится, чтобы обезвредить троян агентов Z.

## Обстановка

Шесть чисел подряд, по четыре байта. Пройти их индексами ты умеешь. Задача — пройти указателем и понять, что это одно и то же.

Понадобится через час: дальше в дампе индексы кончатся.

## Приказ

Написать `artifacts/ptr_arith.c`: обойти массив арифметикой указателей — показать тождества, посчитать сумму, найти максимум и получить его индекс разностью.

## Дано

`int arr[6]`; тождества `arr ≡ &arr[0]` и `p[i] ≡ *(p + i)`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Показано совпадение `*p`, `*(p + 2)` и `p[2]` — на выводе, а не на словах.
- [ ] Сумма считается обходом `for (int *q = arr; q < arr + n; q++)` — без индексной переменной.
- [ ] Индекс максимума получен как `max - arr`, а не подсчитан счётчиком.
- [ ] Разность печатается через `%td` — её тип `ptrdiff_t`.
- [ ] `arr + n` используется только для сравнения; разыменования за концом нет.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/ptr_arith.c
make test
```

Ожидается `sum = 105`, `max = 30 at index 5`. Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| индекс максимума завышен в 4 раза | разность посчитана в байтах через `(char *)` |
| мусор в последнем элементе | цикл дошёл до `arr + n` включительно и разыменовал |
| `warning: format '%d' expects int` | `ptrdiff_t` печатается как `%td` |
| указатель уезжает вместо значения | `*p++` вместо `(*p)++` |

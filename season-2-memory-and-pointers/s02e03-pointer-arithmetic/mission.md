# Mission — s02e03 «Указатели и массивы»

## Что сдать
`artifacts/ptr_arith.c`: проходит массив `int` через арифметику указателей (без индексов) — сумма, максимум, разности.

## Дано
- `int arr[6]`.
- Эквивалентности: `arr` ≡ `&arr[0]`, `*(p+i)` ≡ `p[i]`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Показаны эквивалентности `*p`, `*(p+2)`, `p[2]`.
- [ ] Сумма считается обходом указателем `for (int *q = arr; q < arr + n; q++)`.
- [ ] Индекс максимума получен как `max - arr` (разность указателей).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/ptr_arith.c
make test
```

## Оценка времени
~30–40 минут.

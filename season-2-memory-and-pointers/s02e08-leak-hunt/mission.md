# Mission — s02e08 «Охота на утечки» (финал Season 2)

## Что сдать
`artifacts/fixed_logger.c`: починенный логгер — копит записи в связном списке и освобождает **всё** без утечек. Доказательство — чистый прогон под санитайзером.

## Дано
- `buggy_logger.c` — рабочий, но текущий логгер (изучи, **не сдавай**).
- Каждая запись = узел `LogEntry` + строка (`dup_str`) → две аллокации на запись.
- Инструменты: `gcc -fsanitize=address`, `valgrind` (Linux), `leaks` (macOS).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Есть `free_all()`, освобождающая у каждого узла и строку, и сам узел.
- [ ] `next` сохраняется **до** `free(e)` (иначе use-after-free).
- [ ] Вывод совпадает с `tests/expected.txt`.
- [ ] **Санитайзер без утечек** (`make test` прогоняет `-fsanitize=address`).

## Как проверить
```bash
cp starter.c artifacts/fixed_logger.c
make test
make asan-buggy     # увидеть утечки в исходном логгере
```

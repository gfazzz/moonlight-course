# Mission — s02e02 «Указатели»

## Что сдать
`artifacts/swap.c`: демонстрирует чтение/запись через указатель и функцию `swap(int*, int*)`, которая меняет местами значения двух переменных вызывающего.

## Дано
- Две переменные `int x`, `int y`.
- Операторы `&` (адрес) и `*` (разыменование).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `int *p = &x;` и чтение `*p`, запись `*p = 7` (меняет `x`).
- [ ] `swap(int *a, int *b)` реализована через разыменование и вызывается как `swap(&x, &y)`.
- [ ] Показана безопасная проверка `NULL`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/swap.c
make test
```

## Оценка времени
~30–35 минут.

## Результат в сюжете
Ты умеешь ходить по адресам и менять данные по ним. Дальше — двигаться по памяти шагами (арифметика указателей).

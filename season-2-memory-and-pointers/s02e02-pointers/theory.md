# Теория (углублённо) — s02e02

## 1. Указатель — переменная с адресом

Указатель хранит **адрес** другой переменной. Объявление и инициализация:

```c
int x = 42;
int *p = &x;   // p указывает на x
```

`int *p` читается как «`p` — указатель на `int`». `&x` — адрес x. Тип имеет значение: `int *` знает, что по адресу лежит `int` (4 байта) — это понадобится для арифметики (s02e03).

## 2. Разыменование `*`

`*p` — «значение по адресу, который хранит p». Оно и читает, и пишет:

```c
int v = *p;    // прочитать: v = 42
*p = 7;        // записать: теперь x == 7
```

`&` и `*` — обратные операции: `*(&x)` это `x`.

## 3. Зачем указатели: изменить чужую переменную

В C аргументы копируются (s01e05). Функция `void inc(int n){ n++; }` не изменит переменную вызывающего. Чтобы изменить — передают адрес:

```c
void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }
swap(&x, &y);   // меняет x и y вызывающего
```

Это фундаментальная причина существования указателей: функции получают доступ к данным вызывающего, а не к копиям. (Так же `scanf("%d", &x)` — ты давно передаёшь адрес.)

## 4. NULL и опасность «висячих» указателей

`NULL` — «указатель в никуда». Сравнивать с `NULL` безопасно; **разыменовывать** `NULL` — падение (segmentation fault):

```c
int *np = NULL;
if (np != NULL) { /* только тогда *np */ }
```

Разыменование неинициализированного или освобождённого указателя — та же беда. Подробно про висячие указатели — s02e07.

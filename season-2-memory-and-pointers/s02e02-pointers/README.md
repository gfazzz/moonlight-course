## Теория: `&`, `*`, и зачем это нужно

### Указатель и разыменование

```c
int x = 42;
int *p = &x;    // p хранит адрес x
int v = *p;     // читаем по адресу: v = 42
*p = 7;         // пишем по адресу: теперь x == 7
```

`&` — «взять адрес», `*` — «значение по адресу». Они обратны: `*(&x)` это `x`.

### Зачем: изменить чужую переменную

Аргументы в C копируются (s01e05), поэтому обычная функция не изменит твою переменную. Передашь адрес — сможет:

```c
void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }
swap(&x, &y);   // меняет именно x и y
```

Ты уже так делал: `scanf("%d", &x)` получает адрес, чтобы записать в `x`. Про `NULL` и висячие указатели — [`theory.md`](theory.md).

## Разбор типичных ошибок

1. **`swap` без указателей.** `void swap(int a, int b)` поменяет копии — вызывающий не увидит эффекта. Нужны `int *`.
2. **`*a` vs `a`.** Внутри `swap` меняем `*a`/`*b` (значения), а не `a`/`b` (адреса).
3. **Разыменование `NULL`/мусора.** `*p` без инициализации `p` — падение. Указатель должен на что-то указывать.
4. **Приоритет: `*n++` vs `(*n)++`.** `*n++` инкрементит указатель, а не значение. Для значения — `(*n)++`.

## Debriefing

Указатель читает и меняет данные по адресу; функция через него дотягивается до твоих переменных. Механика есть — пора двигаться по памяти.

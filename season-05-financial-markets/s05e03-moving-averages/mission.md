## Обстановка

Сырой график дёргается на процент-полтора каждый день, и в этой дрожи не видно ничего.

Усреднение погасит шум. Вместе с ним оно съест часть времени — и это надо будет увидеть, а не принять на веру.

## Приказ

Написать `artifacts/ma.c`: посчитать простую и экспоненциальную скользящие средние по ряду цен, вывести их рядом, найти пересечения и отметить их тип.

## Дано

Ряд дневных цен. Период — пять точек для обеих средних.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Первые `n−1` точек SMA помечены как **неопределённые**, а не заполнены нулями.
- [ ] EMA инициализирована первой ценой или SMA за первое окно, а не нулём.
- [ ] Коэффициент EMA равен `2/(n+1)`.
- [ ] Пересечение определяется по **смене знака** разности между соседними точками, а не по текущему соотношению.
- [ ] Различаются два типа пересечения: быстрая пересекает медленную снизу вверх и наоборот.
- [ ] SMA считается скользящей суммой за O(n), а не пересчётом окна на каждой точке.
- [ ] Вещественные печатаются с фиксированной точностью.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/ma.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| первые значения SMA — нули | отсутствие данных заполнено значением |
| EMA долго «догоняет» ряд | инициализация нулём |
| сигнал срабатывает на каждой точке | проверяется соотношение, а не его смена |
| значения EMA не совпадают с чужими расчётами | коэффициент `1/n` вместо `2/(n+1)` |
| на больших рядах заметное расхождение SMA | накопленная ошибка скользящей суммы |

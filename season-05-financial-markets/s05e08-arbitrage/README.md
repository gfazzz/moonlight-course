## Теория: следствие и причина

### Арбитраж

```c
double gross = (best_bid - best_ask) / best_ask * 100.0;
double net   = gross - fee_buy - fee_sell;
```

Купить там, где дешевле всего просят, продать там, где дороже всего дают. Разница — валовая выгода.

Ключевое слово — **валовая**. Из неё вычитается:

| Издержка | Порядок |
|---|---|
| комиссия покупки | 0.1–0.3% |
| комиссия продажи | 0.1–0.3% |
| вывод и перевод между площадками | фиксированная сумма плюс время |
| проскальзывание при объёме | зависит от глубины |

Валовые 2.24% превращаются в чистые 1.64% — и это ещё без учёта того, что перевод занимает минуты, за которые цена изменится.

Правило, которое стоит запомнить: **арбитраж на здоровом рынке живёт секунды**. Если расхождение держится часами, объяснение обычно не в неэффективности, а в том, что одна из площадок не даёт вывести средства.

### Разгон

Схема состоит из четырёх фаз и распознаётся по их последовательности:

| Фаза | Цена | Объём | Кто действует |
|---|---|---|---|
| накопление | без изменений | слегка выше | организатор скупает |
| разгон | резкий рост | взрывной | организатор + привлечённые |
| распределение | плато или дрожь | высокий | организатор продаёт |
| обвал | падение | падает | все остальные |

Ни одна фаза по отдельности не является уликой. Улика — их **последовательность**, и особенно совпадение резкого роста с аномальным объёмом при отсутствии новостей.

### Базовый уровень: главная ловушка

Обнаружение аномалии требует нормы. Наивно посчитать средний объём по всему ряду:

```c
baseline = sum(volume) / n;      /* НЕВЕРНО */
```

Всплеск входит в эту сумму и поднимает планку. При объёме в восемь раз выше обычного среднее вырастет так, что сам всплеск окажется «в пределах нормы».

Правильно — считать базу по **спокойному участку**, до начала аномалии:

```c
baseline = mean(volume[0..3]);   /* до разгона */
```

Ловушка встречалась в s05e01 и возвращается здесь в полный рост, потому что цена ошибки максимальна: неверно посчитанная база означает, что схема не будет обнаружена вовсе.

```
[LUNA] Последние два вопроса сезона.
```

**1.** LUNA: «Валовая выгода 2.24%. Почему это ещё не прибыль?»

<details><summary>Ответ</summary>

Потому что не вычтены издержки: комиссия на покупку, комиссия на продажу, плата за перевод между площадками и проскальзывание при попытке взять заметный объём. После комиссий остаётся 1.64%, и это всё ещё оценка сверху — перевод средств занимает минуты, за которые расхождение может исчезнуть. Валовая величина отвечает на вопрос «сколько было бы при мгновенном бесплатном исполнении», а такого исполнения не бывает.
</details>

**2.** LUNA: «Почему базовый объём нельзя считать по всей выборке?»

<details><summary>Ответ</summary>

Потому что аномалия войдёт в собственную норму. Всплеск в восемь раз выше обычного, попав в среднее по короткому ряду, поднимет базовый уровень настолько, что перестанет от него отличаться, — и детектор промолчит именно там, где должен сработать. База считается по заведомо спокойному участку или по скользящему окну **предыдущих** значений, не включающему проверяемое.
</details>

```
[LUNA] Верно. Разбирай схему.
```

## Разбор типичных ошибок

1. **Сравниваются средние цены вместо бида и аска.** Арбитраж считается по ценам, по которым реально исполнят.
2. **Комиссии не вычтены.** Валовая выгода не является прибылью.
3. **Базовый объём по всей выборке.** Всплеск поднимет планку и спрячется.
4. **Разгон определяется только по цене.** Рост без объёма не является разгоном.
5. **Порог кратности подобран под данные.** Константа должна быть задана заранее.
6. **Пик и дно берутся как первое и последнее значение.** Нужны фактические экстремумы ряда.

## Обстановка

Исторический метод не видит того, чего не было в выборке. Если завтра случится день хуже всех сорока, история о нём не знает.

Значит, будущее надо не угадывать, а проиграть — много раз.

## Приказ

Написать `artifacts/montecarlo.c`: смоделировать 10 000 траекторий портфеля на 20 дней, построить распределение итоговых значений и извлечь из него VaR на двух уровнях, худший и лучший случай.

## Дано

Портфель 50 миллионов, горизонт 20 дней, 10 000 траекторий. Параметры процесса — средняя доходность и волатильность из предыдущей серии.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Генератор псевдослучайных чисел **собственный**, с **фиксированным семенем**. `rand()` не используется.
- [ ] Семя не берётся из времени: результат обязан совпадать при каждом запуске.
- [ ] Нормальные величины получаются преобразованием Бокса — Мюллера; случай `u1 == 0` обработан.
- [ ] `sqrt`, `log`, `cos` реализованы вручную — библиотеки `-lm` в курсе нет.
- [ ] Доходность применяется **мультипликативно**: `value *= (1 + r)`.
- [ ] Итоговые значения **сортируются** перед извлечением квантилей.
- [ ] Выводятся: среднее, худший случай, VaR 95%, VaR 99%, лучший случай.
- [ ] Вещественные печатаются с фиксированной точностью.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/montecarlo.c
make test
```

Ожидается среднее `$49 971 665`, VaR 95% `$4 717 250`, VaR 99% `$6 539 723`. Запустите дважды — числа обязаны совпасть побайтово.

Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| результат меняется между запусками | семя из времени или используется `rand()` |
| результат не совпадает с эталоном на другой машине | использован библиотечный генератор |
| `inf` или `nan` в траекториях | логарифм нуля в преобразовании Бокса — Мюллера |
| распределение симметрично относительно нуля | доходность складывается, а не умножается |
| квантили совпадают с крайними значениями | массив не отсортирован |
| `undefined reference to log` | попытка использовать `-lm` |

## После выполнения

Появится распределение, а не число. В худшем из десяти тысяч сценариев портфель теряет пятую часть — и это то, чего однодневный VaR не показывал.

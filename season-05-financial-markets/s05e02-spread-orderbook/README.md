## Теория: то, что между

### Стакан

```
    покупка (bid)          продажа (ask)
    99.95  x 1200          100.05  x  800
    99.90  x 3400          100.10  x 1500
    99.85  x 2100          100.15  x  900
```

Слева — заявки купить, отсортированные по убыванию цены; справа — продать, по возрастанию. Лучшие цены стоят наверху: покупатель хочет дешевле, продавец дороже, поэтому лучший бид — самый высокий, лучший аск — самый низкий.

Сделка происходит, когда кто-то соглашается на цену противоположной стороны.

### Спред

```c
spread     = best_ask - best_bid;
spread_pct = spread / ((best_ask + best_bid) / 2.0) * 100.0;
mid        = (best_ask + best_bid) / 2.0;
```

Спред — расстояние между лучшими ценами и одновременно **стоимость немедленной сделки**: купив по аску и сразу продав по биду, вы теряете ровно спред.

Он же — мера ликвидности:

| Спред | Что значит |
|---|---|
| узкий (0.01–0.05%) | много участников, легко войти и выйти |
| широкий (>1%) | мало желающих, сделка дорогая |
| аномально узкий на неликвиде | подозрительно: кто-то поддерживает видимость |

Процентный спред считают от средней цены, а не от бида: иначе сравнить бумагу за сто долларов с бумагой за два невозможно.

### Дисбаланс

```c
imbalance = (bid_volume - ask_volume) / (bid_volume + ask_volume);
```

Нормировка обязательна: разница в тысячу лотов означает разное на ликвидном и неликвидном инструменте. Нормированная величина лежит в `[-1, 1]` и сравнима между инструментами.

Значение около нуля — равновесие. Сильный перекос означает давление: одной стороны существенно больше, и цена, скорее всего, сдвинется в её сторону.

С оговоркой, которая важнее самого индикатора: **заявку можно снять**. Выставить крупный объём и убрать его до исполнения — законный способ создать видимость спроса. Приём называется спуфингом, и он запрещён, но обнаруживается только по истории отмен, а не по снимку.

## Проверка на канале

```
[LUNA] Два вопроса про стакан.
```

**1.** LUNA: «Почему лучший бид — самая высокая цена в колонке покупок, а лучший аск — самая низкая в колонке продаж?»

<details><summary>Ответ</summary>

Потому что «лучший» означает выгоднейший для противоположной стороны, то есть ближайший к сделке. Продавцу выгодно продать тому, кто даёт больше, — значит, лучший бид максимальный. Покупателю выгодно купить у того, кто просит меньше, — значит, лучший аск минимальный. Отсюда и устройство стакана: лучшие цены всегда наверху обеих колонок, а между ними спред.
</details>

**2.** LUNA: «Дисбаланс четыре к одному в пользу покупателей. Цена вырастет?»

<details><summary>Ответ</summary>

Вероятнее да, чем нет, — но это не гарантия и не сигнал сам по себе. Заявку можно снять, не исполнив: выставить крупный объём на покупку, дождаться реакции других участников и убрать. Приём называется спуфингом, он запрещён на регулируемых рынках и обнаруживается по истории отмен, а не по снимку стакана. По одному кадру нельзя отличить настоящее намерение от декорации.
</details>

## Разбор типичных ошибок

1. **Лучший бид взят как минимум.** Покупки сортируются по убыванию: лучший — максимум.
2. **Процентный спред от бида, а не от средней.** Значения перестают быть сравнимыми между инструментами.
3. **Дисбаланс не нормирован.** Разность в лотах ничего не говорит без масштаба.
4. **Пустая сторона стакана не обработана.** Деление на ноль при расчёте спреда.
5. **Уровни считаются отсортированными без проверки.** Реальные выгрузки иногда приходят вперемешку.

## Debriefing

Числа сошлись, и картина неприятная.

Спред — узкий, `0.10%`. Для этой бумаги, торгующейся раз в час, он должен быть в двадцать раз шире. Кто-то стоит по обе стороны и поддерживает видимость живого рынка.

Дисбаланс — `+0.60`, четыре к одному в пользу покупателей. Один участник, восемь заявок, все выставлены в течение двух минут.

```
[LUNA] Я подняла историю отмен по этому счёту. Из ста двенадцати заявок за день
[LUNA] исполнено четыре. Остальные сняты в среднем через одиннадцать секунд.
[LUNA] Это не торговля. Это декорация — для тех, кто смотрит на дисбаланс.
```

Ты откидываешься в кресле. Один снимок стакана показал больше, чем двадцать свечей.

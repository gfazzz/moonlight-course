**Рынки через расследование финансовой схемы. 8 серий, ~5.5 часа.**

## О чём сезон

**Нью-Йорк, 8 октября.** Двадцать восьмой этаж, окна на Уолл-стрит, внизу здание NYSE. Ева Циммерман прилетела днём раньше и уже выяснила, что кофе здесь хуже, чем в Цюрихе.

Сорок семь тикеров, связанных с операцией переводами. Сто восемьдесят миллионов строк котировок. Кто-то очень старался, чтобы это выглядело нормальной торговлей.

Сезон устроен как последовательное разрушение убедительных чисел. Расхождение в четыре цента, которое объясняется округлением. Отчёт фонда с доходностью 34% и коэффициентом Шарпа 2.8. Стратегия, дающая +3.91% на истории. Список контрагентов, в котором одна компания на самом деле две. Каждое из этих чисел выглядит достоверно — и каждое разваливается, стоит спросить, **как** оно получено.

## Сквозная идея сезона

Каждая серия показывает, как убедительное число оказывается ничем без процедуры:

| Убедительное число | Чего не хватает |
|---|---|
| «свеча в данных» | проверки инварианта: часть свечей битые |
| «расхождение четыре цента» | знака: погрешность округления не бывает односторонней |
| «сто восемьдесят миллионов записей» | разбора: запятая в названии — не разделитель |
| «сделка длилась минус тридцать минут» | календаря: этот час прожит дважды |
| «стратегия даёт +3.91%» | проверки вне выборки: там −5.72% |
| «формат описан в документации» | версии в заголовке: описана не та |
| «худший день в истории» | моделирования: истории всего сорок дней |
| «в списке один контрагент» | алфавита: их два, и различает их один байт |

Последняя строка — самая дорогая. Проверка, которую никто не делает, стоит дешевле всех остальных — именно поэтому её и не делают.

## Как проходить

```bash
cd s05e01-ohlcv-parser
cp starter.c artifacts/parse.c
make test
```

Из корня сезона `make test` прогоняет все восемь серий и сквозной проект.

**Особенность сезона: никакой `-lm`.** `sqrt`, `log`, `exp`, `cos` и генератор псевдослучайных чисел написаны вручную. Это не аскеза, а требование воспроизводимости: результат Монте-Карло обязан совпасть побитово на любой машине, а библиотечный `rand()` этого не гарантирует.

> **LUNA работает в режиме `Ask`, а не `Agent`.** В `Agent` ассистент правит файлы сам — тест позеленеет, а вы не напишете ни строки.

> **Читайте `.md` в предпросмотре** (`Cmd+Shift+V` / `Ctrl+Shift+V`).

Ваш код в `artifacts/` отслеживается git — работайте в своей ветке. Правки курса — веткой от чистого `main`: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Season Project: `trading_system`

```bash
cd project
make modules     # показать, из чего собрана программа
make run
```

| Модуль | Откуда | Что даёт |
|---|---|---|
| [`ml_hash`](../season-04-crypto-and-algorithms/lib/ml_hash.h) | **Season 4** | индекс контрагентов вместо перебора |
| [`ml_csv`](lib/ml_csv.h) | s05e03 | разбор выгрузки конечным автоматом |
| [`ml_money`](lib/ml_money.h) | s05e02 | суммы целыми, комиссия с округлением |
| [`ml_time`](lib/ml_time.h) | s05e04 | метки местного времени в моменты |
| [`ml_text`](lib/ml_text.h) | s05e08 | ширина колонок и поиск двойников |
| [`ml_tick`](lib/ml_tick.h) | s05e06 | выгрузка в бинарный формат |

Семь единиц трансляции из двух сезонов. Тест проверяет **факт переиспользования**: он падает, если `main.c` содержит скопированные реализации вместо подключения модулей.

**Что уходит дальше.** `ml_text` подключается в s09e06 и s10e06 — с ним снимается оговорка «в выровненных колонках только ASCII». `ml_money` нужен в s10e07, `ml_time` — в s10e03, `ml_csv` — в s08e02, приёмы `ml_tick` — уже в Season 6, где те же байты складываются в кадры протоколов.

## Персонажи сезона

- **Ева Циммерман** — ведёт сезон целиком. Не даёт ответов, задаёт вопросы: «сколько он зарабатывает», «как вы это проверяли», «в какую сторону расхождение». Каждый раз оказывается, что вопрос был важнее ответа.
- **Джерри Абрамс** — управляющий фондом. Появляется трижды: в e02 объясняет расхождение, в e05 предлагает найти ошибку в своих цифрах, в e08 уходит невредимым. Ни разу не врёт напрямую — и это самое неудобное в нём.
- **Виктор Петров** — в теории воспоминаниями («средняя глубина реки — метр двадцать»), в финале — одной строкой на старый канал.
- **«Архитектор»** — не появляется. Но деньги ушли за пять часов до того, как о них узнала комиссия.

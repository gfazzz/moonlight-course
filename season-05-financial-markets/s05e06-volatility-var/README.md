## Теория: разброс и хвост

### Волатильность

```c
mean = Σ r[i] / n;
var  = Σ (r[i] - mean)² / (n - 1);
vol  = sqrt(var);
```

Знаменатель `n − 1`, а не `n`: поправка Бесселя. Среднее оценено по той же выборке, поэтому отклонения от него систематически занижены, и деление на `n` даёт смещённую оценку дисперсии.

**Масштабирование по времени.** Волатильность растёт как корень из времени:

```c
vol_annual = vol_daily * sqrt(252);   /* 252 торговых дня в году */
```

Правило верно при независимости доходностей — предположении, которое на реальных рынках выполняется лишь приблизительно. Волатильность имеет свойство кластеризоваться: спокойные периоды сменяются бурными, и корень из времени в такие моменты недооценивает риск.

### Value at Risk

Определение: **убыток не превысит VaR с вероятностью p**.

Два способа посчитать:

```c
/* параметрический: предполагаем нормальное распределение */
var_param = -(mean + z * vol) * portfolio;    /* z = 1.645 для 95% */

/* исторический: берём фактический квантиль */
sort(returns, n);
var_hist = -returns[(int)(0.05 * n)] * portfolio;
```

Первый быстр и требует двух чисел. Второй не предполагает ничего о форме распределения, но требует достаточно данных.

Расхождение между ними — диагностика: если исторический VaR заметно больше параметрического, распределение имеет **тяжёлые хвосты**, и нормальная модель занижает риск.

### Чего VaR не говорит

Главное ограничение формулируется одной фразой: **VaR — это порог, а не ожидание за порогом**.

`VaR 95% = $340,000` означает: в 95% дней убыток меньше этой суммы. О том, сколько теряется в оставшихся 5%, не сказано ничего. Может быть 350 тысяч, может быть весь портфель.

Отсюда дополнительная мера — **условный VaR** (Expected Shortfall): средний убыток при условии, что порог превышен. Она отвечает на вопрос «а насколько плохо, когда плохо», и после кризиса 2008 года регуляторы Базельского комитета перешли именно на неё.

```
[LUNA] Два вопроса. Второй — тот, из-за которого рушатся фонды.
```

**1.** LUNA: «Почему дисперсию делят на `n − 1`, а не на `n`?»

<details><summary>Ответ</summary>

Потому что среднее оценено по той же выборке. Отклонения считаются от выборочного среднего, которое само подстроено под данные, — а значит, они систематически меньше отклонений от истинного среднего. Деление на `n` даёт смещённую оценку, занижающую дисперсию. Поправка Бесселя это компенсирует. На сорока наблюдениях разница около 1.3%, на пяти — 12%, и вот там она уже существенна.
</details>

**2.** LUNA: «VaR 95% равен трёмстам сорока тысячам. Сколько фонд потеряет в худшем случае?»

<details><summary>Ответ</summary>

Неизвестно. VaR отвечает на вопрос «какой убыток не будет превышен в 95% дней» и ничего не говорит про оставшиеся 5%. Убыток в этих днях может составить и 350 тысяч, и весь портфель — мера этого не различает. Именно поэтому появился условный VaR: средний убыток **при условии** превышения порога. После 2008 года Базельский комитет перешёл на него, а формулировка «наш VaR невелик» перестала считаться описанием риска.
</details>

## Разбор типичных ошибок

1. **Деление на `n` вместо `n − 1`.** Систематическое занижение риска.
2. **Годовая волатильность как `vol × 252`.** Масштабируется корень, а не сама величина.
3. **VaR со знаком минус.** По соглашению это положительная величина убытка.
4. **Квантиль как `returns[0.05 * n]` без учёта округления.** На сорока значениях индекс должен быть определён явно.
5. **Собственный `sqrt` не написан.** В курсе нет `-lm`; корень считается методом Ньютона.
6. **Исторический квантиль взят без сортировки.** Ряд надо упорядочить перед выбором.

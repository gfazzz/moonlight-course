## Обстановка

Средние показали направление. Направление — не всё: цена может расти, а сила движения падать, и разгон кончается раньше, чем это видно по графику.

Девять тикеров начали двигаться в один день без единой новости.

## Приказ

Написать `artifacts/rsi.c`: посчитать индекс относительной силы с периодом 14, разметить зоны, корректно обработать отсутствие падений.

## Дано

Ряд цен. Период 14. Пороги зон: выше 70 — перекупленность, ниже 30 — перепроданность.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `avg_loss` считается как среднее **модулей** падений.
- [ ] Используется сглаживание Уайлдера: `(prev * (n-1) + cur) / n`, а не EMA с `2/(n+1)`.
- [ ] Первое значение считается простым средним за период; до накопления периода RSI не выводится.
- [ ] Случай `avg_loss == 0` обработан **явно** и возвращает 100 — не `inf` и не `nan`.
- [ ] Случай, когда цена не менялась вовсе, тоже обработан.
- [ ] Зоны размечены; условия покрывают шкалу без пересечений.
- [ ] Подписи зон — **только ASCII**: `printf` с шириной считает байты.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/rsi.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| `inf` или `nan` в колонке RSI | не обработан нулевой `avg_loss` |
| RSI всегда около 50 | падения складываются со знаком, а не по модулю |
| значения не совпадают с эталоном | использована обычная EMA вместо схемы Уайлдера |
| таблица разъезжается | кириллица в поле фиксированной ширины |
| первые значения выглядят случайными | расчёт начат до накопления периода |

## После выполнения

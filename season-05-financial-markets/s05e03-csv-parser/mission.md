## Обстановка

Скрипт Евы насчитал записей больше, чем строк в файле. Лишние появились там, где в названии контрагента стоит запятая: «Meridian Capital, LLC» разрезано пополам.

В настоящей выгрузке есть всё: кавычки, удвоенные кавычки, запятые и переводы строк внутри полей, `CRLF` вперемешку с `LF` и битые записи.

## Приказ

Написать `artifacts/csv.c`: разобрать `data/journal.csv` конечным автоматом, найти битые записи, не упасть ни на одной и сравнить результат с наивным разбором по запятой.

## Дано

`data/journal.csv` — одиннадцать строк, десять записей, пять колонок: `trade_id, instrument, counterparty, qty, price`.

В файле намеренно собраны: запятая в поле, две запятые в поле, удвоенные кавычки, перевод строки внутри поля, две строки с `CRLF`, запись с четырьмя полями вместо пяти и незакрытая кавычка в самом конце.

## Заполнить

| Место | Что делает |
|---|---|
| `row_putc` | добавить байт в поле; при нехватке места — пометить `overflow` |
| `row_end_field` | завершить поле, запомнить начало следующего, увеличить счётчик |
| `S_START` | начало поля: кавычка, разделитель, перевод строки или данные |
| `S_PLAIN` | поле без кавычек |
| `S_QUOTED` | внутри кавычек: разделителей нет, всё данные |
| `S_AFTER_QUOTE` | кавычка внутри кавычек: закрытие или удвоение |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Файл открывается в двоичном режиме: `\r` виден автомату.
- [ ] Запятая внутри кавычек **не** делит поле.
- [ ] Перевод строки внутри кавычек **не** заканчивает запись.
- [ ] `""` внутри кавычек даёт одну кавычку в данных.
- [ ] `\r` перед `\n` не попадает в поле.
- [ ] Число полей считается по завершениям, а не по числу запятых.
- [ ] Запись с неверным числом полей помечается битой, и разбор **продолжается**.
- [ ] Переполнение буфера помечает запись битой, а не обрезает её молча.
- [ ] Незакрытая кавычка на конце файла отмечена отдельно.
- [ ] В памяти живёт одна запись: размер файла на потребление не влияет.
- [ ] Вывод при `-O0` и `-O2` совпадает (тест проверяет сам).
- [ ] Вывод совпадает с `tests/expected.txt`: 10 записей, 8 целых, 2 битые.
- [ ] `make test` → `PASS`.

## Диагностика

| Симптом | Причина |
|---|---|
| записей на одну больше | перевод строки внутри кавычек принят за конец записи |
| у всех записей на одно поле больше | счётчик увеличивается на разделителе, а не на завершении |
| поле кончается на невидимый байт | `\r` записан как данные |
| после записи с `""` всё съезжает | нет состояния `S_AFTER_QUOTE` |
| разбор кончился на седьмой записи | битая запись обрабатывается как фатальная |
| последняя запись выглядит целой | незакрытая кавычка не проверяется |
| таблица отчёта разъехалась | перевод строки из поля напечатан как есть |

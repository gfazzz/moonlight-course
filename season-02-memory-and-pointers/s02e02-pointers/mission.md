## Обстановка

В дампе одна запись хранит адрес другой. Чтобы пройти по цепочке, нужен инструмент, умеющий держать адрес и ходить по нему.

Разминка перед дампом — на двух переменных, где ошибку видно сразу.

## Приказ

Написать `artifacts/swap.c`: показать чтение и запись через указатель, реализовать `swap(int *, int *)`, меняющую значения двух переменных вызывающего.

## Дано

Две переменные `int x`, `int y`; операторы `&` и `*`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Объявлен `int *p = &x`; показаны чтение `*p` и запись `*p = 7`, меняющая **саму** `x`.
- [ ] `swap(int *a, int *b)` реализована через разыменование и вызывается как `swap(&x, &y)`.
- [ ] Внутри `swap` меняются значения (`*a`, `*b`), а не адреса.
- [ ] Показана проверка на `NULL` перед разыменованием.
- [ ] Указатели инициализированы при объявлении — ни одного `int *p;` без значения.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/swap.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| `swap` не меняет переменные | параметры объявлены `int`, а не `int *` |
| значение не растёт, а адрес уезжает | `*n++` вместо `(*n)++` |
| падение при запуске | разыменован неинициализированный указатель |
| `warning: ... makes pointer from integer` | забыт `&` при передаче адреса |

## Теория: устойчивые оценки

```
IQR = Q3 − Q1
выброс: x < Q1 − 1.5·IQR  или  x > Q3 + 1.5·IQR      (правило Тьюки)
```

Правило `|z| > 3` кажется строже, но `z = (x − mean)/sd` считается по **испорченным** оценкам: выбросы сами раздули среднее и sigma, знаменатель вырос — и аномалии прячутся под порогом. Это **маскировка**. Устойчивая альтернатива — модифицированный z-score на медиане и MAD. Подробнее — [`theory.md`](theory.md).

<details><summary>Ответ</summary>

</details>

**2.** LUNA: «Правило трёх сигм нашло только один выброс из двух. Почему?»

<details><summary>Ответ</summary>

Оба выброса вошли в расчёт среднего и sigma и раздули их. Sigma стала 332 — знаменатель `z` вырос, и значение 980 дало `z ≈ 2.5`, не пройдя порог 3. Выбросы замаскировали друг друга. IQR этого изъяна лишён: он опирается на квартили, на которые хвосты не влияют.

## Разбор типичных ошибок

1. **Сортировать исходный массив.** Индексы выбросов после этого не соответствуют данным — сортируй копию.
2. **Медиана без учёта чётности `n`.** При чётном числе — среднее двух центральных (интерполяция это делает автоматически).
3. **Доверять z-score на грязных данных.** Он маскирует выбросы; для отсечения бери IQR или MAD.
4. **Молча удалять аномалии.** Выброс может быть самым ценным сигналом — помечай, а не выбрасывай.

# Mission — s08e02 «Статистика и выбросы»

## Что сдать
`artifacts/stats.c`: посчитать неустойчивые (среднее, sigma) и устойчивые (медиана, Q1/Q3, IQR) оценки, найти выбросы правилом Тьюки и правилом z-score, показать разницу.

## Дано
- 20 замеров задержки (мс); два последних — аномалии (`980`, `1250`).
- Правило Тьюки: выброс вне `[Q1 − 1.5·IQR, Q3 + 1.5·IQR]`.
- Квантиль — с линейной интерполяцией по отсортированному массиву.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`** (`sqrt` — свой).
- [ ] Квантили считаются по отсортированной копии, исходный массив не портится.
- [ ] Медиана `45.00`, Q1 `43.00`, Q3 `46.25`, IQR `3.25`.
- [ ] Правило Тьюки находит **оба** выброса; z-score — только один.
- [ ] Показан разрыв между средним и медианой (`106.55` мс).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/stats.c
make test
```

## Оценка времени
~45–55 минут.

## Результат в сюжете
Данные перехватов очищены честно: аномалии найдены устойчивым правилом, а не тем, которое сами аномалии и ломают.

## Что ты освоишь

- Нейрон: линейная часть + сигмоида; выход как вероятность.
- Бинарную кросс-энтропию и почему её градиент по `z` равен `(p − y)`.
- Линейную разделимость и предел перцептрона (Минский и Паперт, 1969).

Глубже (почему не MSE, «зима ИИ», свой `exp`) — в [`theory.md`](theory.md).

---

## Теория: нейрон и его граница

```
z = w1·x1 + w2·x2 + b        p = sigmoid(z) = 1/(1 + e^(−z))
```

Потери — кросс-энтропия `L = −[y·ln p + (1−y)·ln(1−p)]`. Её производная по `z` сокращается до

```
dL/dz = p − y      =>   dL/dw_i = (p − y)·x_i,   dL/db = (p − y)
```

Нейрон задаёт **одну прямую** `w1·x1 + w2·x2 + b = 0`. AND и OR ею отделяются, XOR — нет: его классы лежат по диагоналям. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про нейрон.
```

**1.** LUNA: «Почему для классификации берут кросс-энтропию, а не MSE, как в прошлой серии?»

<details><summary>Ответ</summary>

Производная сигмоиды содержит множитель `p(1−p)`, который стремится к нулю при насыщении. С MSE градиент из-за него «умирает», и уверенно ошибающаяся модель почти не учится. В кросс-энтропии этот множитель сокращается — остаётся `(p − y)`, и чем увереннее ошибка, тем сильнее коррекция.
</details>

**2.** LUNA: «XOR дал ровно 50%, а веса обнулились. Это баг обучения?»

<details><summary>Ответ</summary>

Нет, это математический предел модели. Один нейрон проводит одну прямую, а классы XOR расположены по диагоналям — разделяющей прямой не существует. Спуск честно нашёл оптимум: симметричное решение `p = 0.5` для всех входов. Нужен скрытый слой.
</details>

```
[LUNA] Верно. Обучай.
```

## Разбор типичных ошибок

1. **Считать 50% на XOR ошибкой кода.** Это ожидаемый результат — предел модели.
2. **MSE вместо кросс-энтропии.** Обучение застревает при насыщенной сигмоиде.
3. **Забыть усреднить градиент.** Шаг зависит от числа примеров — дели на `NS`.
4. **Взять `exp` из `libm`.** Разные платформы дают расхождение в последнем бите — вывод перестаёт быть воспроизводимым.

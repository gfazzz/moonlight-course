# Теория (углублённо) — s08e06

## 1. Искусственный нейрон

```
z = w1·x1 + w2·x2 + b        (линейная часть)
p = sigmoid(z)               (нелинейность)
```

Веса `w` задают наклон разделяющей прямой, смещение `b` — её сдвиг. Сигмоида превращает любое число в `(0, 1)` — то есть в **вероятность** принадлежности к классу:

```
sigmoid(z) = 1 / (1 + e^(−z))
```

Без нелинейности нейрон был бы обычной линейной регрессией (s08e05), а стопка таких слоёв схлопывалась бы в одну линейную функцию — глубина не давала бы ничего.

## 2. Почему градиент оказался равен `(p − y)`

Для классификации берут не MSE, а **бинарную кросс-энтропию**:

```
L = −[ y·ln(p) + (1−y)·ln(1−p) ]
```

Её производная по `z` (с учётом `dp/dz = p(1−p)`) сокращается до поразительно простого выражения:

```
dL/dz = p − y
```

Множители `p(1−p)` из производной сигмоиды и знаменатели из логарифма взаимно уничтожаются. Отсюда `dL/dw_i = (p − y)·x_i`, `dL/db = (p − y)` — ровно то, что в коде.

Почему не MSE: при насыщенной сигмоиде (`p` близко к 0 или 1) множитель `p(1−p)` стремится к нулю, градиент MSE «умирает» и обучение застревает. Кросс-энтропия этого множителя лишена — она штрафует уверенную ошибку тем сильнее, чем увереннее модель ошиблась.

## 3. Предел одного нейрона

Один нейрон рисует **одну прямую** `w1·x1 + w2·x2 + b = 0` и делит плоскость надвое. Значит, он решает только **линейно разделимые** задачи:

- **AND** `{(1,1)}` против остальных — прямая есть;
- **OR** `{(0,0)}` против остальных — прямая есть;
- **XOR** `{(0,1),(1,0)}` против `{(0,0),(1,1)}` — прямой **не существует**: нужные точки лежат по диагоналям.

В задаче это видно буквально: веса XOR обнуляются, выход застревает на `p = 0.5`, точность 50% — модель не может сделать ничего лучше подбрасывания монеты.

## 4. «Зима ИИ»

Розенблатт построил перцептрон в 1958-м, и вокруг него был большой энтузиазм. В 1969-м Минский и Паперт в книге «Perceptrons» строго доказали именно этот предел. Финансирование направления обрушилось — наступила первая **«зима ИИ»**.

Выход был известен теоретически: добавить **скрытый слой**, который преобразует пространство признаков так, что задача становится линейно разделимой. Но не было практичного способа обучать такие сети. Он появился, когда в 1986-м Румельхарт, Хинтон и Уильямс популяризовали **обратное распространение ошибки** — это s08e07.

## 5. Почему `exp` написан вручную

Библиотечный `exp` из `libm` может отличаться в последнем бите между платформами и версиями — тогда вывод перестаёт быть побитово воспроизводимым. Наша реализация:

1. приводит аргумент делением пополам до `|x| ≤ 0.5`;
2. считает фиксированные 16 членов ряда Тейлора;
3. возводит результат в квадрат `k` раз (`e^x = (e^(x/2^k))^(2^k)`).

Фиксированное число операций → одинаковый результат везде. Это та же дисциплина воспроизводимости, что в Season 5 (свой `sqrt`) и Season 7 (свой ГПСЧ).

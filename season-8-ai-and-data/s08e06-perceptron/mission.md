## Обстановка

Регрессия выдаёт число, а нужен ответ «да» или «нет». Выход прогоняется через сигмоиду и становится вероятностью.

Две из трёх логических функций нейрон освоит. На третьей упрётся в стену, которая когда-то остановила всю область.

## Приказ

Написать `artifacts/perceptron.c`: обучить один нейрон с сигмоидой на конъюнкции, дизъюнкции и исключающем «или»; показать, что первые две решаются, а третья — нет.

## Дано

- Четыре примера: `(0,0), (0,1), (1,0), (1,1)`.
- Старт весов фиксирован: `w1 = 0.3`, `w2 = −0.2`, `b = 0.1`.
- 20000 эпох, скорость обучения `0.5`, порог классификации `0.5`.
- `exp()` реализуется вручную — ради побитовой воспроизводимости.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] `sigmoid(z) = 1/(1 + exp(−z))` на собственном `my_exp`.
- [ ] Потери — бинарная кросс-энтропия, не квадратичная ошибка.
- [ ] Градиент по `z` берётся как `(p − y)`; обновление усредняется по числу примеров.
- [ ] Конъюнкция и дизъюнкция обучаются на **100 %** (`4 из 4`).
- [ ] Исключающее «или» даёт **50 %** (`2 из 4`) — ожидаемый результат, а не ошибка.
- [ ] Веса на третьей задаче обнуляются, выход равен `0.500` на всех входах.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/perceptron.c
make test
```

Поучительная проверка: замените кросс-энтропию на квадратичную ошибку и обучите конъюнкцию. Сходимость замедлится в разы — множитель `p(1−p)` гасит градиент при насыщении.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| исключающее «или» вдруг решилось | сравнение идёт не с той таблицей истинности |
| конъюнкция обучается крайне медленно | использована квадратичная ошибка |
| результат зависит от числа примеров | градиент не усреднён |
| вывод отличается в последних знаках | `exp` взят из библиотеки |
| веса ушли в бесконечность | скорость обучения слишком велика |
| точность 75 % вместо 50 % | порог классификации не `0.5` |

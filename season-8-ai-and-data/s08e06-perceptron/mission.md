# Mission — s08e06 «Перцептрон»

## Что сдать
`artifacts/perceptron.c`: обучить один нейрон с сигмоидой на AND, OR и XOR; показать, что первые два решаются, а XOR — нет.

## Дано
- Четыре примера: `(0,0), (0,1), (1,0), (1,1)`.
- Старт весов фиксирован: `w1 = 0.3, w2 = −0.2, b = 0.1`; 20000 эпох, `lr = 0.5`.
- `exp()` реализуется вручную (без `-lm`), чтобы вывод был воспроизводим.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] `sigmoid(z) = 1/(1 + exp(−z))` на собственном `my_exp`.
- [ ] Градиент по `z` берётся как `(p − y)`; обновление усредняется по числу примеров.
- [ ] AND и OR обучаются на **100%** (`4 из 4`).
- [ ] XOR даёт **50%** (`2 из 4`) — это ожидаемый результат, а не ошибка.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/perceptron.c
make test
```

## Оценка времени
~50–60 минут.

## Что ты освоишь

- Зачем нужен скрытый слой и теорему об универсальной аппроксимации.
- Backpropagation через цепное правило: `d_h = d_out · w2 · h(1−h)`.
- Проблему симметрии весов, локальные минимумы и затухающий градиент.

Глубже (Xavier/He, ReLU, замер сходимости) — в [`theory.md`](theory.md).

---

## Теория: протащить ошибку назад

```
прямой ход:   h_j = s(Σ w1[i][j]·x_i + b1_j)      out = s(Σ w2_j·h_j + b2)

обратный ход: d_out = out − y
              d_h_j = d_out · w2_j · h_j·(1 − h_j)

градиенты:    dw2_j = d_out·h_j      dw1[i][j] = d_h_j·x_i
```

Ошибка выхода распределяется по скрытым нейронам пропорционально весам `w2_j` и умножается на производную активации. Backprop переиспользует значения прямого хода — поэтому стоит столько же, сколько он. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про обучение слоёв.
```

**1.** LUNA: «Что будет, если инициализировать все веса нулями?»

<details><summary>Ответ</summary>

Все скрытые нейроны получат одинаковые градиенты, обновятся одинаково и навсегда останутся копиями друг друга — сеть выродится в один нейрон и снова не решит XOR. Это проблема симметрии; лечится случайной (или, как здесь, фиксированной несимметричной) инициализацией.
</details>

**2.** LUNA: «Для XOR теоретически хватает двух скрытых нейронов. Почему в задаче их четыре?»

<details><summary>Ответ</summary>

Поверхность ошибки невыпуклая, и спуск застревает в локальных минимумах. Замер на 200 инициализациях: с двумя нейронами сходимость всего в 59% запусков, с четырьмя — практически всегда. Избыточная ширина упрощает оптимизацию, даже когда минимальной ёмкости формально достаточно.
</details>

```
[LUNA] Верно. Строй сеть.
```

## Разбор типичных ошибок

1. **Одинаковые стартовые веса.** Нейроны остаются копиями — сеть вырождается.
2. **Забыть `h·(1−h)` в `d_h`.** Без производной активации градиент неверен, обучение разваливается.
3. **Обновить `w2` до вычисления `d_h`.** `d_h` зависит от **старых** `w2` — порядок важен.
4. **Считать 75% нормальным результатом.** Это застревание в локальном минимуме, а не предел модели.

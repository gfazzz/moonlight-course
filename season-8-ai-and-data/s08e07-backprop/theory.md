# Теория — s08e07

> Эта серия закрывает пункт плана T4 в части «математика обратного распространения не раскрыта».

## 1. Скрытый слой меняет систему координат

> *— Глубокая сеть не «думает лучше». Она перерисовывает пространство, пока задача не станет такой простой, что с ней справится прямая. Последний слой всегда простой.*

Один нейрон рисует одну прямую. Скрытый слой строит по прямой на каждый нейрон и переводит вход в новое пространство `(h1, h2, …, h_k)`, где задача уже разделима.

В выводе задачи это видно буквально: второй скрытый нейрон срабатывает почти только на `(0,1)`, третий — почти только на `(1,0)`. Сеть сама разделила два случая, которые требовалось объединить в один класс, — и в новых координатах разделяющая прямая нашлась.

**Теорема об универсальной аппроксимации** (Цыбенко, 1989; Хорник, 1991): сеть с одним скрытым слоем и нелинейной активацией приближает любую непрерывную функцию на компакте с любой точностью.

Что теорема **не** утверждает:

| Вопрос | Ответ теоремы |
|---|---|
| приблизит ли любую функцию | да |
| сколько нейронов понадобится | не сказано; может быть экспоненциально много |
| найдёт ли обучение нужные веса | не сказано |
| обобщится ли на новые данные | не сказано |

Отсюда практический вывод: теорема объясняет, почему глубокое обучение возможно, и ничего не объясняет про то, почему оно работает.

Глубина же полезна экономически: функции, требующие экспоненциального числа нейронов в одном слое, часто представимы полиномиальным числом при нескольких слоях.

## 2. Цепное правило

Проблема: веса скрытого слоя не связаны с выходом напрямую. Решение — производная сложной функции:

```
dL/dw1[i][j] = dL/d(out) · d(out)/d(h_j) · d(h_j)/d(w1[i][j])
```

Раскрывая по слоям:

```
d_out = out − y                          /* кросс-энтропия + сигмоида, см. s08e06 */
d_h_j = d_out · w2_j · h_j·(1 − h_j)

dw2_j     = d_out · h_j        db2   = d_out
dw1[i][j] = d_h_j · x_i        db1_j = d_h_j
```

Читается содержательно: ошибка выхода **распределяется** по скрытым нейронам пропорционально их весам и умножается на производную их активации. Отсюда название.

| Множитель в `d_h_j` | Что означает |
|---|---|
| `d_out` | насколько ошибся выход |
| `w2_j` | насколько этот нейрон повлиял на выход |
| `h_j·(1 − h_j)` | насколько нейрон чувствителен к изменению входа |

**Порядок операций.** `d_h` вычисляется по старым `w2`. Обновление выходного слоя до этого даёт градиент скрытого слоя по уже изменённым весам — алгоритм продолжит сходиться, но медленнее и не туда.

## 3. Почему это дёшево

Обратный ход переиспользует значения `h_j`, посчитанные на прямом. Стоимость обучения примерно вдвое выше стоимости предсказания — **независимо от числа параметров**.

Альтернатива без цепного правила — численное дифференцирование:

```
dL/dw ≈ (L(w + ε) − L(w − ε)) / (2ε)
```

Два прогона сети на **каждый** вес. Для миллиона параметров — два миллиона прогонов на один шаг обучения против одного прогона у обратного распространения.

Именно эта разница делает глубокое обучение вычислительно возможным. Численный градиент при этом остаётся незаменимым инструментом отладки: он медленный, но ловит любую ошибку в аналитических формулах.

## 4. Симметрия весов

Если все веса равны, все скрытые нейроны получают одинаковый вход, дают одинаковую активацию, получают одинаковый градиент и обновляются одинаково. Они остаются копиями навсегда, и сеть из `k` нейронов ведёт себя как сеть из одного.

Смещения нулями инициализировать можно — симметрию ломают именно веса.

В реальных сетях используют схемы, подбирающие масштаб инициализации так, чтобы дисперсия сигнала не затухала и не взрывалась по слоям:

| Схема | Для чего | Масштаб |
|---|---|---|
| Ксавье (Glorot) | сигмоида, гиперболический тангенс | `1/√(n_in + n_out)` |
| Хе (He) | выпрямитель ReLU | `2/n_in` |

Разница в двойке существенна: выпрямитель обнуляет половину активаций, и без компенсации сигнал затухает вдвое на каждом слое.

В задаче случайность заменена фиксированными несимметричными числами — ради побитовой воспроизводимости.

## 5. Локальные минимумы: замер

Теоретически для исключающего «или» хватает **двух** скрытых нейронов. Поверхность ошибки невыпуклая, и спуск застревает.

Замер на 200 инициализациях при прочих равных (20000 эпох, `lr = 0.5`):

| Скрытых нейронов | Доля успешных запусков |
|---|---|
| 2 | **59 %** |
| 3 | 92 % |
| 4 | **100 %** (199 из 200) |

В неудачных случаях потери замирают на `0.125` — ровно одной восьмой. Это состояние, где часть скрытых нейронов насыщена и не даёт градиента: сеть верно классифицирует три примера из четырёх и не может сдвинуться.

Практический вывод шире задачи: **избыточная ширина упрощает оптимизацию**, даже когда минимальной ёмкости формально достаточно. Реальные сети всегда шире теоретического минимума — не ради выразительности, а ради того, чтобы обучение вообще сошлось.

Современное понимание добавляет деталь: в пространствах высокой размерности настоящие локальные минимумы редки, а основное препятствие — сёдла, точки с нулевым градиентом, но выходом вниз по одному из направлений. Шум стохастического спуска помогает их покидать.

## 6. Затухающий градиент

В `d_h_j` присутствует `h(1−h)` — производная сигмоиды, максимум которой равен **0.25** и достигается при `h = 0.5`.

Каждый слой умножает градиент на величину не больше 0.25:

| Слоёв | Множитель в лучшем случае |
|---|---|
| 2 | 0.06 |
| 5 | 0.001 |
| 10 | 10⁻⁶ |

Ранние слои получают исчезающе малый градиент и практически не обучаются. Это и есть причина, по которой глубокие сети не поддавались обучению до начала 2010-х.

Что помогло:

| Средство | Как работает |
|---|---|
| выпрямитель ReLU | производная равна 1 при положительном входе |
| остаточные связи | градиент идёт в обход слоёв |
| нормализация по батчам | удерживает активации в рабочей области |
| правильная инициализация | дисперсия сигнала не затухает |

Сигмоида сегодня осталась в основном на выходе бинарного классификатора — там, где нужна вероятность, а не внутреннее представление.

## 7. Python как компаньон

```python
model = nn.Sequential(nn.Linear(2, 4), nn.Sigmoid(), nn.Linear(4, 1), nn.Sigmoid())
loss = criterion(model(x), y)
optimizer.zero_grad()
loss.backward()
optimizer.step()
```

Автоматическое дифференцирование строит граф вычислений и применяет к нему то же цепное правило — только для произвольной структуры, а не для одной фиксированной сети.

Понимание механики объясняет практические странности:

- **зачем `zero_grad()`** — градиенты накапливаются, а не заменяются; без обнуления шаг делается по сумме всех предыдущих;
- **откуда `NaN`** — переполнение в экспоненте при разошедшихся весах;
- **почему глубокая сеть с сигмоидами не учится** — затухающий градиент;
- **почему `detach()` останавливает обучение части сети** — разрыв графа обрывает путь градиента назад.

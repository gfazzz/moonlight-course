## Обстановка

У скрытого слоя нет целевого значения. Но известно, насколько ошибся выход, и известно, через какие веса каждый скрытый нейрон на него повлиял.

Этого достаточно. Остальное делает цепное правило.

## Приказ

Написать `artifacts/backprop.c`: сеть 2-4-1 с сигмоидами, обучаемая обратным распространением; решить исключающее «или», которое не поддалось одному нейрону.

## Дано

- Четыре примера; 60000 эпох, скорость обучения `0.5`, обучение по одному примеру.
- Стартовые веса фиксированы и **несимметричны**.
- `exp()` — свой, без `-lm`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Прямой ход: `h_j = s(Σ w1[i][j]·x_i + b1_j)`, `out = s(Σ w2_j·h_j + b2)`.
- [ ] Обратный ход по цепному правилу: `d_h_j = d_out · w2_j · h_j·(1 − h_j)`.
- [ ] `d_h` считается по **старым** `w2`, до обновления выходного слоя.
- [ ] Обновляются **все четыре** набора параметров: `w2`, `b2`, `w1`, `b1`.
- [ ] Стартовые веса несимметричны — иначе скрытые нейроны останутся копиями.
- [ ] Потери падают `0.254986` → `0.000000`; задача решена на **100 %** (`4 из 4`).
- [ ] Печатаются активации скрытого слоя — все `NH` значений на каждый вход.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/backprop.c
make test
```

Поучительная проверка: обнулите стартовые веса. Все четыре скрытых нейрона дадут одинаковые активации на всех входах, и сеть выдаст те же 50 %, что один нейрон в прошлой серии.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| результат 50 %, активации скрытого слоя одинаковы | стартовые веса симметричны |
| потери замерли на `0.125` | застревание в локальном минимуме |
| обучение разваливается | забыт множитель `h·(1−h)` в `d_h` |
| сходится, но медленно и не туда | `w2` обновлён до вычисления `d_h` |
| выход насыщен на одном значении | смещения не обновляются |
| в потерях появился `NaN` | переполнение в экспоненте при больших весах |

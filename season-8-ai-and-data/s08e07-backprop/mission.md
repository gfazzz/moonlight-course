# Mission — s08e07 «Backprop: скрытый слой и XOR»

## Что сдать
`artifacts/backprop.c`: сеть 2-4-1 с сигмоидами, обучаемая обратным распространением ошибки; решить XOR, который не поддался одному нейрону.

## Дано
- Четыре примера XOR; 60000 эпох, `lr = 0.5`, обучение по одному примеру (SGD).
- Стартовые веса фиксированы и **несимметричны**.
- `exp()` — свой (без `-lm`).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Прямой ход: `h_j = s(Σ w1[i][j]·x_i + b1_j)`, `out = s(Σ w2_j·h_j + b2)`.
- [ ] Обратный ход по цепному правилу: `d_h_j = d_out · w2_j · h_j·(1 − h_j)`.
- [ ] Обновляются **оба** слоя (`w2`, `b2`, `w1`, `b1`).
- [ ] Loss падает `0.252125` → `0.000000`; XOR решён на **100%** (`4 из 4`).
- [ ] Печатаются активации скрытого слоя (все `NH` значений).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/backprop.c
make test
```

## Оценка времени
~60–70 минут.

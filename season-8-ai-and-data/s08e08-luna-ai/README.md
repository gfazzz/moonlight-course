## Теория: метрики вместо точности

```
precision = TP/(TP+FP)     recall = TP/(TP+FN)     F1 = 2·P·R/(P+R)
```

Accuracy при дисбалансе бессмысленна: «всегда норма» даёт 0.810 при нулевом recall. F1 берёт гармоническое среднее, чтобы перекос штрафовался жёстко (P = 1.0, R = 0.0 → F1 = 0, а не 0.5).

Три правила честной оценки: считать на **отложенных** данных, перемешивать **честно** (s08e03), нормировать по статистикам обучающей части (иначе утечка данных). Подробнее — [`theory.md`](theory.md).

## Разбор типичных ошибок

1. **Судить по accuracy.** При дисбалансе она маскирует полную неспособность находить редкий класс.
2. **Разбивать без перемешивания.** Если данные упорядочены, «первые 300» — систематическая ошибка.
3. **Учиться на проверочной части.** Оценка становится бессмысленной (тот же overfitting, что в Season 5).
4. **Забыть нормировку.** Признак с большой шкалой задавит остальные, обучение будет ползти.

# Mission — s08e08 «luna_ai» (финал Season 8)

## Что сдать
`artifacts/luna_ai.c`: полный цикл машинного обучения на чистом C — данные, нормировка, честное разбиение, обучение сети 3-6-1 и оценка метриками, а не только точностью.

## Дано
- 400 узлов, 3 признака (трафик, доля ошибок, ночная активность); класс «угроза» — около 20%.
- Диапазоны классов **пересекаются**: идеальное разделение невозможно.
- Разбиение 300 / 100, перемешивание Кнута; 3000 эпох, `lr = 0.5`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`** (`exp` и `sqrt` — свои).
- [ ] Признаки нормируются (вычесть среднее, поделить на sigma).
- [ ] Разбиение делается **после** перемешивания Кнута с честным `below_fair`.
- [ ] Обучение идёт **только** на обучающей части; оценка — на отложенной.
- [ ] Считаются TP/TN/FP/FN, precision, recall, F1 — не только accuracy.
- [ ] Показан ориентир «всегда норма» (`accuracy 0.810` при нулевом recall).
- [ ] Итог: accuracy `0.980`, F1 `0.947`; вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/luna_ai.c
make test
```

## Оценка времени
~70–80 минут.

## Результат в сюжете
LUNA, которая вела тебя восемь сезонов, теперь работает на твоём коде. Классификатор угроз обучен и честно оценён — включая цену ошибок, которых модель избежать не смогла.

## Обстановка

Сортировка вставками делает почти четыре миллиона сравнений на четырёх тысячах элементов. Проблема не в сравнениях, а в перемещениях: элемент ползёт к своему месту по одной позиции.

Первый алгоритм двигает его сразу далеко. Второй не бывает медленным вообще.

## Приказ

Написать `artifacts/sorts.c`: реализовать сортировку Шелла с шагами Кнута и пирамидальную сортировку, замерить сравнения и обмены, сопоставить со вставками — включая худший случай.

## Дано

- 4000 детерминированных значений (линейный генератор, сид `20260726`).
- Худший случай — массив, упорядоченный по убыванию.
- Замеряются **операции**, а не время: время невоспроизводимо.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Сортировка Шелла использует шаги Кнута: `h = 3h + 1`, затем `h /= 3`.
- [ ] Последний проход выполняется при `h = 1`.
- [ ] Куча строится **просеиванием вниз** от `n/2 − 1` — за `O(n)`, а не `O(n log n)`.
- [ ] Проверяется существование правого потомка перед обращением к нему.
- [ ] Все три алгоритма действительно сортируют — это проверяется явно.
- [ ] Числа совпадают: вставки `3902039`, Шелл `75119`, пирамидальная `83513` сравнений.
- [ ] Худший случай: вставки `7998000` против `80151` — разрыв `99.8×`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/sorts.c
make test
```

Поучительная проверка: замените шаги Кнута на `h = n/2, n/4, …` и подайте худший случай. Число сравнений вырастет на порядок — исходная последовательность Шелла сохраняет квадратичное поведение.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| Шелл почти не выигрывает у вставок | шаги делятся пополам вместо шагов Кнута |
| массив остался неотсортированным | пропущен проход с `h = 1` |
| выход за границу массива | не проверено существование правого потомка |
| построение кучи стоит как сортировка | использовано просеивание вверх |
| массив отсортирован по убыванию | построена min-куча вместо max |
| числа не воспроизводятся | замеряется время, а не операции |

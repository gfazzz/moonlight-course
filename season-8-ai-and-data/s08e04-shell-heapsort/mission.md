# Mission — s08e04 «Shell sort и heapsort»

## Что сдать
`artifacts/sorts.c`: реализовать Shell sort (шаги Кнута) и heapsort, замерить сравнения и обмены, сопоставить с сортировкой вставками — включая худший случай.

## Дано
- 4000 детерминированных значений (LCG, сид `20260726`).
- Худший случай: массив, упорядоченный по убыванию.
- Замеряем **операции**, а не время (время невоспроизводимо).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Shell sort использует шаги Кнута: `h = 3h+1`, затем `h /= 3`.
- [ ] Heapsort: построение кучи `sift_down` от `n/2−1`, затем извлечение максимума.
- [ ] Все три алгоритма действительно сортируют (`отсортирован: да`).
- [ ] Числа совпадают: insertion `3902039`, shell `75119`, heapsort `83513` сравнений.
- [ ] Худший случай: insertion `7998000` против heapsort `80151` — разрыв `99.8×`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/sorts.c
make test
```

## Оценка времени
~50–60 минут.

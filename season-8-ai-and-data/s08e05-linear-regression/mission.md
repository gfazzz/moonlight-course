# Mission — s08e05 «Линейная регрессия и градиентный спуск»

## Что сдать
`artifacts/regression.c`: обучить модель `y = w·x + b` градиентным спуском, сверить результат с точным решением МНК и показать расходимость при слишком большом шаге.

## Дано
- 100 точек: `y = 2.5x + 7 + шум` (детерминированный LCG, сид `31337`).
- Скорость обучения `0.02`, 2001 эпоха; для демонстрации расходимости — `lr = 1.0`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Градиенты верны: `dw = 2/N·Σ(pred−y)·x`, `db = 2/N·Σ(pred−y)`.
- [ ] Логируется прогресс каждые 400 эпох; MSE монотонно падает (`427.5` → `0.3388`).
- [ ] Точное решение считается по формулам МНК.
- [ ] Спуск сходится к нему: расхождение `dw`, `db` < 0.00001 → «да».
- [ ] При `lr = 1.0` модель расходится → «да».
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/regression.c
make test
```

## Оценка времени
~50–60 минут.

## Результат в сюжете
Первая модель, которая учится сама. Тот же механизм — шаг против градиента — работает внутри любой нейросети; дальше он масштабируется.

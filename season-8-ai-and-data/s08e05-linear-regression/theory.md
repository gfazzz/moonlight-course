# Теория — s08e05

## 1. Три части любого обучения

> *— Всякое обучение состоит из трёх вещей: что мы вычисляем, как мы понимаем, что ошиблись, и что делаем с этим пониманием. Если хоть одна не сформулирована явно, вы не обучаете модель, а надеетесь.*

| Часть | Здесь | В нейросети |
|---|---|---|
| модель | `pred = w·x + b` | композиция слоёв |
| функция потерь | среднеквадратичная ошибка | кросс-энтропия и другие |
| правило обновления | шаг против градиента | тот же шаг, градиенты по цепному правилу |

Правая колонка отличается только сложностью вычисления градиента. Сама схема не меняется от прямой до модели на сотни миллиардов параметров.

## 2. Почему именно среднеквадратичная ошибка

```
MSE = (1/N) · Σ (pred − y)²
```

| Свойство | Следствие |
|---|---|
| гладкая | производная существует везде, спуск применим |
| выпуклая по параметрам | минимум **один**, локальных ловушек нет |
| квадрат ошибки | крупные промахи штрафуются сильнее |
| соответствует нормальному шуму | минимизация равна оценке максимального правдоподобия |

Последняя строка объясняет происхождение: если шум в данных нормальный, минимизация квадратов — это в точности поиск наиболее правдоподобных параметров. Формула не изобретена ради удобства, она выведена из предположения о шуме.

Отсюда и её слабость. Квадрат делает оценку чувствительной к выбросам — та же нулевая точка пробоя, что у среднего в s08e02. Когда выбросы ожидаемы, берут абсолютную ошибку или функцию Хубера: квадратичная вблизи нуля, линейная в хвостах.

## 3. Градиент

Градиент — вектор частных производных, указывающий направление наибольшего **роста**. Спуск идёт против него.

Вывод для `w`:

```
d/dw (pred − y)²  =  2(pred − y) · d(pred)/dw  =  2(pred − y) · x
```

Для `b` производная `pred` равна единице, поэтому множителя `x` нет:

```
dMSE/dw = (2/N) · Σ (pred − y)·x
dMSE/db = (2/N) · Σ (pred − y)
```

Множитель `2` часто убирают, определяя ошибку как `(1/2N)·Σ(...)²`. На результат это не влияет — константа поглощается скоростью обучения.

**Оба градиента считаются по одному состоянию модели.** Обновление `w` до вычисления `db` даёт другой алгоритм (покоординатный спуск), который тоже сходится, но иначе и не к тому же за то же число шагов.

## 4. Скорость обучения

| Режим | Поведение |
|---|---|
| `lr` мала | сходимость есть, эпох нужно на порядки больше |
| `lr` в норме | быстрое устойчивое убывание ошибки |
| `lr` велика | ошибка растёт, значения уходят в бесконечность |

Третий режим качественно отличается от первых двух. Шаг перелетает минимум и оказывается дальше от него; в новой точке градиент больше, шаг длиннее — процесс раскручивается.

Для квадратичной функции потерь порог точен:

```
lr < 2 / λ_max
```

где `λ_max` — наибольшее собственное число матрицы вторых производных. Выше порога расходимость гарантирована при любых данных и любой начальной точке.

**Масштабирование признаков** связано с этим напрямую. Если `x` измеряется тысячами, градиент по `w` огромен, `λ_max` велик, и допустимый шаг становится крошечным. Нормировка (вычесть среднее, поделить на стандартное отклонение) выравнивает масштабы и позволяет учиться на порядки быстрее.

Адаптивные методы — Adam, RMSProp, AdaGrad — подстраивают шаг для каждого параметра отдельно, что снимает часть проблемы, но не отменяет нормировки.

## 5. Точное решение и зачем всё-таки спуск

```
w = (N·Σxy − Σx·Σy) / (N·Σxx − (Σx)²)
b = (Σy − w·Σx) / N
```

В общем виде это нормальное уравнение `θ = (XᵀX)⁻¹Xᵀy`.

| Препятствие | Почему спуск лучше |
|---|---|
| обращение матрицы стоит `O(d³)` | при тысячах признаков неподъёмно |
| матрица вырождена при коллинеарных признаках | спуск работает и там |
| данные не помещаются в память | спуск идёт батчами |
| модель нелинейна | точной формулы **не существует** |

Последняя строка решающая. Спуск требует только дифференцируемости, и потому применим везде, где точная формула невозможна.

Тем не менее сравнение с точным решением — важнейший приём отладки: **правильность градиентов проверяют там, где ответ известен**. В нейросети сравнивать будет не с чем, поэтому реализацию обкатывают на задаче с аналитическим решением.

Родственный приём — численная проверка градиента:

```
grad ≈ (L(w + ε) − L(w − ε)) / (2ε)
```

Медленно, но ловит любую ошибку в аналитической производной.

## 6. Варианты спуска

| Вариант | Градиент по | Свойства |
|---|---|---|
| полный (batch) | всем данным | точное направление, дорогой шаг |
| стохастический (SGD) | одному примеру | шумно, быстро, выскакивает из плохих областей |
| мини-батчами | 32–512 примерам | стандарт глубокого обучения |

Шум стохастического спуска не только недостаток: он помогает не застревать в плохих точках и на практике даёт лучшую обобщающую способность.

Здесь же нужен честный шаффл из s08e03: порядок примеров и состав батчей влияют на сходимость, и систематика в перемешивании становится систематикой в обучении.

## 7. Python как компаньон

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)
print(model.coef_, model.intercept_)
```

Внутри тот же метод наименьших квадратов — точнее, разложение по сингулярным числам, устойчивое к вырожденности.

Знание механики нужно для чтения диагностики: почему ошибка на обучении падает, а на проверке растёт (переобучение из s05e05), почему после нормировки та же модель учится втрое быстрее, почему при коллинеарных признаках коэффициенты огромны и противоположны по знаку.

# Теория (углублённо) — s08e05

## 1. Модель, функция потерь, обучение

Три обязательные части любого обучения:

1. **Модель** — `pred = w·x + b` (параметры `w`, `b`);
2. **Функция потерь** — насколько плохо: `MSE = (1/N)·Σ(pred − y)²`;
3. **Правило обновления** — как менять параметры, чтобы потери падали.

MSE выбрана не случайно: она гладкая (есть производная везде) и выпуклая по параметрам — у неё **один** минимум, без локальных ловушек. Квадрат сильно штрафует крупные ошибки — отсюда же и чувствительность MSE к выбросам (s08e02).

## 2. Градиент и спуск

Градиент — вектор частных производных, указывающий направление **наибольшего роста**. Значит, шагать надо против него:

```
dMSE/dw = (2/N)·Σ (pred − y)·x
dMSE/db = (2/N)·Σ (pred − y)

w ← w − lr·dMSE/dw
b ← b − lr·dMSE/db
```

Вывод для `w`: `d/dw (pred − y)² = 2(pred − y)·d(pred)/dw = 2(pred − y)·x`. Для `b` производная `pred` по `b` равна 1 — отсюда формула без множителя `x`.

Это **тот же алгоритм**, что обучает нейросети: разница лишь в том, что там производные считаются по цепному правилу через слои (s08e07).

## 3. Скорость обучения решает всё

- **слишком мала** — сходимся, но за тысячи лишних эпох;
- **слишком велика** — шаг перелетает минимум, ошибка растёт, значения уходят в бесконечность (в задаче при `lr = 1.0` MSE взрывается за 20 эпох);
- **в самый раз** — быстрая устойчивая сходимость.

Существует порог устойчивости: для квадратичной ошибки спуск расходится при `lr > 2/λ_max`, где `λ_max` — наибольшее собственное число матрицы вторых производных. На практике подбирают эмпирически или используют адаптивные методы (**Adam**, **RMSProp**), где шаг подстраивается сам.

Тесно связано **масштабирование признаков**: если `x` измеряется тысячами, градиент по `w` огромен, и приходится брать крошечный `lr`. Нормировка признаков (вычесть среднее, поделить на sigma) выравнивает масштабы и ускоряет сходимость.

## 4. Зачем спуск, если есть точная формула

Для линейной регрессии существует **аналитическое** решение (метод наименьших квадратов):

```
w = (N·Σxy − Σx·Σy) / (N·Σxx − (Σx)²)
b = (Σy − w·Σx) / N
```

В общем виде это «нормальное уравнение» `θ = (XᵀX)⁻¹Xᵀy`. Задача подтверждает: спуск сходится ровно к нему.

Почему тогда учат спуском:

- обращение `XᵀX` стоит **O(d³)** по числу признаков — при тысячах признаков это неподъёмно;
- матрица может быть вырожденной (коллинеарные признаки);
- данные могут не помещаться в память — спуск работает **батчами** (SGD);
- для нелинейных моделей (нейросети) точной формулы **не существует вовсе**.

Градиентный спуск универсален; точная формула — приятное исключение.

## 5. Варианты спуска

- **Batch GD** (наш) — градиент по всем данным: точное направление, дорогой шаг.
- **SGD** — по одному примеру: шумно, но быстро и способно выскочить из плохих областей.
- **Mini-batch** — компромисс (32–512 примеров), стандарт в глубоком обучении. Здесь и нужен честный шаффл из s08e03: порядок батчей влияет на сходимость.

## 6. Python как компаньон

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression().fit(X, y)
```

Одна строка — и внутри тот же МНК. Понимание механики нужно, чтобы читать диагностику: почему loss не падает, почему помогает нормировка, когда модель недообучена, а когда переобучена (Season 5, s05e05).

## Теория: шаг против градиента

```
MSE = (1/N)·Σ(pred − y)²

dMSE/dw = (2/N)·Σ(pred − y)·x        w ← w − lr·dMSE/dw
dMSE/db = (2/N)·Σ(pred − y)          b ← b − lr·dMSE/db
```

Градиент указывает направление наибольшего **роста** ошибки — поэтому вычитаем. Скорость обучения `lr` критична: мала — учимся вечно, велика — перелетаем минимум и улетаем в бесконечность. Для прямой есть и точная формула МНК; спуск сходится ровно к ней. Подробнее — [`theory.md`](theory.md).

**1.** LUNA: «Для прямой есть точная формула. Зачем тогда спуск?»

<details><summary>Ответ</summary>

Точное решение требует обращения матрицы — O(d³) по числу признаков, и оно ломается на вырожденных данных. Кроме того, данные могут не помещаться в память (спуск работает батчами), а для нелинейных моделей точной формулы не существует вовсе. Спуск универсален.
</details>

**2.** LUNA: «При `lr = 1.0` ошибка не просто падает медленно, а взрывается. Почему?»

<details><summary>Ответ</summary>

Шаг перелетает минимум и оказывается дальше от него, чем был. Следующий градиент больше, шаг ещё длиннее — процесс раскручивается, и значения уходят в бесконечность. Для квадратичной ошибки есть порог устойчивости: выше него спуск расходится всегда.
</details>

```
[LUNA] Верно. Обучай.
```

## Разбор типичных ошибок

1. **Знак обновления.** `w += lr·grad` уводит вверх по ошибке. Против градиента — минус.
2. **Забыть множитель `x` в `dw`.** Производная по `w` содержит `x`, по `b` — нет.
3. **Обновлять `w` до вычисления `db`.** Оба градиента считаются по одному состоянию модели.
4. **Подбирать `lr` наугад.** Начни с малого, следи за MSE: растёт — шаг велик.

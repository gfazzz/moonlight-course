# Mission — s08e01 «Большие данные: mmap и один проход»

## Что сдать
`artifacts/bigdata.c`: отобразить файл данных через `mmap` и посчитать статистику **за один проход**, удерживая лишь несколько накопителей; показать, где ломается наивная формула дисперсии.

## Дано
- 200000 значений `double` (~1.6 МБ) со смещением `1e8` и разбросом 100.
- Файл: `/tmp/moonlight_s08e01_data.bin` (создаёт сама программа).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Данные читаются через `mmap` (`MAP_PRIVATE`), **без** копирования в кучу; результат проверяется на `MAP_FAILED`.
- [ ] Размер берётся из `fstat`, дескриптор закрывается после `mmap`.
- [ ] Дисперсия считается методом **Уэлфорда** (`835.355023`), параллельно — наивной формулой для сравнения.
- [ ] Показано расхождение (`38.899589`) — наивный способ теряет точность.
- [ ] Ресурсы освобождаются: `munmap`, `unlink`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/bigdata.c
make test
```

## Оценка времени
~45–55 минут.

Перехваты противника — терабайты. Ты научился считать по ним статистику, не загружая их в память и не теряя точности. Это фундамент всего, что будет дальше в сезоне.

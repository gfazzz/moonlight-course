## Обстановка

Выборку надо разделить на обучающую и проверочную. Очевидный способ перемешать массив смещён арифметически: `nⁿ` путей не делится на `n!` перестановок.

Смещение не даёт сбоя. Оно просто делает оценку модели неправдой.

## Приказ

Написать `artifacts/shuffle.c`: измерить смещение наивного тасования, реализовать честный алгоритм Фишера — Йетса в форме Кнута и показать смещение остатка при выборе случайного индекса.

## Дано

- 60000 испытаний на 3 элементах (6 перестановок), ожидание — по 10000.
- Детерминированный линейный конгруэнтный генератор, сид `424242` для обоих алгоритмов.
- Демонстрация смещения остатка: источник `[0, 10)`, 3 корзины, 120000 бросков.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] `below_fair(n)` использует **отбраковку** хвоста: `limit = range − range % n`.
- [ ] Берутся старшие биты генератора, а не младшие.
- [ ] Наивное тасование даёт максимальное отклонение `1172` (11.72 %).
- [ ] Кнут реализован как `for (i = n−1; i > 0; i--) swap(a, i, below_fair(i+1))`.
- [ ] Диапазон выбора — `[0, i]` включительно; отклонение `179` (1.79 %).
- [ ] Смещение остатка показано: корзина 0 получает `+20.3 %` при остатке и `−0.1 %` при отбраковке.
- [ ] Сид фиксирован; результат воспроизводим между запусками.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/shuffle.c
make test
```

Поучительная проверка: увеличьте число испытаний вдесятеро. Отклонение Кнута упадёт примерно втрое (шум убывает как корень), а отклонение наивного алгоритма останется на месте — потому что это не шум.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| оба алгоритма дают одинаковое отклонение | в наивном используется тот же диапазон, что у Кнута |
| Кнут даёт систематическое смещение | диапазон `[0, i)` вместо `[0, i]` |
| корзины совпали при обоих способах | отбраковка не применена или применена к обоим |
| результат меняется между запусками | сид взят от времени |
| перестановки распределены странно | младшие биты генератора имеют короткий период |
| отклонение растёт с числом испытаний | считается абсолютное, а не относительное |

## После выполнения

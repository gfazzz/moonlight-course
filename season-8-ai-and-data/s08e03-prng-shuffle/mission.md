# Mission — s08e03 «ГПСЧ и перемешивание Кнута»

## Что сдать
`artifacts/shuffle.c`: измерить смещение наивного тасования, реализовать честный алгоритм Фишера–Йетса (Кнута) и показать modulo bias при выборе случайного индекса.

## Дано
- 60000 испытаний на 3 элементах (6 перестановок), ожидание — по 10000.
- Детерминированный LCG, сид `424242` для обоих алгоритмов.
- Демонстрация modulo bias: источник `[0,10)`, 3 корзины, 120000 бросков.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] `below_fair(n)` использует **отбраковку** хвоста (`limit = range − range % n`), а не голый остаток.
- [ ] Наивное тасование: `swap(a, i, below_fair(n))` — даёт максимальное отклонение `1172` (11.72%).
- [ ] Кнут: `for (i = n−1; i > 0; i−−) swap(a, i, below_fair(i+1))` — отклонение `179` (1.79%, шум).
- [ ] Modulo bias виден: корзина 0 получает `+20.3%` при остатке и `−0.1%` при отбраковке.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/shuffle.c
make test
```

## Оценка времени
~50–60 минут.

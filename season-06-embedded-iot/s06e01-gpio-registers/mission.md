## Обстановка

Плата на столе — точная копия того, что стоит в НИИ, собранная по фотографиям щитка. На настоящей ты ошибёшься один раз. На этой — сколько угодно.

Здесь память не хранит данные. Она управляет проводами.

## Приказ

Написать `artifacts/gpio.c`: настроить направления пинов, прочитать состояние входов, снять блокировку люка и восстановить исходное состояние.

## Карта пинов

| Бит | Назначение | Направление |
|---|---|---|
| 0 | датчик двери | вход |
| 1 | светодиод состояния | выход |
| 2 | датчик вскрытия | вход |
| 3 | реле блокировки | выход |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Все изменения регистров — **битовыми операциями**; присваивания регистру целого значения нет.
- [ ] Сброс бита делается через `&= ~(1u << n)` — с инверсией маски.
- [ ] Маски записаны с суффиксом `u`: сдвиг знакового типа в старшие разряды недопустим.
- [ ] Проверка бита обёрнута в скобки: `(reg & mask) != 0` — приоритет `&` ниже, чем у `==`.
- [ ] Указатели на регистры объявлены `volatile`.
- [ ] Регистры имеют беззнаковый тип.
- [ ] Исходное состояние регистров **восстановлено** в конце.
- [ ] Вывод совпадает с `tests/expected.txt`: `DDR = 0b00001010`, `door=1 tamper=0`.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/gpio.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| соседние пины изменились | присваивание вместо `\|=` |
| после сброса обнулилось всё, кроме одного бита | забыта инверсия маски |
| условие всегда ложно | `reg & MASK == 0` без скобок |
| странное поведение старших бит | маска без суффикса `u` |
| в реальном железе цикл ожидания зависает | отсутствует `volatile` |

## После выполнения

Люк откроется. И на проводе, идущем от щитка внутрь здания, обнаружится непрерывная передача — по одному проводу, значит биты идут по очереди.

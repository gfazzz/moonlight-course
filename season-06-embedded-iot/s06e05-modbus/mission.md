## Обстановка

Дмитрий подцепился к витой паре через оптическую развязку — не разрывая линию. В ней ходят короткие посылки: контроллер спрашивает, устройство отвечает.

Здесь уже не чётность. Здесь CRC-16, и его так просто не обманешь.

## Приказ

Написать `artifacts/modbus.c`: собрать запрос на чтение регистров с корректным CRC, разобрать ответ, проверить целостность и отвергнуть повреждённый кадр.

## Формат

```
запрос:  [адрес][функция][старт_hi][старт_lo][кол_hi][кол_lo][CRC_lo][CRC_hi]
ответ:   [адрес][функция][байт][данные...][CRC_lo][CRC_hi]
```

CRC-16/MODBUS: начальное значение `0xFFFF`, полином `0xA001` при сдвиге вправо.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Начальное значение CRC — `0xFFFF`, а не ноль.
- [ ] Полином `0xA001` — обратное представление для сдвига вправо.
- [ ] CRC считается по **всему кадру** до самого поля CRC, включая адрес и функцию.
- [ ] CRC записывается в кадр **младшим байтом вперёд**, тогда как данные — старшим.
- [ ] Проверка выполняется сведением к нулю: расчёт по кадру вместе с CRC даёт `0`.
- [ ] Целостность проверяется **до** извлечения значений регистров.
- [ ] Повреждённый кадр отвергается с явным сообщением, а не разбирается.
- [ ] Значения регистров собираются из двух байт старшим вперёд.
- [ ] Вывод совпадает с `tests/expected.txt`: запрос `11 03 00 6B 00 03 76 87`, регистры `555, 0, 100`.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/modbus.c
make test
```

Проверьте себя на эталоне: кадр `11 03 00 6B 00 03` обязан дать CRC `0x8776`, то есть байты `76 87` в линии. Это канонический пример из спецификации — не сошлось, значит ошибка в алгоритме, а не в данных.

Эталон решения — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| CRC не совпадает с эталонным `0x8776` | полином `0x8005` вместо `0xA001` |
| кадры с ведущими нулями проходят | начальное значение ноль |
| устройство не принимает запрос | CRC записан старшим байтом вперёд |
| проверка не сводится к нулю | CRC посчитан не по всему кадру |
| значения регистров вдвое больше | перепутано количество регистров и байт |

## После выполнения

Три регистра назовут обороты вентиляции, состояние насоса и положение заслонки. Дмитрий посмотрит на них и скажет, что в серверных заслонок не бывает.

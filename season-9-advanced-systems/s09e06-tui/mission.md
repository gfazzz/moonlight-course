# Mission — s09e06 «TUI: терминал как экран»

## Что сдать
`artifacts/tui.c`: мини-фреймворк текстового интерфейса — буфер экрана, примитивы рисования и диффер кадров.

## Дано
- Экран 40×12; одна ячейка = один байт + атрибут.
- Пять кадров монитора: первый показ, рост нагрузки, обнаружение угроз, тревога, повтор без изменений.

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Рендер идёт **в память**; программа работает без TTY (тест запускает её через канал).
- [ ] `put()` отсекает координаты за границами — рисование за краем не портит память.
- [ ] `box()` рисует рамку из `+ - |` и вписывает заголовок.
- [ ] `gauge()` заполняет `filled = percent * w / 100` ячеек символом `#`, остальное — `.`.
- [ ] `diff_cells()` считает ячейки, отличающиеся символом **или** атрибутом.
- [ ] Стратегия вывода выбирается по стоимости: нет изменений → ничего не шлём; дифф дешевле → шлём разницу; иначе → перерисовка целиком.
- [ ] Текст внутри экрана — только ASCII (одна ячейка = один байт; про UTF-8 см. `theory.md`).
- [ ] Все строки экрана одинаковой ширины (тест проверяет отдельно).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Ожидаемые числа

|---|---|---|

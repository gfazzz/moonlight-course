## Обстановка

Одиннадцать миллионов строк в выгрузке, и ни одна не говорит о состоянии системы. Нужен монитор, обновляющийся на месте.

Перерисовка целиком мерцает. Вывод по координатам напрямую делает код непроверяемым.

## Приказ

Написать `artifacts/tui.c`: мини-фреймворк текстового интерфейса — буфер экрана, примитивы рисования и сравнение кадров.

## Дано

- Экран 40×12; одна ячейка — один байт плюс атрибут.
- Пять кадров монитора: первый показ, рост нагрузки, обнаружение угроз, тревога, повтор без изменений.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Рендер идёт **в память**; программа работает без терминала.
- [ ] `put()` отсекает координаты за границами.
- [ ] `box()` рисует рамку из `+ - |` и вписывает заголовок.
- [ ] `gauge()` заполняет `percent * w / 100` ячеек символом `#`, остальное — точками.
- [ ] Сравнение кадров считает ячейки, отличающиеся символом **или** атрибутом.
- [ ] Стратегия выбирается по стоимости: нет изменений — ничего; разница дешевле — разница; иначе — перерисовка.
- [ ] Текст внутри экрана — только ASCII.
- [ ] Все строки экрана одинаковой ширины.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/tui.c
make test
```

Поучительная проверка: отправляйте разницу всегда, без сравнения стоимости. Первый кадр обойдётся втрое дороже полной перерисовки — при том, что «шлём только изменения» звучит как безусловная оптимизация.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| порча памяти при рисовании у края | нет отсечения координат в `put()` |
| первый кадр дороже перерисовки | стратегия не выбирается по стоимости |
| изменение цвета не замечено | сравниваются только символы |
| строки экрана разной длины | буфер заполнен не полностью |
| вёрстка разъезжается | в ячейки попал не-ASCII |
| индикатор заполнен неверно | округление в другую сторону |

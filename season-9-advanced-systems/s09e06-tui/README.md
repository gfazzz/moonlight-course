## Сцена

LUNA переключает терминал в режим, где он перестаёт быть «печатной машинкой».

```
[LUNA] Терминал умеет ставить курсор в любую точку. Это просто байты: ESC, скобка, координаты.
[LUNA] Но не вздумай перерисовывать весь экран в цикле — получишь мерцание и тормоза по SSH.
[LUNA] Рисуй в буфер. Сравнивай с предыдущим кадром. Отправляй только разницу.
[LUNA] И заодно твой код станет тестируемым: буфер можно сравнить с эталоном без терминала.
```

## Теория: буфер, потом вывод

```
состояние -> [рендер] -> буфер ячеек -> [вывод] -> терминал
```

Рендер становится **чистой функцией** — тот же вход даёт тот же буфер, и его можно сравнить с эталоном (так и работает тест, без TTY). Дальше сравниваем кадры и шлём только изменения.

Но выигрыш не безусловен: позиционирование курсора стоит ~9 байт против 1 байта символа. Изменилось много — дешевле перерисовать целиком. В задаче это видно на числах. Про termios, `wcwidth` и `SIGWINCH` — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про экран.
```

**1.** LUNA: «Диффер шлёт только изменения. Почему на первом кадре он проиграл полной перерисовке?»

<details><summary>Ответ</summary>

Каждая изменённая ячейка требует позиционирования курсора (`ESC[y;xH` ≈ 9 байт) плюс сам символ. Когда меняется большая часть экрана (186 ячеек из 480), суммарно выходит дороже, чем вывести все 480 символов подряд. Порог примерно 15% экрана — поэтому стратегию выбирают по стоимости, а не догматически.
</details>

**2.** LUNA: «Почему текст внутри экрана только ASCII?»

<details><summary>Ответ</summary>

Ячейка хранит один байт, а кириллица в UTF-8 занимает два байта на символ — вёрстка разъедется. Настоящие TUI хранят кодовую точку и считают ширину через `wcwidth()` (иероглифы и эмодзи занимают две колонки), а также обрабатывают кластеры графем.
</details>

```
[LUNA] Верно. Рисуй.
```

## Разбор типичных ошибок

1. **Рисовать сразу в терминал.** Код становится непроверяемым и мерцает. Сначала буфер.
2. **`put()` без отсечения.** Рисование за краем портит соседнюю память.
3. **Всегда слать дифф.** На первом кадре это дороже полной перерисовки — сравнивай стоимость.
4. **Кириллица в ячейках.** Один байт на ячейку + UTF-8 = сломанная вёрстка.

## Debriefing

Интерфейс есть. Но данные, которые он показывает, приходят с датчиков — а датчики врут. Радар даёт координаты с шумом, и «сырую» отметку показывать оператору нельзя: цель будет прыгать. Нужна оценка, которая объединяет предсказание модели и зашумлённое измерение.

```
[LUNA] Красиво. Но цифры на этом экране — с радара, а радар шумит.
[LUNA] Показывать сырое измерение нельзя: отметка запляшет, оператор потеряет цель.
[LUNA] Нужен фильтр, который взвешивает: насколько верить модели, насколько — датчику.
[LUNA] Фильтр Калмана. Дальше — s09e07.
```

**Навык разблокирован:** ANSI, сырой режим, буфер кадра, damage tracking.

# Mission — s09e02 «Парсер и AST»

## Что сдать
`artifacts/parser.c`: парсер методом рекурсивного спуска, строящий абстрактное синтаксическое дерево (AST) для арифметических выражений, и три обхода этого дерева.

## Грамматика

```
expr   := term   (('+' | '-') term)*        левоассоциативно
term   := factor (('*' | '/') factor)*      левоассоциативно
factor := NUM | '(' expr ')' | '-' factor   унарный минус правоассоциативен
```

Лексер дан готовым — задача только в разборе.

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Каждому уровню приоритета — своя функция; повторение операторов оформлено **циклом**, а не левой рекурсией (иначе бесконечный спуск).
- [ ] Узлы берутся из статического пула (`POOL`), `malloc` не используется.
- [ ] `print_sexpr` печатает скобочную запись: `(+ 3 (* 4 2))`, унарный минус — `(neg 8)`.
- [ ] `print_rpn` печатает постфиксную запись, **пробел после каждого** элемента.
- [ ] `eval` вычисляет дерево; деление на ноль даёт `0` (без падения).
- [ ] Ошибки ловятся: незавершённое выражение (`7 + `) и незакрытая скобка (`(1 + 2`) → `ошибка разбора`. Остаток токенов после выражения — тоже ошибка.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Контрольные случаи (то, что проверяет тест)

| Вход | AST | Значение |
|---|---|---|
| `3 + 4 * 2` | `(+ 3 (* 4 2))` | 11 |
| `(3 + 4) * 2` | `(* (+ 3 4) 2)` | 14 |
| `100 - 20 - 5` | `(- (- 100 20) 5)` | 75 |
| `-8 + 3 * -2` | `(+ (neg 8) (* 3 (neg 2)))` | −14 |


# Mission — s09e08 «Квантовые вычисления» (финал Season 9)

## Что сдать
`artifacts/quantum.c`: симулятор квантового регистра — гейты `H`, `X`, `Z`, `CNOT`, демонстрация суперпозиции, запутанности и интерференции, плюс алгоритм Гровера.

## Дано
- 3 кубита → вектор из 8 комплексных амплитуд.
- Цель поиска Гровера — состояние `|110>` (индекс 6), 2 итерации.
- Комплексные числа реализуются вручную (`re`, `im`); `sqrt` — свой, без `-lm`.

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**.
- [ ] Однокубитные гейты обрабатывают **пары** индексов, различающиеся битом `q`, ровно один раз.
- [ ] `H` вносит множитель `1/√2`; **сумма вероятностей всегда равна 1** (тест проверяет каждую строку).
- [ ] `CNOT` действует только там, где управляющий кубит равен 1.
- [ ] Состояние Белла содержит **только** `|000>` и `|011>` — вариантов с несовпадающими кубитами нет.
- [ ] Пара `H → Z → H` демонстрирует интерференцию: результат — определённое состояние `|001>`.
- [ ] Гровер: оракул меняет знак амплитуды цели, диффузия отражает относительно среднего; после 2 итераций вероятность цели **94.5%**.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/quantum.c
make test
```

Тест отдельно проверяет нормировку, отсутствие `|001>`/`|010>` в состоянии Белла и результат Гровера.

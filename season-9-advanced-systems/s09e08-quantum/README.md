## Теория: фаза решает

Однокубитный гейт действует на **пары** индексов, различающиеся битом `q`:

```
H:  amp[i] = (a + b)/√2      amp[j] = (a − b)/√2
Z:  меняет знак амплитуд, где бит q = 1
```

**Суперпозиция** сама по себе бесполезна — измерение даёт один случайный исход. Работает **интерференция**: после `H → Z → H` вероятности на промежуточном шаге не менялись, но результат стал определённым `|001>`.

**Гровер**: оракул помечает цель сменой знака, диффузия отражает амплитуды относительно среднего — цель усиливается. Оптимум ≈ `(π/4)·√N` итераций; больше — **хуже**. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса. Последние в этом сезоне.
```

**1.** LUNA: «Восемь состояний в суперпозиции — значит, мы посчитали функцию для всех восьми входов сразу?»

<details><summary>Ответ</summary>

Посчитать — да, но **прочитать** нельзя: измерение даёт ровно один случайный исход, остальное разрушается. Поэтому «квантовый параллелизм» сам по себе не даёт ускорения. Алгоритм должен ещё и построить интерференцию так, чтобы неправильные ответы погасили друг друга.
</details>

**2.** LUNA: «Два шага Гровера дали 94.5%. Сделаем двадцать — получим 99.9%?»

<details><summary>Ответ</summary>

Нет, станет хуже. Каждая итерация поворачивает вектор состояния к цели на фиксированный угол; после оптимума (≈ `(π/4)·√N` шагов) он проходит мимо, и вероятность начинает падать. Квантовые алгоритмы требуют **точного** числа итераций.
</details>

```
[LUNA] Верно. Запускай симулятор.
```

## Разбор типичных ошибок

1. **Обработать пару дважды.** Гейт применится вторично и «откатится» — пропускай индексы с установленным битом.
2. **Забыть `1/√2` в `H`.** Нормировка ломается, сумма вероятностей перестаёт быть единицей.
3. **Считать `Z` бесполезным.** Он не меняет вероятности, но именно фазы делают возможной интерференцию.
4. **Крутить Гровера «побольше».** После оптимума вероятность цели падает.

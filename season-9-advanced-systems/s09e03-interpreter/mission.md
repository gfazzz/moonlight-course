# Mission — s09e03 «Интерпретатор»

## Что сдать
`artifacts/interp.c`: интерпретатор языка **MOON** — переменные, присваивание, `if/else`, `while`, `print`, плюс ошибки времени выполнения.

## Язык

```
программа := оператор*
оператор  := ident '=' expr ';'
           | 'print' expr ';'
           | 'if' '(' expr ')' блок ('else' блок)?
           | 'while' '(' expr ')' блок
блок      := '{' оператор* '}' | оператор
expr      := sum (('==' | '!=' | '<' | '<=' | '>' | '>=') sum)*
sum       := term (('+' | '-') term)*
term      := factor (('*' | '/') factor)*
factor    := NUM | ident | '(' expr ')' | '-' factor
```

Истина — любое ненулевое значение; сравнение возвращает `1` или `0`.

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Окружение: таблица «имя → значение»; повторное присваивание обновляет переменную, а не добавляет новую.
- [ ] **Отложенное вычисление ветвей**: тело `if` выполняется только при истинном условии, `else` — только при ложном. Невыбранная ветвь всё равно **разбирается** (иначе поток токенов собьётся), но не исполняется.
- [ ] `while` перечитывает условие каждую итерацию — лексер возвращается к сохранённой позиции.
- [ ] Защита от вечного цикла: более 10000 итераций → ошибка.
- [ ] Ошибки времени выполнения: неизвестная переменная и деление на ноль печатают сообщение и останавливают программу; `print` при этом **ничего не выводит**.
- [ ] После каждой программы печатается состояние окружения.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Контрольные программы

| Программа | Ожидание |
|---|---|
| `x = 3 + 4 * 2; y = (x-1)*2;` | `x=11 y=20` |
| `if (threat >= 10) {...} else {...}` | выполняется ровно одна ветвь |
| сумма `1..5` циклом | `print: 15` |
| факториал 5 циклом | `print: 120` |


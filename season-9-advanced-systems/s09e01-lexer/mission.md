# Mission — s09e01 «Лексер»

> **Season 9: меньше подсказок.** В `starter.c` теперь только интерфейс. Пошаговых TODO нет — ТЗ ниже и формат вывода в `tests/expected.txt` заменяют их.

## Что сдать
`artifacts/lexer.c`: лексический анализатор языка **MOON** — превращает исходный текст в поток токенов с позициями.

## Язык MOON (то, что должен распознавать лексер)

| Категория | Элементы |
|---|---|
| Числа | целые без знака: `12`, `0`, `1024` |
| Идентификаторы | буквы, цифры, `_`; не начинаются с цифры |
| Ключевые слова | `if`, `else`, `while`, `print` |
| Операторы | `+ - * /`, `=`, `== != < <= > >=` |
| Разделители | `( ) { } ;` |
| Комментарии | `// до конца строки` — пропускаются |
| Пробельные | пробел, табуляция, перевод строки — пропускаются |

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] **Longest match**: `>=` — один токен `GE`, а не `GT` + `ASSIGN`. То же для `<=`, `==`, `!=`.
- [ ] Ключевые слова отделяются от идентификаторов **после** чтения слова целиком (иначе `iffy` разберётся как `if` + `fy`).
- [ ] Каждый токен несёт позицию: `line` и `col` начала, нумерация с 1; после `\n` столбец сбрасывается.
- [ ] Число сохраняет значение в поле `value`.
- [ ] Неизвестный символ даёт токен `T_ERROR` — лексер **не падает** и продолжает работу.
- [ ] Поток завершается токеном `T_EOF`.
- [ ] Вывод совпадает с `tests/expected.txt` (44 токена, 8 чисел, 9 идентификаторов, 3 ключевых слова, 1 ошибка); `make test` → `PASS`.

cp starter.c artifacts/lexer.c
make test

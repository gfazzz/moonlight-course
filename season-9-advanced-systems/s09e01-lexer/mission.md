## Обстановка

Конфигурации их инфраструктуры написаны на неизвестном скриптовом языке. Чтобы читать чужие скрипты, нужен свой интерпретатор.

Начинается он с самого низа: символы надо превратить в слова.

## Приказ

Написать `artifacts/lexer.c`: лексический анализатор языка **MOON**, превращающий исходный текст в поток токенов с позициями.

## Язык MOON

| Категория | Элементы |
|---|---|
| числа | целые без знака: `12`, `0`, `1024` |
| идентификаторы | буквы, цифры, `_`; не начинаются с цифры |
| ключевые слова | `if`, `else`, `while`, `print` |
| операторы | `+ - * /`, `=`, `== != < <= > >=` |
| разделители | `( ) { } ;` |
| комментарии | `// до конца строки` — пропускаются |
| пробельные | пробел, табуляция, перевод строки — пропускаются |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] **Максимальное совпадение**: `>=` — один токен, а не два. То же для `<=`, `==`, `!=`.
- [ ] Ключевые слова отделяются от идентификаторов **после** чтения слова целиком.
- [ ] Каждый токен несёт позицию: строка и столбец начала, нумерация с единицы.
- [ ] Столбец сбрасывается после перевода строки.
- [ ] Число сохраняет разобранное значение в поле `value`.
- [ ] Комментарий распознаётся по двум слэшам и не путается с делением.
- [ ] Неизвестный символ даёт токен ошибки; лексер **не падает** и продолжает работу.
- [ ] Поток завершается токеном конца файла.
- [ ] Вывод совпадает с `tests/expected.txt`: 44 токена, 8 чисел, 9 идентификаторов, 3 ключевых слова, 1 ошибка.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/lexer.c
make test
```

Поучительная проверка: выдайте токен `>` сразу, не глядя на следующий символ. Тест покажет `GT` и `ASSIGN` вместо `GE` — язык молча станет другим языком.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| вместо `GE` два токена | не проверен следующий символ перед выдачей |
| `iffy` разобрано как `if` + `fy` | ключевое слово опознано до чтения слова целиком |
| позиции уехали со второй строки | столбец не сбрасывается после `\n` |
| комментарий стал делением | не обработан случай двух слэшей подряд |
| лексер завершился на `@` | неизвестный символ считается фатальным |
| последний токен потерян | не выдан токен конца файла |

## Теория: слова без грамматики

```
текст -> [лексер] -> токены -> [парсер] -> AST -> [интерпретатор] -> результат
```

Токен несёт не только тип, но и **позицию** — без неё компилятор не скажет, где ошибка. Два правила, на которых спотыкаются:

- **longest match**: увидев `>`, посмотри на следующий символ — `>=` это один токен;
- **ключевые слова — потом**: сначала прочитай слово целиком, затем сверься с таблицей, иначе `iffy` разрежется на `if` + `fy`.

Лексер принципиально не умеет считать вложенность — парность скобок не его работа. Подробнее — [`theory.md`](theory.md).

**1.** LUNA: «Почему нельзя выдавать `T_KEYWORD` сразу, как увидел буквы `if`?»

<details><summary>Ответ</summary>

Потому что идентификатор `iffy` начинается так же — его разрежет пополам. Правильный порядок: прочитать слово целиком по правилу идентификатора, а затем проверить по таблице ключевых слов.
</details>

**2.** LUNA: «Может ли лексер проверить, что скобки расставлены парно?»

<details><summary>Ответ</summary>

Нет, принципиально. Лексика описывается регулярными выражениями, а регулярные языки не умеют считать вложенность (нет памяти о глубине). Парность — работа парсера с контекстно-свободной грамматикой.
</details>

## Разбор типичных ошибок

1. **`>=` как два токена.** Нарушение longest match: проверяй второй символ до выдачи одиночного.
2. **Ключевые слова «на лету».** `iffy` разрежется пополам. Сначала слово, потом таблица.
3. **Забыть про позиции.** Без `line`/`col` диагностика бесполезна; столбец сбрасывается после `\n`.
4. **Падать на неизвестном символе.** Выдай `T_ERROR` и продолжай — пользователь увидит все ошибки сразу.

## Debriefing

Поток нарезан на слова. Но `x = 3 + 4 * 2` — это пока просто восемь токенов подряд: лексер не знает, что умножение старше сложения. Структуру задаёт грамматика.

```
[LUNA] Слова есть. Смысла нет: для лексера "3 + 4 * 2" — просто пять токенов.
[LUNA] Кто с кем связан и что вычисляется первым — определяет грамматика.
[LUNA] Строим дерево разбора методом рекурсивного спуска. Дальше — s09e02.
```

**Навык разблокирован:** лексический анализ, токены, longest match, позиции и диагностика.

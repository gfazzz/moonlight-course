## Теория: взвесить два вранья

```
предсказание:  x = x + v·dt        P = F·P·Fᵀ + Q      неопределённость растёт
коррекция:     K = P/(P + R)       x += K·(z − x)      неопределённость падает
```

`K → 1` — верим датчику (модель неуверена), `K → 0` — верим модели (датчик шумит). Фильтр настраивает баланс **сам**, отслеживая собственную неопределённость.

Ключ к скорости — **корреляция**: шаг предсказания связывает ошибку положения с ошибкой скорости (`p01`, `p10`), поэтому `K1 = p10/S` ненулевой и невязка по координате правит скорость. При скалярной `P` этого не произойдёт. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про оценивание.
```

**1.** LUNA: «Радар измеряет только координату. Откуда фильтр знает скорость?»

<details><summary>Ответ</summary>

Из корреляции. Шаг предсказания (`x += v·dt`) связывает ошибку скорости с ошибкой положения — это записано во внедиагональных элементах `P`. Поэтому усиление `K1 = p10/S` ненулевое, и невязка по координате корректирует скорость. Со скалярной `P` связи нет, `K1` всегда 0, и скорость навсегда останется стартовой.
</details>

**2.** LUNA: «Хочу более гладкий трек — занижу `Q` посильнее. Что не так?»

<details><summary>Ответ</summary>

Фильтр «уверует» в свою модель: `P` станет малой, `K` уйдёт почти в ноль, и измерения перестанут на него влиять. При манёвре цели он её потеряет — это расходимость (divergence). Признак в логах: невязка систематически одного знака.
</details>

```
[LUNA] Верно. Веди цель.
```

## Разбор типичных ошибок

1. **Скалярная `P`.** Скорость не выучится никогда: нет связи между переменными.
2. **Забыть `Q`.** `P` схлопнется в ноль, фильтр перестанет слушать измерения.
3. **Перепутать порядок шагов.** Сначала предсказание, потом коррекция — иначе измерение применяется к устаревшему состоянию.
4. **Обновлять `P` до вычисления `K`.** `K` считается по предсказанной ковариации.

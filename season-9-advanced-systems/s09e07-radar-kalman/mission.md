## Обстановка

Цель летит ровно, отметка радара пляшет в пределах десяти метров. Верить датчику нельзя — шумит. Верить модели нельзя — цель маневрирует.

Значит, надо взвешивать, и вес обязан меняться сам.

## Приказ

Написать `artifacts/kalman.c`: фильтр Калмана для сопровождения цели по зашумлённым измерениям — оценка положения **и** скорости.

## Дано

- Цель: старт 100 м, скорость 12 м/с, 30 шагов по одной секунде.
- Радар измеряет **только координату**; шум `sigma = 5` м (`R = 25`), шум процесса `Q = 0.05`.
- Фильтр стартует вслепую: `x = 0`, `v = 0`, ковариация `500` по диагонали.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`**: `sqrt` свой.
- [ ] Ковариация — матрица **2×2**, а не скаляр.
- [ ] Предсказание: `x += v·dt`, `P = F·P·Fᵀ + Q` с `F = [[1, dt], [0, 1]]`.
- [ ] Коррекция: `S = p00 + R`, `K0 = p00/S`, `K1 = p10/S`, обновление `x`, `v` и `P = (I − K·H)·P`.
- [ ] Усиление вычисляется по **предсказанной** ковариации, до её обновления.
- [ ] Скорость выучивается через внедиагональные элементы: при `p10 = 0` она не сойдётся.
- [ ] Оценка фильтра **точнее** сырого измерения — тест проверяет отдельно.
- [ ] Оценённая скорость сходится к истинной: отклонение меньше 1 м/с.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/kalman.c
make test
```

Поучительная проверка: обнулите внедиагональные элементы ковариации после каждого шага. Положение будет оцениваться по-прежнему хорошо, а скорость навсегда останется нулевой.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| скорость остаётся стартовой | ковариация скалярная или связь обнулена |
| фильтр перестаёт реагировать на измерения | забыт шум процесса |
| оценка хуже сырого измерения | усиление считается по обновлённой ковариации |
| фильтр отстаёт на постоянную величину | перепутан порядок предсказания и коррекции |
| сходимость занимает десятки шагов | начальная ковариация слишком мала |
| невязка систематически одного знака | шум процесса занижен, фильтр расходится |

# Mission — s09e07 «Радар и фильтр Калмана»

## Что сдать
`artifacts/kalman.c`: фильтр Калмана для сопровождения цели по зашумлённым измерениям радара — оценка положения **и** скорости.

## Дано
- Цель: старт 100 м, скорость 12 м/с, 30 шагов по 1 с.
- Радар измеряет **только координату**, шум `sigma = 5` м (`R = 25`), шум процесса `Q = 0.05`.
- Фильтр стартует «вслепую»: `x = 0`, `v = 0`, `P = 500` по диагонали.

## Требования

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` **без `-lm`** (`sqrt` — свой).
- [ ] Ковариация — матрица **2×2** (`p00, p01, p10, p11`), а не скаляр.
- [ ] Предсказание: `x += v·dt`, `P = F·P·Fᵀ + Q` с `F = [[1, dt], [0, 1]]`.
- [ ] Коррекция: `S = p00 + R`, `K0 = p00/S`, `K1 = p10/S`, обновление `x`, `v` и `P = (I − K·H)·P`.
- [ ] Скорость выучивается **через внедиагональные элементы** — при `p10 = 0` всегда `K1 = 0` и `v` не сойдётся.
- [ ] Оценка фильтра **точнее** сырого измерения (тест проверяет отдельно).
- [ ] Оценённая скорость сходится к истинной (отклонение < 1 м/с).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Ожидаемый результат

| Метрика | Значение |
|---|---|
| средняя ошибка измерения | 4.03 м |
| средняя ошибка оценки | **2.08 м** |
| выигрыш | 1.9× |
| оценённая скорость | 11.93 м/с (истина 12) |
| K0 | падает с ~0.95 до ~0.26 |

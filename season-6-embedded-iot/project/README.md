# Season Project — `iot_controller`

**Контроллер периметра: опрос устройств по Modbus и контроль доступа.**

Программа собирается из **модулей, написанных в предыдущих сериях и сезонах**, — они подключаются заголовками и линкуются как отдельные единицы трансляции, а не копируются.

## Из чего собрано

| Модуль | Откуда | Что даёт |
|---|---|---|
| `ml_hash.c` | `season-4/lib` (s04e03) | адресация устройств по имени |
| `ml_crc.c` | `season-6/lib` (s06e05) | CRC-16/MODBUS |
| `ml_wiegand.c` | `season-6/lib` (s06e04) | карты доступа Wiegand-26 |
| `main.c` | этот сезон | контроллер |

**4 единиц трансляции из 2 сезонов** компилируются раздельно и линкуются в один исполняемый файл.

## Сборка и запуск

```bash
make            # компиляция и линковка
make run        # запуск
make modules    # показать состав сборки
make test       # автотест
```

## Что проверяет тест

Тест проверяет не только вывод, но и **сам факт межсезонной сборки**:

1. модули существуют в своих сезонах и подключены **заголовками**;
2. в `main.c` **нет копий реализаций** — только вызовы (иначе «переиспользование» подменяется копипастой);
3. программа собирается из нескольких `.c` и проходит самопроверку.

## Что ты освоишь

- Кольцевой буфер фиксированного размера и скользящее среднее за O(1).
- Почему в embedded не зовут `malloc` в цикле реального времени.
- Конечный автомат тревоги и гистерезис против дребезга.

Глубже — в [`theory.md`](theory.md).

## Теория: сгладить и решить

```c
// кольцевой буфер + бегущая сумма -> среднее за O(1)
if (count == K) sum -= buf[head];
buf[head] = x; sum += x; head = (head + 1) % K;
avg = sum / count;
```

Среднее размывает одиночный выброс — ложной тревоги нет. Состояние тревоги — **автомат** с **гистерезисом**: вверх по одному порогу, вниз — по другому, ниже (зазор гасит дребезг у границы):

```
NORMAL ->60-> WARNING ->80-> ALARM
NORMAL <-50<- WARNING <-70<- ALARM
```

Про O(1)-сумму, медианный фильтр и debounce по времени — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про реальное время.
```

**1.** LUNA: «Почему пороги вверх (60/80) и вниз (50/70) разные, а не одна граница?»

<details><summary>Ответ</summary>

Одна граница даёт дребезг: у порога 60 сигнал 59↔61 будет прыгать между состояниями каждый отсчёт. Гистерезис вводит зазор — «мёртвую зону»: подняться на 60, а вернуться только на 50. Состояние стабильно. Тот же приём — в термостате и триггере Шмитта.
</details>

**2.** LUNA: «Зачем кольцевой буфер, если можно копить всю историю в массиве и усреднять?»

<details><summary>Ответ</summary>

Памяти на контроллере килобайты, а поток бесконечен — всю историю не сохранить. Кольцо фиксированного размера хранит последние K отсчётов и работает без `malloc`; с бегущей суммой среднее считается за O(1), а не проходом по всему массиву.
</details>

```
[Дмитрий] Верно. Запускай монитор.
```

## Разбор типичных ошибок

1. **`malloc` в цикле.** В реальном времени — нет: фрагментация и непредсказуемая задержка. Статический буфер.
2. **Пересчитывать сумму проходом.** Веди бегущую сумму: вычел старый, прибавил новый — O(1).
3. **Одна граница порога.** Без гистерезиса состояние дребезжит. Разнеси пороги вверх/вниз.
4. **Реагировать на сырой отсчёт.** Сначала сгладь окном — иначе каждый выброс = ложная тревога.

## Debriefing

Монитор датчиков работает: шум погашен, тревога честная. Ты «видишь» температуру и давление в периметре. Но охрана НИИ смотрит не датчиками, а камерами. Чтобы понять маршруты патрулей и найти слепые зоны, нужно перехватить видеопоток и обработать кадры — уже не байты, а пиксели.

```
[Дмитрий] Датчики под контролем. Осталось зрение — камеры. Их поток идёт по RTSP.
[LUNA]    Снимем два кадра и сравним пиксели: где изменилось — там движение.
[LUNA]    Найдём слепые зоны и патрули. Дальше — s06e07.
```

**Навык разблокирован:** кольцевой буфер, скользящее среднее, конечный автомат, гистерезис.

## Обстановка

Один отсчёт показал девяносто. Это или помеха, или начало процесса, и решать надо сейчас — от решения зависит, включится ли аварийная вентиляция.

Наивный порог даст дребезг: реле защёлкает по десять раз в минуту.

## Приказ

Написать `artifacts/sensors.c`: кольцевой буфер на четыре отсчёта, скользящее среднее, автомат из трёх состояний с гистерезисом, отметка переходов.

## Пороги

| Переход | Условие |
|---|---|
| `NORMAL` → `WARNING` | среднее ≥ 60 |
| `WARNING` → `ALARM` | среднее ≥ 80 |
| `ALARM` → `WARNING` | среднее ≤ 70 |
| `WARNING` → `NORMAL` | среднее ≤ 50 |

Пороги входа и выхода **намеренно различаются** — это и есть гистерезис.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Окно реализовано **кольцевым буфером**: добавление за константное время, без сдвига массива.
- [ ] До заполнения окна среднее считается по фактическому числу отсчётов, а не по `K`.
- [ ] Решение принимается по **среднему**, а не по сырому значению.
- [ ] Пороги входа и выхода различаются; переход обратно требует пройти зону нечувствительности.
- [ ] Состояние — перечисление, а не набор флагов.
- [ ] Переходы только между соседними состояниями: из `NORMAL` в `ALARM` напрямую нельзя.
- [ ] Моменты переходов отмечаются в выводе отдельно.
- [ ] Подписи состояний — **только ASCII**: поле фиксированной ширины считает байты.
- [ ] Вывод совпадает с `tests/expected.txt`: всплеск на `t=4` тревоги не вызывает, `WARNING` на `t=10`, `ALARM` на `t=12`, возврат на `t=16`.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/sensors.c
make test
```

Поучительная проверка: сделайте пороги входа и выхода одинаковыми и посмотрите на вывод. Состояние начнёт метаться — это и есть дребезг.

Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| тревога на `t=4` | решение по сырому значению вместо среднего |
| состояние меняется почти каждый отсчёт | пороги входа и выхода совпадают |
| первые значения среднего занижены | буфер до заполнения считается как полный |
| переход сразу в `ALARM` | пропущено промежуточное состояние |
| таблица разъезжается | кириллица в поле фиксированной ширины |

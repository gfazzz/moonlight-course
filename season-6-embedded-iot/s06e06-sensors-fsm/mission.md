# Mission — s06e06 «Датчики: кольцевой буфер и автомат»

## Что сдать
`artifacts/sensors.c`: обработчик потока датчика — кольцевой буфер фиксированного размера для скользящего среднего и конечный автомат тревоги с гистерезисом.

## Дано
- Поток из 18 отсчётов (°C), включающий одиночный выброс (t=4) и реальный устойчивый рост.
- Окно сглаживания `K=4`. Пороговые уровни: WARN `≥60`, ALARM `≥80`; возврат: `≤70` (ALARM→WARN), `≤50` (WARN→NORMAL).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Кольцевой буфер **без `malloc`**; скользящее среднее считается за O(1) (через `sum`).
- [ ] Автомат имеет **гистерезис**: пороги вверх и вниз различаются.
- [ ] Одиночный выброс сглаживается и **не** вызывает эскалацию.
- [ ] Переходы отмечаются (`ESCALATE`/`recover`).
- [ ] Вывод совпадает с `tests/expected.txt` (WARNING на t=10, ALARM на t=12, возврат к NORMAL к t=17); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/sensors.c
make test
```

## Оценка времени
~45–55 минут.

## Результат в сюжете
Твой монитор ведёт датчики НИИ в реальном времени: гасит шум, не паникует от одиночного всплеска и поднимает тревогу только на настоящую угрозу. Это глаза внутри периметра.

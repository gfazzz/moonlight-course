## Теория: байт, растянутый во времени

### Кадр

```
уровень
  1  ──┐   ┌───┐       ┌───┐   ┌──────
       │   │   │       │   │   │
  0    └───┘   └───────┘   └───┘
       ↑   ↑                   ↑
     старт данные (8 бит)     стоп
```

| Элемент | Длительность | Уровень |
|---|---|---|
| старт | 1 бит | всегда 0 |
| данные | 8 бит | младший бит первым |
| чётность | 1 бит | дополняет число единиц |
| стоп | 1–2 бита | всегда 1 |

В покое линия держит уровень 1. Переход в 0 означает старт — по нему приёмник и синхронизируется.

### Младшим битом вперёд

```
байт 0x4F = 0100 1111
по проводу:  1 1 1 1 0 0 1 0    (справа налево от исходного)
```

Порядок бит внутри байта, а не порядок байтов в слове. Это разные вещи: `htons` из Season 3 переставляет байты, здесь речь о битах внутри одного байта, и делает это аппаратура.

Историческая причина — сдвиговый регистр: младший бит выдвигается первым естественным образом.

### Чётность

```c
int ones = 0;
for (int i = 0; i < 8; i++) if (data & (1 << i)) ones++;
int parity_even = (ones % 2 == 0) ? 0 : 1;   /* дополнить до чётного */
```

При чётной схеме бит выбирается так, чтобы общее число единиц (включая сам бит) стало чётным.

Что ловит и чего не ловит:

| Ошибка | Заметит |
|---|---|
| один искажённый бит | да |
| два искажённых бита | **нет** |
| три искажённых | да |
| чётное число ошибок | нет |

Один бит защиты даёт ровно одну проверку. Для линии с редкими одиночными помехами этого достаточно; для чего-то серьёзнее нужен CRC — он будет в s06e05.

### Рассинхронизация

Общих часов нет. Обе стороны отсчитывают биты по своим генераторам, и если частоты расходятся, к концу кадра накапливается сдвиг.

Допустимое расхождение — около 2% для десятибитного кадра: за десять бит сдвиг не должен превысить половину битового интервала. Отсюда требование к точности генератора и известная проблема с кварцем на 8 МГц: для 115200 бод погрешность деления даёт 3.5% и связь не работает. Именно поэтому в микроконтроллерах ставят кварцы на 7.3728 МГц — число подобрано так, чтобы стандартные скорости получались точно.

Признак рассинхронизации — **стоповый бит не равен единице**. Приёмник считывает данные не там, где надо, и в позиции стопа оказывается что-то другое.

## Проверка на канале

```
[LUNA] Два вопроса про провод.
```

**1.** LUNA: «Чётность сошлась. Значит, данные целы?»

<details><summary>Ответ</summary>

Не обязательно. Один бит чётности обнаруживает нечётное число искажённых бит: одно искажение — да, два — нет. Если помеха перевернула два бита, число единиц изменилось на чётную величину, и проверка пройдёт при испорченных данных. Для линии с редкими одиночными помехами этого хватает, для промышленной шины — нет, там ставят CRC. Одна проверка ловит один класс ошибок, и знать её границы важнее, чем уметь её считать.
</details>

**2.** LUNA: «Стоповый бит оказался нулём. Что случилось?»

<details><summary>Ответ</summary>

Приёмник читает не там, где передатчик пишет. Стоповый бит по определению равен единице, поэтому ноль в его позиции означает рассинхронизацию: либо скорости сторон разошлись больше допустимого, либо начало кадра определено неверно — например, помеха была принята за стартовый бит. Это называют ошибкой кадрирования, и правильная реакция — не пытаться разобрать данные, а искать следующий старт заново.
</details>

```
[LUNA] Верно. Читай провод.
```

## Разбор типичных ошибок

1. **Биты собираются старшим вперёд.** UART передаёт младшим; байт получится перевёрнутым.
2. **Бит чётности включён в данные.** Он служебный и в байт не входит.
3. **Стоповый бит не проверяется.** Рассинхронизация останется незамеченной.
4. **Разбор прерывается на первой ошибке.** Битый кадр отмечают и идут дальше.
5. **Чётность считается только по данным.** В подсчёт входит и сам бит чётности — тогда сумма должна быть чётной.
6. **Сдвиг знакового типа.** Сборка байта — только на беззнаковых.

## Debriefing

Кадры разобраны. Шесть из восьми целы, два повреждены — у одного не сошлась чётность, у другого стоповый бит равен нулю.

Из целых складывается строка:

```
OPEN 7
```

Шесть байт, повторяющихся по кругу с интервалом в две секунды. Контроллер люка непрерывно сообщает кому-то, что дверь номер семь открыта, — и делает это с того момента, как ты снял блокировку сорок минут назад.

Дмитрий откладывает щуп.

> — Седьмая. Значит, их как минимум семь, и каждая рапортует.
>
> — И там знают, что она открыта?

> — Знают, что открыта. Не знают, кто открыл. Пока не знают.

Он сворачивает осциллограф и смотрит на схему щитка.

> — И заметь: два кадра из восьми битые. На линии в полтора метра. Это не помехи — это плохая земля или наводка от чего-то мощного. Что-то в этом подвале жрёт очень много тока.

Он проводит пальцем по схеме.

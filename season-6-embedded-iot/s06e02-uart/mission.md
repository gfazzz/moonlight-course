## Обстановка

По одному проводу от щитка идёт непрерывная передача: пачка импульсов, пауза, снова пачка. Скорость снята осциллографом — сто четыре микросекунды на бит.

Байт растянут во времени. Осталось прочитать.

## Приказ

Написать `artifacts/uart.c`: декодировать последовательность кадров, извлечь данные, проверить чётность и стоповый бит, отметить повреждённые кадры и собрать сообщение из целых.

## Формат кадра

| Позиция | Что | Значение |
|---|---|---|
| 0 | старт | всегда 0 |
| 1–8 | данные | **младшим битом вперёд** |
| 9 | чётность | чётная схема |
| 10 | стоп | всегда 1 |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Байт собирается **младшим битом вперёд**: первый бит данных — нулевой разряд.
- [ ] Бит чётности **не входит** в собранный байт.
- [ ] Чётность проверяется по всем битам, включая сам бит чётности: сумма должна быть чётной.
- [ ] Стоповый бит проверяется отдельно; ноль означает ошибку кадрирования.
- [ ] Повреждённый кадр **отмечается и не прерывает** разбор остальных.
- [ ] Сборка байта ведётся на беззнаковых типах.
- [ ] Для каждого кадра выводится состояние обеих проверок.
- [ ] Вывод совпадает с `tests/expected.txt`: восемь кадров, `6 ok, 2 errors`, сообщение `OPEN 7`.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/uart.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| байты перевёрнуты по битам | сборка старшим битом вперёд |
| значения вдвое больше ожидаемых | бит чётности попал в данные |
| все кадры «целы», хотя два повреждены | стоповый бит не проверяется |
| разбор останавливается на третьем кадре | ошибка прерывает цикл вместо отметки |
| чётность не сходится на корректных кадрах | сам бит чётности не учтён в сумме |

## После выполнения

Из целых кадров сложится короткое слово. Контроллер повторяет его по кругу с того момента, как ты снял блокировку.

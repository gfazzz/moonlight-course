# Mission — s06e02 «UART»

## Что сдать
`artifacts/uart.c`: декодер UART-кадров — извлечь байт, проверить чётность и стоп-бит, собрать сообщение из «провода» и отчитаться об ошибках.

## Дано
- «Провод»: массив 16-битных кадров. Кадр: бит0=start(0), биты1..8=данные, бит9=parity(even), бит10=stop(1).
- Сообщение `"OPEN 7"` + два дефектных кадра (испорчена чётность; сброшен стоп-бит).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `even_parity(b)` — XOR всех 8 бит (even parity).
- [ ] Проверяются start (=0) и stop (=1); нарушение → FRAMING ERROR.
- [ ] Чётность сверяется с вычисленной; расхождение → PARITY ERROR.
- [ ] Валидные байты собираются в строку сообщения.
- [ ] Вывод совпадает с `tests/expected.txt` (`"OPEN 7"`, 6 ok / 2 errors); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/uart.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
Ты читаешь язык, на котором контроллер люка «говорит» с остальными устройствами. Теперь понятно, как перехватывать и проверять его команды — и где в них шум, а где подмена.

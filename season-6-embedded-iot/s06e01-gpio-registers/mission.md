# Mission — s06e01 «GPIO и регистры»

## Что сдать
`artifacts/gpio.c`: управление аппаратными регистрами через битовые операции — сконфигурировать пины, зажечь/переключить выходы, прочитать входы, снять реле замка по условию.

## Дано
- Три 8-битных регистра (AVR-модель): `DDR` (направление), `PORT` (выход), `PIN` (вход).
- Пины: `LED=1`, `LOCK=3` (выходы), `DOOR=2`, `TAMPER=6` (входы).
- Стартовое состояние входов: датчик двери замкнут, вскрытия нет.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Используются все четыре операции: set `|=`, clear `&= ~`, toggle `^=`, read `>> & 1`.
- [ ] Замок снимается только если `door && !tamper`.
- [ ] Регистры печатаются в двоичном виде (биты 7..0) и hex.
- [ ] Вывод совпадает с `tests/expected.txt` (финал: LOCK LOW → SECURED); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/gpio.c
make test
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Ты понял, как код говорит с железом: один бит — один вывод. Этого достаточно, чтобы снять техническую блокировку сервисного люка НИИ и войти внутрь.

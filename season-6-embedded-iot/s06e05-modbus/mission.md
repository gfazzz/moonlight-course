# Mission — s06e05 «Modbus RTU»

## Что сдать
`artifacts/modbus.c`: собрать запрос Modbus RTU «read holding registers», посчитать и дописать CRC-16, проверить CRC ответа, извлечь значения регистров и отбраковать повреждённый кадр.

## Дано
- Кадр: адрес + функция + данные + CRC-16 (2 байта, младший первым).
- CRC-16/MODBUS: init `0xFFFF`, отражённый полином `0xA001`, без финального XOR.
- Запрос: slave `0x11`, функция `0x03`, старт `0x006B`, 3 регистра. Ответ: 3 значения.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `crc16` реализована по алгоритму MODBUS (init `0xFFFF`, полином `0xA001`).
- [ ] CRC дописывается младшим байтом вперёд; проверка сверяет посчитанное с принятым.
- [ ] Регистры собираются как big-endian (`hi<<8 | lo`).
- [ ] Повреждённый кадр (искажён байт) даёт CRC FAIL и отвергается.
- [ ] Вывод совпадает с `tests/expected.txt` (request CRC `76 87`, регистры 555/0/100); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/modbus.c
make test
```

## Оценка времени
~45–55 минут.

## Результат в сюжете
Ты опрашиваешь PLC, управляющий вентиляцией и шлюзами лаборатории, и читаешь его регистры. CRC гарантирует, что команда дошла без искажений, — а значит, ей можно доверять или, наоборот, поймать подмену.

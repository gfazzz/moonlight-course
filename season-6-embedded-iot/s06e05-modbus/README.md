## Теория: кадр + CRC

```
[ slave ][ func ][ data... ][ CRC lo ][ CRC hi ]
```

```c
uint16_t crc = 0xFFFF;
for each byte { crc ^= byte;
    for (8) crc = (crc & 1) ? (crc>>1) ^ 0xA001 : (crc>>1); }
```

CRC надёжнее чётности: ловит двойные и пакетные ошибки, которые parity пропускает. Дописывается **младшим байтом вперёд** — фирменная деталь Modbus. Проверка: пересчитать по всем байтам, кроме двух последних, и сравнить. Про отражённый полином и безопасность — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса, прежде чем ты отправишь команду на PLC.
```

**1.** LUNA: «Почему в промышленной сети берут CRC-16, а не привычный бит чётности?»

<details><summary>Ответ</summary>

Parity не видит чётное число ошибок, а в цеху помехи от приводов рвут пакеты бит. CRC-16 ловит все одиночные/двойные, любые нечётные и пакеты до 16 бит. Исполнить искажённую команду на реальном клапане — недопустимо, поэтому контроль строже.
</details>

**2.** LUNA: «CRC ответа сошёлся. Значит ли это, что команду прислал легитимный узел?»

<details><summary>Ответ</summary>

Нет. CRC подтверждает лишь отсутствие искажений в линии. Классический Modbus без аутентификации: злоумышленник посчитает корректный CRC для поддельной команды. Защита — изоляция сети, а не протокол.
</details>

```
[Дмитрий] Верно. Опрашивай контроллер.
```

## Разбор типичных ошибок

1. **Порядок байт CRC.** Modbus кладёт младший байт первым; перепутаешь — проверка всегда падает.
2. **Полином.** Для сдвига вправо это `0xA001` (отражённый `0x8005`), не `0x8005`.
3. **init 0x0000.** Modbus стартует с `0xFFFF`, иначе не ловятся ведущие нули.
4. **Порядок регистров.** Значения big-endian: `hi<<8 | lo`, в отличие от CRC.

## Debriefing

Регистры PLC прочитаны, CRC отсекает искажения. Но одиночный опрос — это снимок. Датчики НИИ шлют поток измерений непрерывно, и реагировать надо в реальном времени: сгладить шум, поймать тревогу, не дёрнуться на единичный выброс. Для этого на контроллере нужен кольцевой буфер и конечный автомат — без всякого `malloc`.

```
[Дмитрий] Регистр ты снял. Но датчик сыпет данные потоком, а памяти на чипе — крохи.
[LUNA]    Кольцевой буфер фиксированного размера и автомат состояний с антидребезгом.
[LUNA]    Норма, тревога, авария — и никакого malloc. Дальше — s06e06.
```

**Навык разблокирован:** Modbus RTU, CRC-16, разбор кадра, отбраковка по контрольной сумме.

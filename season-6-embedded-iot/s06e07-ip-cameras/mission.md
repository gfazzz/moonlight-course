# Mission — s06e07 «IP-камеры: детект движения»

## Что сдать
`artifacts/motion.c`: детектор движения по двум кадрам — разность пикселей, порог против шума, карта изменений и разбиение на зоны (где движение, где «слепо»).

## Дано
- Два grayscale-кадра 8×8 (значения пикселей 0–255).
- Порог `THRESH=40` (ниже — шум сенсора). Движение считается при `≥ MIN_PIX=3` изменённых пикселях.
- «Охранник» — яркий блок 2×2 — смещается из верхнего-левого квадранта в нижний-правый.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Разность считается как `abs(f2 - f1)` по каждому пикселю; порог отсекает подпороговый шум.
- [ ] Строится ASCII-карта изменений (`#`/`.`).
- [ ] Изменённые пиксели считаются по 4 квадрантам; пустой квадрант помечается BLIND.
- [ ] Вывод совпадает с `tests/expected.txt` (8 изменённых, top-left и bottom-right — motion; два — BLIND); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/motion.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
Ты «видишь» глазами камер НИИ: разность кадров показывает, где прошёл патруль, а два квадранта остаются слепыми — это твой коридор внутри периметра.

# Mission — s06e04 «Wiegand / СКУД»

## Что сдать
`artifacts/wiegand.c`: декодер Wiegand-26 — разобрать кадр на facility/card, проверить обе чётности и принять решение о доступе по списку разрешённых facility.

## Дано
- Формат 26 бит: `[25]` ведущая чётность (even по битам 24..13), `[24..17]` facility, `[16..1]` card, `[0]` замыкающая чётность (odd по битам 12..1).
- Разрешённый facility — `42`.
- Три карты: валидная, испорченная (1 бит), клон с чужим facility.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `xor_bits(v, hi, lo)` — XOR бит диапазона; используется для обеих чётностей.
- [ ] Ведущая чётность — even, замыкающая — odd (инверсия XOR).
- [ ] Решение: битая чётность → DENY (corrupt); чужой facility → DENY (unauthorized); иначе GRANT.
- [ ] Вывод совпадает с `tests/expected.txt` (A GRANT, B DENY-parity, C DENY-facility); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/wiegand.c
make test
```

## Оценка времени
~45–55 минут.

## Обстановка

Считыватель передаёт контроллеру двадцать шесть бит по двум проводам. Ни шифрования, ни ключа, ни вызова-ответа — просто число.

Три пропуска на столе: один рабочий, один повреждённый, один чужой.

## Приказ

Написать `artifacts/wiegand.c`: разобрать посылки, извлечь код объекта и номер карты, проверить обе чётности, принять решение о доступе с указанием причины отказа.

## Раскладка посылки

| Биты | Поле | Ширина |
|---|---|---|
| 0 | `P0` — чётная | 1 |
| 1–8 | код объекта | 8 |
| 9–24 | номер карты | 16 |
| 25 | `P1` — нечётная | 1 |

`P0` покрывает биты 1–12, `P1` — биты 13–24. Нумерация от старшего бита.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Посылка хранится в **беззнаковом** типе шириной не менее 26 бит.
- [ ] Поля извлекаются сдвигом и маской; смещения соответствуют нумерации от старшего бита.
- [ ] Проверяются **обе** чётности, причём `P0` по чётной схеме, а `P1` по нечётной.
- [ ] Целостность проверяется **до** авторизации.
- [ ] Причины отказа различаются: повреждённая посылка и неразрешённый объект — разные вердикты.
- [ ] Для каждого пропуска выводится состояние обеих чётностей отдельно.
- [ ] Вывод совпадает с `tests/expected.txt`: A — `GRANT`, B — `DENY (corrupt card)`, C — `DENY (facility 99 not authorized)`.
- [ ] `make test` → `PASS`.

## Выполнение

Проверьте себя на известном значении: `facility=42, card=1337` обязано давать `0x2540A73`. Не сошлось — ошибка в смещениях, а не в данных.

Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| поля читаются правдоподобно, но неверно | смещение ошиблось на единицу |
| повреждённый пропуск проходит | проверяется только одна чётность |
| корректный пропуск отвергается | обе чётности посчитаны по одной схеме |
| чужой объект получает `DENY (corrupt)` | авторизация проверена до целостности |
| старший бит теряется | посылка хранится в знаковом типе |

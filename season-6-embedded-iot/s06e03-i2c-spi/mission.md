# Mission — s06e03 «I2C/SPI»

## Что сдать
`artifacts/i2c.c`: клиент шины — опросить датчик по адресу, проверить его ID, запустить измерение, прочитать статус и 16-битное значение из двух регистров; корректно обработать ACK/NACK.

## Дано
- Датчик на шине по адресу `0x76`, ожидаемый chip id `0x58` в регистре `0xD0`.
- Регистры: `0xF3` STATUS, `0xF4` CTRL_MEAS, `0xFA/0xFB` сырое значение (MSB/LSB).
- `0xD0` — только для чтения.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `i2c_read`/`i2c_write` возвращают ACK(0)/NACK(-1) по адресу; запись в read-only → -2.
- [ ] ID сверяется с `CHIP_ID`; обращение к чужому адресу даёт NACK.
- [ ] 16-битное значение собирается как `(msb<<8)|lsb` (старший байт первым).
- [ ] Запуск измерения выставляет `data_ready` в STATUS.
- [ ] Вывод совпадает с `tests/expected.txt` (RAW `0x0A2B = 2603 → 26.03`); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/i2c.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
Ты снимаешь показания промышленных датчиков НИИ, не трогая их физически, — читаешь их регистры по шине. Следующая цель серьёзнее: система контроля доступа на дверях.

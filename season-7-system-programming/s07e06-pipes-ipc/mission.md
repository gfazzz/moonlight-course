# Mission — s07e06 «Каналы (IPC)»

## Что сдать
`artifacts/pipes.c`: двусторонний обмен между родителем и потомком через два канала плюс конвейер `echo | tr`, собранный вручную через `dup2`.

## Дано
- Сообщение потомку: `"SCAN 47 TARGETS"` (15 байт).
- Ответ потомка: `"OK:<число прочитанных байт>"`.
- Конвейер: `/bin/echo "stealth agent online"` → `tr a-z A-Z`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Используются **два** канала: прямой и обратный (один канал однонаправлен).
- [ ] Каждая сторона закрывает неиспользуемые концы; писатель закрывает свой конец, чтобы читатель увидел EOF.
- [ ] Потомок отвечает числом прочитанных байт; родитель сверяет его с длиной сообщения.
- [ ] Конвейер собран через `dup2` на `STDOUT_FILENO`/`STDIN_FILENO`; родитель закрывает **оба** конца.
- [ ] Программа не зависает (тест обрывает через 10 с).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/pipes.c
make test
```

## Оценка времени
~50–60 минут.

Части `stealth_agent` — разные процессы с раздельной памятью — научились разговаривать. Ровно так же оболочка соединяет команды символом `|`.

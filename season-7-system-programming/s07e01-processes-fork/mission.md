# Mission — s07e01 «Процессы и fork()»

## Что сдать
`artifacts/fork.c`: породить процесс-потомок, доказать родство, дождаться его через `waitpid()` и снять код возврата; показать, что память после `fork()` раздельна.

## Дано
- Код возврата потомка — `7`.
- Проверки печатаются как **свойства** («да»/«нет»), а не сырые PID.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] `fflush(stdout)` вызывается **до** `fork()` (иначе буфер продублируется).
- [ ] Потомок завершается через `_exit()`, не `exit()`.
- [ ] Родитель ждёт именно своего потомка через `waitpid(rc, ...)` и разбирает статус (`WIFEXITED`/`WEXITSTATUS`).
- [ ] Демонстрируется раздельность памяти: изменение переменной в потомке не видно родителю.
- [ ] **Ни один сырой PID не печатается** — вывод обязан быть одинаковым между запусками.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (тест прогоняет программу дважды).

## Как проверить
```bash
cp starter.c artifacts/fork.c
make test
```

## Оценка времени
~45–55 минут.

## Результат в сюжете
Ты понял, как система плодит процессы, — тем же механизмом, которым враг развернул свои `tracker` и `surveillance_d`. Это первый шаг к тому, чтобы спрятаться среди них.

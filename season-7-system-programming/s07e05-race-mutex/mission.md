# Mission — s07e05 «Гонки и мьютексы»

## Что сдать
`artifacts/race.c`: воспроизвести data race на общем счётчике и починить его мьютексом; в `stdout` печатать только инварианты, плавающие числа — в `stderr`.

## Дано
- 4 потока × 200000 инкрементов; ожидаемый итог `800000`.
- Два счётчика: незащищённый и под `pthread_mutex_t`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11 -pthread` без предупреждений.
- [ ] Инкремент разложен на чтение и запись (`tmp = c; c = tmp + 1;`) — окно гонки видно явно.
- [ ] Защищённая версия оборачивает критическую секцию в `pthread_mutex_lock`/`unlock`.
- [ ] Итог под мьютексом **в точности** равен `800000`.
- [ ] В `stdout` нет ни одного плавающего значения; фактические числа идут в `stderr`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (шесть прогонов).

## Как проверить
```bash
cp starter.c artifacts/race.c
make test        # проверка инвариантов
make race        # увидеть глазами, как «плавает» результат гонки
```

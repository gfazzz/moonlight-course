# Mission — s07e03 «Демоны»

## Что сдать
`artifacts/daemon.c`: полный ритуал демонизации и доказательство, что процесс отвязан от терминала — с отчётом через файл.

## Дано
- Путь отчёта: `/tmp/moonlight_s07e03_report.txt`.
- Управляющий процесс дожидается отчёта и печатает его.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Ритуал соблюдён целиком: `fork` → `setsid` → **второй** `fork` → `chdir("/")` → `umask(0)` → `dup2` фд в `/dev/null`.
- [ ] После второго `fork` демон **не** лидер сессии (`getsid(0) != getpid()`).
- [ ] Управляющего терминала нет (`open("/dev/tty")` не удаётся).
- [ ] Вывод демона в `stdout` **не появляется** в выводе программы (тест проверяет отдельно).
- [ ] Ни один PID не печатается; вывод одинаков между запусками.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/daemon.c
make test
```

## Оценка времени
~50–60 минут.

## Результат в сюжете
Ты умеешь то же, что `surveillance_d` противника: уходить в фон, теряя терминал и сессию. Твой `stealth_agent` теперь может жить в системе незаметно.

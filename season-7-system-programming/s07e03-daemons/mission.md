## Обстановка

`surveillance_d` пережил закрытие консоли и работал всю ночь. У него нет управляющего терминала, нет сессии пользователя и родитель под номером один.

Ритуал, которым это делается, не менялся тридцать лет.

## Приказ

Написать `artifacts/daemon.c`: выполнить ритуал демонизации целиком и доказать отвязку от терминала — отчётом через файл, поскольку вывода у демона больше нет.

## Дано

- Путь отчёта: `/tmp/moonlight_s07e03_report.txt`.
- Управляющий процесс дожидается отчёта и печатает его содержимое.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Ритуал соблюдён целиком и в порядке: `fork` → `setsid` → **второй** `fork` → `chdir("/")` → `umask(0)` → `dup2` дескрипторов на `/dev/null`.
- [ ] Промежуточные процессы выходят через `_exit()`.
- [ ] После второго раздвоения демон **не** лидер сессии: `getsid(0) != getpid()`.
- [ ] Управляющего терминала нет: открытие `/dev/tty` не удаётся.
- [ ] Дескрипторы 0, 1 и 2 **переоткрыты**, а не закрыты.
- [ ] Вывод демона в стандартный поток в выводе программы **не появляется**.
- [ ] Идентификаторы процессов не печатаются; вывод одинаков между запусками.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/daemon.c
make test
```

Поучительная проверка: уберите второе раздвоение и посмотрите на `getsid(0)`. Демон окажется лидером сессии — и уязвим к приобретению терминала.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| `setsid()` вернул `-1` | вызван в процессе, который уже лидер группы |
| демон оказался лидером сессии | пропущено второе раздвоение |
| в выводе появились строки демона | дескрипторы не перенаправлены |
| отчёт не находится | демон сменил каталог до формирования пути |
| посторонний файл испорчен записью | дескрипторы закрыты вместо переоткрытия |
| управляющий процесс висит | демон не дошёл до записи отчёта |

## После выполнения

В журнале `surveillance_d` три сканирования запущены **в одну секунду**. Процессов в дереве всего четыре — значит, параллелизм устроен иначе.

# Mission — s07e04 «Потоки (pthread)»

## Что сдать
`artifacts/threads.c`: параллельный Monte Carlo на `pthread` — тот самый, что был обещан в Season 5. Результат обязан **побитово** совпасть с последовательным.

## Дано
- 10000 траекторий, горизонт 20 дней, старт $50M, дневная волатильность 1.3%.
- 4 потока; диапазон делится на непересекающиеся куски `[lo, hi)`.
- Сид ГПСЧ вычисляется из **номера траектории**: `12345 + path * 2654435761`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11 -pthread` без предупреждений.
- [ ] Потоки создаются через `pthread_create` и собираются через `pthread_join`.
- [ ] Каждый поток пишет только в **свой** диапазон `pnl_par[lo..hi)` — общих записей нет, мьютексы не нужны.
- [ ] Последовательный и параллельный массивы совпадают побитово (`memcmp == 0`).
- [ ] Никаких таймингов в выводе (они меняются от запуска к запуску).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (тест прогоняет программу 4 раза).

## Как проверить
```bash
cp starter.c artifacts/threads.c
make test
```

## Оценка времени
~50–60 минут.

## Результат в сюжете
Твой агент считает так же параллельно, как сканеры противника, — и при этом воспроизводимо. Обещание, данное в Season 5, выполнено.

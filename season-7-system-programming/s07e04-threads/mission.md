## Обстановка

У `tracker` шестнадцать потоков в одном процессе. Одиннадцать дней назад в Нью-Йорке было сказано: параллельный расчёт — после седьмого сезона.

Седьмой сезон идёт.

## Приказ

Написать `artifacts/threads.c`: посчитать Монте-Карло последовательно и в четыре потока, доказать **побитовое** совпадение результатов, вывести показатели риска.

## Дано

- 10000 траекторий, горизонт 20 дней, старт $50M, дневная волатильность 1.3%.
- 4 потока; диапазон делится на непересекающиеся полуинтервалы `[lo, hi)`.
- Сид генератора вычисляется из **номера траектории**: `12345 + path * 2654435761`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11 -pthread` без предупреждений.
- [ ] Потоки создаются через `pthread_create` и собираются через `pthread_join`.
- [ ] Возврат `pthread_create` проверяется.
- [ ] Каждому потоку передаётся **свой** элемент массива аргументов, а не указатель на переменную цикла.
- [ ] Каждый поток пишет только в свой диапазон — общих записей нет, блокировки не используются.
- [ ] Разбиение покрывает весь диапазон: остаток от деления не теряется.
- [ ] Последовательный и параллельный массивы совпадают побитово (`memcmp == 0`).
- [ ] Сид генератора зависит от номера траектории, а не от номера потока и не от порядка счёта.
- [ ] В выводе нет времени выполнения и других плавающих величин.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (прогон четырежды).

## Выполнение

```bash
cp starter.c artifacts/threads.c
make test
```

Поучительная проверка: замените сид на общий счётчик генератора и прогоняйте программу несколько раз подряд. Побитовое совпадение исчезнет, а результаты останутся правдоподобными — это худший вид ошибки.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| результаты не совпали побитово | сид зависит от порядка счёта или от номера потока |
| часть траекторий не посчитана | остаток от деления диапазона потерян |
| все потоки посчитали один и тот же кусок | передан указатель на переменную цикла |
| программа завершилась раньше потоков | пропущен `pthread_join` |
| прогоны различаются | в выводе есть время или адрес |
| падение всей программы | ошибка с указателем в одном из потоков |

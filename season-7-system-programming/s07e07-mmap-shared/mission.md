## Обстановка

Тридцать восемь процентов процессорного времени демона уходит на копирование между ядром и процессами. Лечится это отказом от передачи: одна физическая память на всех.

Вместе со скоростью возвращаются гонки.

## Приказ

Написать `artifacts/shared.c`: разделить структуру между процессами через общее отображение, синхронизировать доступ межпроцессным мьютексом и показать контраст с приватным отображением.

## Дано

- Общая структура: мьютекс, счётчик, строка.
- 4 потомка × 50000 увеличений; ожидаемый итог — `200000`.
- Отдельное приватное отображение со значением `100`; потомок пишет туда `999`.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=gnu11 -pthread` без предупреждений.
- [ ] `mmap` вызывается с `MAP_SHARED | MAP_ANONYMOUS`; результат сверяется с `MAP_FAILED`.
- [ ] Мьютекс расположен **внутри** общего отображения.
- [ ] Мьютекс инициализирован с атрибутом `PTHREAD_PROCESS_SHARED`.
- [ ] Счётчик в общей памяти **в точности** равен `200000`.
- [ ] Строка, записанная потомком, читается родителем.
- [ ] В приватном отображении запись потомка родителю **не** видна: остаётся `100`.
- [ ] Ресурсы освобождаются: `pthread_mutexattr_destroy`, `pthread_mutex_destroy`, `munmap`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (четыре прогона).

## Выполнение

```bash
cp starter.c artifacts/shared.c
make test
```

Поучительная проверка: перенесите мьютекс из общей структуры в глобальную переменную. Программа продолжит работать без единой жалобы, а счётчик станет каждый раз разным — защиты не будет вовсе.

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| счётчик каждый раз разный | мьютекс лежит вне общего отображения |
| программа зависла намертво | не выставлен `PTHREAD_PROCESS_SHARED` |
| падение сразу после `mmap` | результат сверён с `NULL` вместо `MAP_FAILED` |
| потомок пишет, родитель не видит | использовано приватное отображение |
| приватное отображение ведёт себя как общее | перепутаны флаги |
| память не освобождается | пропущен `munmap` |

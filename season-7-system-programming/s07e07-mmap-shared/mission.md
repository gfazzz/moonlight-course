# Mission — s07e07 «mmap и разделяемая память»

## Что сдать
`artifacts/shared.c`: разделить структуру между процессами через `mmap(MAP_SHARED)`, синхронизировать доступ межпроцессным мьютексом и показать контраст с `MAP_PRIVATE`.

## Дано
- Общая структура: мьютекс + счётчик + строка.
- 4 потомка × 50000 инкрементов; ожидаемый итог `200000`.
- Отдельное отображение `MAP_PRIVATE` со значением `100`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11 -pthread` без предупреждений.
- [ ] `mmap` с `MAP_SHARED | MAP_ANONYMOUS`; результат проверяется на `MAP_FAILED`.
- [ ] Мьютекс инициализирован с атрибутом `PTHREAD_PROCESS_SHARED` (иначе — зависание или гонка).
- [ ] Счётчик в общей памяти **в точности** `200000`; строка от потомка видна родителю.
- [ ] В `MAP_PRIVATE` запись потомка **не** видна родителю (остаётся `100`).
- [ ] Ресурсы освобождаются: `pthread_mutex_destroy`, `munmap`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (четыре прогона).

## Как проверить
```bash
cp starter.c artifacts/shared.c
make test
```

## Оценка времени
~50–60 минут.

Части `stealth_agent` теперь делят таблицу целей напрямую, без копирования через ядро, — и делают это без гонок.

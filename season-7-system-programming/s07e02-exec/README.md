# s07e02 — exec: замена образа процесса

**Season 7: Systems Programming · Серия 2 из 8 · ~50 мин**
Концепт: `exec()` не создаёт процесс, а заменяет его содержимое новой программой — и при успехе не возвращается. Задача: собрать связку fork+exec и снимать коды возврата.

> *«PID остаётся прежним. Всё остальное — уже другая программа».*

## Теория: fork даёт процесс, exec даёт программу

```c
pid_t pid = fork();
if (pid == 0) {
    execv(argv[0], argv);
    _exit(127);            // достижимо ТОЛЬКО если exec провалился
}
waitpid(pid, &status, 0);
```

При успехе возвращаться некуда — старого кода в памяти уже нет. Провал `exec` — это обычная ошибка: −1 и `errno` (`ENOENT`), процесс продолжает жить. Статус разбираем через `WIFEXITED`/`WEXITSTATUS`, а убийство сигналом — `128 + WTERMSIG`. Подробнее — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про подмену образа.
```

**1.** LUNA: «Что случится, если после `execv` в потомке забыть `_exit()`?»

<details><summary>Ответ</summary>

При успешном `exec` — ничего, туда не попадут. Но при **провале** потомок продолжит выполнять родительский код дальше по функции: получится два процесса, делающих одно и то же (двойной вывод, двойная работа). Поэтому после `exec` всегда стоит обработчик ошибки с `_exit()`.
</details>

**2.** LUNA: «Программа завершилась с кодом 127. Что это значит?»

<details><summary>Ответ</summary>

По соглашению оболочки — команда не найдена (у нас это код, с которым потомок выходит после провала `exec`). Рядом: `126` — файл есть, но не исполняемый; `128+N` — процесс убит сигналом N (130 = Ctrl-C, то есть SIGINT).
</details>

```
[LUNA] Верно. Запускай.
```

## Разбор типичных ошибок

1. **Нет `_exit()` после `exec`.** При провале потомок «проваливается» в родительскую логику.
2. **`argv` без `NULL` в конце.** Массив аргументов обязан завершаться `NULL`, иначе UB.
3. **Считать провал `exec` крахом.** Это ошибка с `errno`; процесс продолжает работу.
4. **Читать `status` напрямую.** Только через макросы `WIFEXITED`/`WEXITSTATUS`/`WTERMSIG`.

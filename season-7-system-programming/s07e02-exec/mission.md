# Mission — s07e02 «exec: замена образа процесса»

## Что сдать
`artifacts/exec.c`: функция `run()` на связке fork+exec, запуск внешних программ, снятие кодов возврата, обработка неудачного `exec`.

## Дано
- Программы: `/bin/echo`, `/bin/sh -c "exit 3"`, несуществующий `/nonexistent/tracker`.
- Соглашения оболочки: `127` — команда не найдена, `128 + N` — убит сигналом N.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] `run()` делает `fflush` → `fork` → `execv` в потомке → `waitpid` в родителе.
- [ ] После `execv` в потомке стоит `_exit(127)` — код достижим только при провале.
- [ ] Разбираются оба исхода: `WIFEXITED` и `WIFSIGNALED` (`128 + WTERMSIG`).
- [ ] Доказано, что при успешном `exec` код после него **не** выполняется.
- [ ] Провал `execv` не убивает процесс: возвращает −1 и ставит `errno == ENOENT`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (прогон дважды).

## Как проверить
```bash
cp starter.c artifacts/exec.c
make test
```

## Оценка времени
~45–55 минут.

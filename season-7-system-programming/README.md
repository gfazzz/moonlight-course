## Сквозная идея сезона

Восемь системных вызовов оказываются одной картиной: **у процессов раздельная память, и всё остальное следует из этого**.

| Слой | Что следует из раздельности памяти |
|---|---|
| `fork` | потомок не видит изменений родителя |
| `exec` | новый образ, но дескрипторы и номер сохранены |
| демон | процесс переживает того, кто его запустил |
| потоки | память общая — впервые за сезон |
| мьютекс | общая память возвращает гонки |
| канал | раздельным процессам нужен посредник через ядро |
| `mmap` | общая память без копирования — и гонки снова на тебе |
| сигнал | процесс окликают снаружи, не заходя в его память |

Второй сквозной мотив — **детерминизм в конкурентном мире**. Весь сезон тесты проверяют не значения, а инварианты: `fork` вернул ноль в потомке, итог под мьютексом точно равен ожидаемому, параллельный расчёт совпал с последовательным побитово. Идентификаторы процессов, тайминги и адреса в проверяемый вывод не попадают никогда, а зависания ловятся тайм-аутом.

## Как проходить

```bash
cd s07e01-processes-fork
cp starter.c artifacts/fork.c
make test
```

Из корня сезона `make test` прогоняет все восемь серий и сквозной проект.

Сезон использует `-std=gnu11` (вызовы POSIX видны без ручных макросов) и `-pthread` там, где нужны потоки. Оболочка — рабочий инструмент: через неё запускаются команды и собираются конвейеры.

> **LUNA работает в режиме `Ask`, а не `Agent`.** В `Agent` ассистент правит файлы сам — тест позеленеет, а вы не напишете ни строки.

> **Читайте `.md` в предпросмотре** (`Cmd+Shift+V` / `Ctrl+Shift+V`): так работают таблицы и сворачиваемые ответы в блоке «Проверка на канале».

Ваш код в `artifacts/` отслеживается git — работайте в своей ветке. Правки курса — веткой от чистого `main`: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Season Project: `stealth_agent`

```bash
cd project
make          # собрать из модулей трёх сезонов
make run
```

| Модуль | Откуда | Что даёт |
|---|---|---|
| [`ml_crypto`](../season-1-foundations/) | **Season 1** | скрытие полезной нагрузки |
| [`ml_crc`](../season-6-embedded-iot/lib/ml_crc.h) | **Season 6** | упаковка в кадр с контрольной суммой |
| `ml_proc` | Season 7 | запуск команд связкой `fork` + `exec` |

Тест проекта проверяет **факт переиспользования**: он падает, если `main.c` содержит скопированные реализации вместо подключения модулей. Четыре единицы трансляции из трёх сезонов компонуются в один агент.

**Долги плана, закрытые здесь.** T1: параллельный Монте-Карло, обещанный в Season 5, реализован в [s07e04](s07e04-threads/) и даёт побитово тот же результат, что последовательная версия. T6: цепочка `mmap` (упомянут в S2 → разобран в S7 → используется в S8) зафиксирована в [s07e07](s07e07-mmap-shared/).

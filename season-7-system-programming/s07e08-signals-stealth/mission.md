# Mission — s07e08 «Сигналы и stealth-финал» (финал Season 7)

## Что сдать
`artifacts/signals.c`: корректная обработка сигналов через `sigaction`, чистое завершение по `SIGTERM`, доказательство неперехватываемости `SIGKILL` и финальная сборка `stealth_agent`.

## Дано
- Сигналы: `SIGUSR1` (дважды), `SIGTERM` (просьба завершиться), `SIGKILL` (не обсуждается).
- Потомок игнорирует `SIGTERM` и ждёт в `pause()`; готовность сообщает через канал.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=gnu11` без предупреждений.
- [ ] Обработчики ставятся через `sigaction` (не `signal`), с `SA_RESTART`.
- [ ] В обработчике — **только** запись в `volatile sig_atomic_t`; никаких `printf`/`malloc`.
- [ ] Решение о завершении принимает основной цикл по флагу, а не обработчик.
- [ ] Барьер готовности через канал: `SIGTERM` отправляется только после того, как потомок установил игнорирование.
- [ ] Доказано: потомок пережил `SIGTERM` (`waitpid` с `WNOHANG` вернул 0), но `SIGKILL` его завершил (`WIFSIGNALED`, `WTERMSIG == SIGKILL`).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS` (четыре прогона).

## Как проверить
```bash
cp starter.c artifacts/signals.c
make test
```

## Оценка времени
~55–65 минут.

## Результат в сюжете
`stealth_agent` собран целиком: он плодится, уходит в фон, считает параллельно, общается, делит память — и завершается чисто, не теряя данных. Глубокое сканирование противника его не найдёт.

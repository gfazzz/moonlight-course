## Теория: массивы и строки

### Массив и его длина

75 байт Виктора лежат в массиве подряд. Длину не пишут числом «75» — её вычисляют, чтобы код пережил смену данных:

```c
int length = sizeof(encrypted) / sizeof(encrypted[0]);
```

`sizeof(encrypted)` — размер всего массива в байтах, `sizeof(encrypted[0])` — размер одного элемента; их частное — число элементов.

### XOR по всему массиву

XOR ты уже знаешь (s01e01). Теперь применяем его к каждому байту в цикле, записывая результат в отдельный массив (входные данные не трогаем):

```c
for (int i = 0; i < length; i++)
    decrypted[i] = encrypted[i] ^ 0x42;
```

> Одно-байтовый XOR — учебный шифр, не защита: 256 ключей перебираются мгновенно. «Настоящую» криптографию соберёшь в Season 4.

### Строка и `'\0'`

Строка в C — это массив `char`, оканчивающийся нулевым байтом `'\0'`. `printf("%s")` печатает байты, пока не встретит `'\0'`. Значит, под расшифровку нужно `length + 1` байт, а терминатор ставят руками:

```c
unsigned char decrypted[length + 1];
/* ... заполнили ... */
decrypted[length] = '\0';
```

Забудешь — `printf` уйдёт читать чужую память, и вывод «поедет». (Про знаковость `char` и потерю размера массива в функциях — [`theory.md`](theory.md).)

**1.** LUNA: «Почему длину массива я требую считать через `sizeof`, а не писать `75`?»

<details><summary>Ответ</summary>

«Магическое число» рассыплется при смене данных. `sizeof(encrypted)/sizeof(encrypted[0])` пересчитает длину само.
</details>

**2.** LUNA: «Ты выделил ровно `length` байт под расшифровку, а `%s` печатает мусор в конце. Диагноз?»

<details><summary>Ответ</summary>

Нет места под `'\0'`. Нужно `length + 1` и `decrypted[length] = '\0';`, иначе `printf` не знает, где строка кончается.
</details>

**3.** LUNA: «Почему пишем в `decrypted`, а не поверх `encrypted`?»

<details><summary>Ответ</summary>

Чтобы не терять исходные данные: они могут понадобиться (проверка, повторный проход). Входные данные не мутируем без нужды.
</details>

— V.
--- END ---

Скелет логики:

```c
int length = sizeof(encrypted) / sizeof(encrypted[0]);
unsigned char decrypted[length + 1];
unsigned char checksum = 0;
for (int i = 0; i < length; i++) {
    decrypted[i] = encrypted[i] ^ 0x42;
    checksum += decrypted[i];
}
decrypted[length] = '\0';
```

## Разбор типичных ошибок

1. **Мусор в конце / segfault.** Выделил `length` вместо `length + 1` или забыл `'\0'`.
2. **`char` вместо `unsigned char`.** В перехвате есть `0xA0 0xC2 0xD6` — это UTF-8 тире «—» в подписи V. На знаковом `char` подпись побьётся.
3. **Магическое число `75`.** Только `sizeof(arr)/sizeof(arr[0])`.
4. **XOR поверх входных данных.** Пиши в `decrypted`, `encrypted` не трогай.

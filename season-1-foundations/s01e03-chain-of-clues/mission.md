# Mission — s01e02 «Цепочка зацепок»

## Что сдать
`artifacts/classifier.c`: читает записи из `data.dat` (через stdin), определяет тип, проверяет диапазоны и печатает статистику, помечая подделки.

## Дано
- `data.dat` — 12 записей формата `<тип> <v1> <v2> <timestamp>`.
- Типы: `C` (координата), `T` (время), `I` (ID).
- Правила валидности:
  - `C`: lat ∈ [−90, 90] И lon ∈ [−180, 180];
  - `T`: hh ∈ [0, 23] И mm ∈ [0, 59];
  - `I`: id > 0.
- Подделка Призрака: координата с широтой `99.99` (вне диапазона).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `switch` по типу записи; невалидные значения ловятся через `if` с `&&`.
- [ ] Ветка `default` не роняет разбор (пропускает неизвестную строку).
- [ ] Вывод совпадает с `tests/expected.txt` (9 valid, 3 invalid).
- [ ] `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/classifier.c
# ... правишь ...
make test          # прогон на data.dat
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Отсеяв подделки, ты видишь настоящую цепочку координат и времён — она указывает, где искать «старое место». Впервые на канал выходит **Призрак**.

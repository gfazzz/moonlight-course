## Обстановка

В цепочке двенадцать записей: координаты, время, идентификаторы. Настоящие ведут к «старому месту» из сообщения Виктора. Подделки ведут туда, где тебя ждут.

Неизвестный с подписью `:)` утверждает, что фальшивки видны по нарушенным диапазонам. Проверить это — твоя работа.

## Приказ

Написать `artifacts/classifier.c`: прочитать записи, определить тип каждой, проверить допустимость значений и вывести статистику с пометкой подделок.

## Формат данных

`data.dat`, по одной записи на строку:

```
<тип> <значение1> <значение2> <метка времени>
```

| Тип | Поля | Допустимые значения |
|---|---|---|
| `COORD` | широта, долгота | −90…90 и −180…180 |
| `TIME` | часы, минуты | 0…23 и 0…59 |
| `ID` | идентификатор | строго больше нуля |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Тип записи разбирается через `switch` или явную цепочку сравнений.
- [ ] Присутствует ветка **для неизвестного типа** — она обязана существовать.
- [ ] Диапазоны проверяются **до** использования значения.
- [ ] Некорректные записи помечаются `[BAD]` с указанием причины, но **не** прерывают разбор.
- [ ] Итог: 12 записей, из них 3 подделки — широта `99.99`, время `25:61`, идентификатор `-5`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

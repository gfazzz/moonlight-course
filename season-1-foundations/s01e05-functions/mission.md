# Mission — s01e05 «Функции»

## Что сдать
`artifacts/decoder.c`: та же расшифровка сообщения, но XOR и контрольная сумма вынесены в **функции** `xor_crypt()` и `checksum()`, вызываемые из `main` (без копипаста).

## Дано
- Сообщение V. (75 байт) — в каркасе.
- Ключ `0x42`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `xor_crypt(unsigned char*, int, unsigned char)` определена и вызывается.
- [ ] `checksum(const unsigned char*, int)` возвращает сумму и вызывается.
- [ ] `main` не содержит собственной копии XOR-цикла — только вызовы функций.
- [ ] `xor_crypt()` вызывается дважды (расшифровка и обратно) — доказательство переиспользования.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/decoder.c
make test
```

## Оценка времени
~30–40 минут.

## Результат в сюжете
XOR теперь живёт в одной функции, а не в трёх копиях. Следующий шаг к настоящему инструменту — вынести её в переиспользуемый модуль (s01e06).

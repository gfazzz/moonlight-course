# Mission — s01e07 «Файлы и аргументы»

## Что сдать
`artifacts/decoder.c`: принимает имя файла аргументом командной строки, читает зашифрованные байты из файла и расшифровывает их (XOR `0x42`).

## Дано
- `message.enc` — 75 зашифрованных байт (бинарный файл).
- Запуск: `./decoder message.enc`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Проверяет `argc` и печатает `usage` в `stderr`, если файл не задан.
- [ ] Открывает файл `fopen(argv[1], "rb")`; при ошибке — `perror` и выход с кодом 1.
- [ ] Читает байты через `fread`, закрывает `fclose`.
- [ ] Вывод совпадает с `tests/expected.txt` (тест запускает `decoder ../message.enc`).
- [ ] `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/decoder.c
make test
# вручную:
make run          # decoder message.enc
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Декодер больше не «зашит» под одно сообщение — он читает любой файл. Инструмент становится настоящим: данные снаружи, код внутри.

## Теория: модули

### Интерфейс `.h` и реализация `.c`

Функцию из s01e05 разносим на два файла:

- `crypto.h` — **интерфейс**: только прототипы. Его включают другие файлы через `#include`.
- `crypto.c` — **реализация**: тела функций. Компилируется отдельно.

```c
/* crypto.h */
#ifndef CRYPTO_H
#define CRYPTO_H
void xor_crypt(unsigned char *buf, int len, unsigned char key);
unsigned char checksum(const unsigned char *buf, int len);
#endif
```

Header guard (`#ifndef/#define/#endif`) спасает от двойного включения: заголовки подтягивают друг друга транзитивно, и один `.h` легко попадёт в файл дважды.

### Сборка и линковка

```bash
gcc crypto.c decoder.c -o decoder
```

Два шага: каждый `.c` компилируется в объектный файл, потом линкер связывает их. Если объявил функцию в `.h`, но не определил в `.c`, — поймаешь `undefined reference` **на линковке** (не на компиляции). Включать `.c` в `#include` нельзя — только `.h`; иначе дубли символов. Подробнее — [`theory.md`](theory.md).

### Зачем это

XOR живёт в одном месте. Нужен он в Season 3 для сетевого трафика? `#include "crypto.h"` — и всё. Это кумулятивность курса: модули S1 переиспользуются дальше.

**1.** LUNA: «Что из `crypto.h`/`crypto.c` попадает в `#include`, а что — в команду сборки?»

<details><summary>Ответ</summary>

`#include` — только `.h` (интерфейс). `.c` добавляют в команду компиляции/сборки. Инклудить `.c` нельзя — получишь дубли символов.
</details>

**2.** LUNA: «Компиляция прошла, линкер ругается `undefined reference to xor_crypt`. Диагноз?»

<details><summary>Ответ</summary>

Функция объявлена в `.h`, но не определена в `.c` — либо `crypto.c` не добавлен в сборку. Это ошибка линковки, а не компиляции.
</details>

**3.** LUNA: «Зачем header guard, если я подключаю `crypto.h` один раз?»

<details><summary>Ответ</summary>

Транзитивно `.h` подтянется дважды, и будет `redefinition`. Guard — дешёвая страховка, её пишут всегда.
</details>

## Разбор типичных ошибок

1. **`#include "crypto.c"`.** Включают только `.h`; `.c` даёт дубли символов при линковке.
2. **Объявил, но не определил.** Прототип в `.h` без тела в `.c` → `undefined reference` на линковке.
3. **Нет header guard.** Двойное включение → `redefinition`. Пиши `#ifndef` всегда.
4. **Забыл `crypto.c` в команде.** `gcc decoder.c` без `crypto.c` не найдёт функции.

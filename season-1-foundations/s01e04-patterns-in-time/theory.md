# Теория (углублённо) — s01e03

## 1. Три вида циклов

- `for` — когда число шагов известно или считается по индексу:
  ```c
  for (int i = 0; i < n; i++) { /* ... */ }
  ```
- `while` — когда повторяем, пока верно условие (число шагов заранее неизвестно):
  ```c
  while (scanf("%ld", &x) == 1) { /* ... */ }
  ```
- `do…while` — как `while`, но тело выполнится хотя бы раз (условие проверяется в конце). В C нужен реже.

Идиома чтения «до конца ввода» — именно `while (scanf(...) == N)`: `scanf` возвращает число прочитанных полей, а на конце файла — `EOF` (не N), и цикл останавливается.

## 2. Накопление и агрегаты

Классический паттерн: завести аккумулятор до цикла и обновлять внутри.

```c
long sum = 0;
for (int i = 0; i < n; i++) sum += a[i];   // сумма
```

Так же считают минимум/максимум (заводим кандидата первым элементом и сравниваем), количество по условию (счётчик), среднее (сумма/‌количество).

## 3. Мода без сортировки

«Самый частый интервал» — это мода. Простой способ без сортировки: для каждого элемента посчитать, сколько раз он встречается, и запомнить максимум. Это два вложенных цикла — O(n²):

```c
for (int i = 0; i < m; i++) {
    int count = 0;
    for (int j = 0; j < m; j++)
        if (val[j] == val[i]) count++;
    if (count > best) { best = count; mode = val[i]; }
}
```

Для маленьких данных O(n²) нормально. Когда данных много, берут сортировку или хеш-таблицу — это Season 4. (Здесь важно почувствовать вложенные циклы, а не гнаться за скоростью.)

## 4. `break` и `continue`

- `break` — выйти из цикла целиком (нашли — хватит искать).
- `continue` — пропустить остаток тела и перейти к следующей итерации.

Оба сокращают вложенность и делают намерение явным, но злоупотребление `break`/`continue` внутри глубоких циклов усложняет чтение.

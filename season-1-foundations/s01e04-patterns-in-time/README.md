## Теория: циклы

### `for` и `while`

`for` — когда шаги считаются по индексу; `while` — когда повторяем, пока верно условие:

```c
for (int i = 0; i < n; i++) { /* известное число шагов */ }

while (scanf("%ld", &x) == 1) { /* пока есть что читать */ }
```

Чтение «до конца файла» держится на возвращаемом значении `scanf`: оно равно числу прочитанных полей, а на конце ввода — `EOF`. Поэтому цикл сам останавливается, когда метки закончились.

### Накопление

Базовый приём: завести аккумулятор до цикла, обновлять внутри.

```c
long sum = 0;
for (int i = 0; i < n; i++) sum += a[i];
```

Так же считают счётчики по условию, минимум и максимум.

### Мода: вложенные циклы

«Самый частый интервал» — это мода. Без сортировки её находят двумя вложенными циклами: для каждого интервала считаем, сколько раз он встречается, и запоминаем максимум.

```c
for (int i = 0; i + 1 < n; i++) {
    long gap = ts[i+1] - ts[i];
    int count = 0;
    for (int j = 0; j + 1 < n; j++)
        if (ts[j+1] - ts[j] == gap) count++;
    if (count > best) { best = count; period = gap; }
}
```

O(n²) — нормально для десяти меток. Для больших данных берут сортировку или хеш-таблицу (Season 4). Здесь важно почувствовать вложенный цикл.


**1.** LUNA: «Почему `while (scanf("%ld", &x) == 1)` не зациклится навсегда на конце файла?»

<details><summary>Ответ</summary>

На EOF `scanf` вернёт не 1 (а `EOF`), условие станет ложным — цикл выйдет. Если проверять по-другому (например, `!= EOF` без разбора N полей), можно словить бесконечный цикл на битом вводе.
</details>

**2.** LUNA: «10 меток. Сколько интервалов между ними и почему цикл идёт `i + 1 < n`?»

<details><summary>Ответ</summary>

Интервалов `n − 1 = 9`. Внутри обращаемся к `ts[i+1]`, поэтому последний допустимый `i` — это `n−2`; условие `i + 1 < n` держит индекс в границах.
</details>

**3.** LUNA: «Мода за O(n²) — не стыдно?»

<details><summary>Ответ</summary>

Для 10 элементов — нет: это 100 операций. Стыдно будет на миллионе; тогда — сортировка или хеш (Season 4). Правильная сложность зависит от размера данных.
</details>

## Разбор типичных ошибок

1. **Выход за границу массива.** Обращаешься к `ts[i+1]` — значит цикл идёт до `i + 1 < n`, а не `i < n`. Иначе читаешь чужую память.
2. **Аккумулятор внутри цикла.** `int count = 0;` для моды заводится **на каждый** внешний шаг, а сумма/максимум — **до** цикла. Перепутал — получишь мусор.
3. **`scanf` без проверки.** Читать в `ts[n]`, не проверив `== 1`, — значит на битой строке засчитать неинициализированное значение.
4. **Бесконечный цикл.** Забыл `n++` или изменение переменной условия — программа зависнет. `Ctrl+C` и ищи, что не двигается.

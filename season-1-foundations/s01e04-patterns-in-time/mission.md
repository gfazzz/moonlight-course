## Обстановка

Десять меток времени без пояснений. Если это расписание — у него есть период, и есть момент, когда расписание нарушилось.

Нарушение и есть цель: событие, ради которого Виктор сохранил файл.

## Приказ

Написать `artifacts/pattern_finder.c`: вычислить интервалы между метками, определить доминирующий период и найти отклонения.

## Данные

`data.txt` — 10 меток времени (UNIX timestamp), по одной на строку.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Интервалов ровно **на один меньше**, чем меток: из 10 точек — 9 промежутков.
- [ ] Разности берутся «назад» (`t[i] - t[i-1]` при `i` от 1) — без обращения за границу массива.
- [ ] Доминирующий период определяется по **частоте** значения, а не по среднему.
- [ ] Аномалии ищутся **после** того, как период известен.
- [ ] Итог: период `3600 с` (встречается 8 раз), 1 аномалия — интервал 5, разрыв `7200 с`.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/pattern_finder.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## После выполнения

Станет виден час, в который расписание сломалось. Расписания не ломаются сами.

# Mission — s01e03 «Паттерны во времени»

## Что сдать
`artifacts/pattern_finder.c`: по меткам времени из `data.txt` находит период расписания и локализует аномалии.

## Дано
- `data.txt` — 10 меток времени (UNIX timestamp), по одной на строку.
- Период = самый частый интервал между соседними метками.
- Аномалия = интервал, отличный от периода (сбой расписания).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Метки читаются циклом `while (scanf(...) == 1)` в массив.
- [ ] Период найден как мода интервалов (вложенный цикл `for`).
- [ ] Аномалии посчитаны и выведены по одной на строку.
- [ ] Вывод совпадает с `tests/expected.txt` (период 3600 s ×8, 1 аномалия).
- [ ] `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/pattern_finder.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
Период расписания и единственный сбой в нём указывают на момент, когда «старое место» оживает. Сбой — это и есть настоящее событие.

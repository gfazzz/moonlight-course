# Mission — s01e05 «Сборка инструмента» (финал Season 1)

## Что сдать
Финальный `moonlight_decoder`: декодирует несколько сообщений и складывает результаты в массив структур `Message`, печатает отчёт. Собирается многофайловым Makefile (`.c → .o → бинарь`).

## Дано
- Модуль `crypto` (готов, из s01e04) — в `starter/`.
- Два зашифрованных сообщения (ключ `0x42`) — в `decoder.c`.

## Критерии приёмки
- [ ] Объявлен `typedef struct { ... } Message` с полями label, len, sum, text.
- [ ] Функция `decode()` возвращает заполненную `Message`.
- [ ] Результаты хранятся в массиве `Message msgs[2]` и печатаются таблицей.
- [ ] Сборка через `make` (объектные файлы `crypto.o`, `decoder.o` → бинарь) без предупреждений.
- [ ] Вывод совпадает с `tests/expected.txt` (два сообщения, checksums `0xA4` и `0xD2`).
- [ ] `make test` → `PASS`.

## Как проверить
```bash
cp -r starter/* artifacts/
# ... правишь artifacts/decoder.c (struct + decode + отчёт) ...
make            # crypto.o + decoder.o -> moonlight_decoder
make test
```

## 1. `if / else if / else`

Ветвление выбирает путь по условию. Условие — выражение, которое в C истинно, если не равно нулю:

```c
if (lat >= -90.0 && lat <= 90.0) {
    // валидно
} else {
    // за диапазоном
}
```

Диапазон проверяют двумя сравнениями через логическое И (`&&`). Частая ошибка новичка — писать `-90 <= lat <= 90`: в C это разбирается как `(-90 <= lat) <= 90`, где левая часть даёт 0 или 1, и сравнение теряет смысл. Всегда два условия: `lat >= -90 && lat <= 90`.

## 2. Логические операторы и короткое замыкание

- `&&` — И: истинно, если оба операнда истинны;
- `||` — ИЛИ: истинно, если хотя бы один;
- `!` — НЕ.

`&&` и `||` вычисляются «лениво» (short-circuit): в `a && b`, если `a` ложно, `b` даже не вычисляется. Это удобно для защитных проверок: `if (p != NULL && p->x > 0)` — второе условие не тронет `p`, если он `NULL` (пригодится в Season 2).

## 3. `switch`

Когда выбор идёт по одному дискретному значению (тип записи — символ), `switch` читается лучше цепочки `if`:

```c
switch (type) {
    case 'C': /* ... */ break;
    case 'T': /* ... */ break;
    default:  /* неизвестный тип */ break;
}
```

Ключевое: без `break` управление «проваливается» в следующий case (fall-through) — это источник хитрых багов. Здесь `break` обязателен после каждой ветки. `default` — страховка от мусора во входных данных.

## 4. `scanf` и возвращаемое значение

`scanf` возвращает число успешно прочитанных полей. Это и есть проверка ошибок:

```c
if (scanf("%lf %lf %ld", &lat, &lon, &ts) != 3) {
    // строка битая — не доверяй значениям
}
```

`" %c"` с пробелом перед `%c` пропускает пробелы и переводы строк — иначе `%c` прочитает `'\n'` от прошлой строки. `%lf` — это `double` в `scanf` (в отличие от `printf`, где `double` печатается как `%f`).

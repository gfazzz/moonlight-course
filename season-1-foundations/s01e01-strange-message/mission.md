# Mission — s01e01 «Странное сообщение»

## Что сдать
Программу `artifacts/decoder.c`, которая расшифровывает перехват от V. (XOR, ключ `0x42`) и печатает сообщение.

## Дано
- 75 зашифрованных байт (уже в `starter.c`).
- Ключ XOR: `0x42`.
- Метод: побайтовый XOR. Свойство: `A ^ K ^ K = A` — тот же ключ и шифрует, и расшифровывает.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Длина считается через `sizeof(arr)/sizeof(arr[0])`, а не числом «75».
- [ ] Массив расшифровки имеет `length + 1` и завершается `'\0'`.
- [ ] Вывод совпадает с `tests/expected.txt` (сообщение + `Checksum: 0xA4`).
- [ ] `make test` показывает `PASS`.

## Как проверить
```bash
cp starter.c artifacts/decoder.c   # один раз
# ... правишь artifacts/decoder.c ...
make test
```

## Оценка времени
~30–40 минут. Один концепт, одна задача — не растягивай.

## Результат в сюжете
Расшифрованное сообщение V. открывает ниточку к следующему перехвату (s01e02).

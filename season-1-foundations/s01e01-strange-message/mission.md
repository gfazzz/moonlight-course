# Mission — s01e01 «Первый байт»

## Что сдать
`artifacts/bytecheck.c`: расшифровывает первый байт перехвата (`0x0F`) ключом `0x42` и показывает, что тот же ключ возвращает исходный байт.

## Дано
- Первый байт перехвата: `0x0F`.
- Ключ XOR: `0x42`.
- Свойство: `A ^ K ^ K = A` — один ключ и шифрует, и расшифровывает.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Байты хранятся в `unsigned char`; вывод в hex через `%02X`.
- [ ] Показаны обе операции: `0x0F ^ 0x42` и обратная.
- [ ] Первый байт расшифровывается в `0x4D` (`'M'`).
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/bytecheck.c
make test
```

## Оценка времени
~20–25 минут (разминка).

## Результат в сюжете
Ключ подтверждён на одном байте — сообщение настоящее. Полную расшифровку соберёшь в s01e02.

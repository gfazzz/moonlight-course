# Теория (углублённо) — s01e01

## 1. Байт и `unsigned char`

Байт — 8 бит, значения 0–255. Для «сырого» байта в C берут `unsigned char` (0–255), а не `char`: `char` может быть знаковым (−128…127), и на значениях выше `0x7F` вылезают знаковые эффекты. Все данные (текст, картинки, сеть) — это в конечном счёте байты.

## 2. Шестнадцатеричная запись

Одна hex-цифра = 4 бита; два разряда = один байт. `0x42` = `0100 0010` = 66. Печать hex:

- `%02X` — два разряда, ведущие нули, верхний регистр (`0x0F`, `0x4D`).
- `%c` — тот же байт как символ ASCII (`0x4D` → `M`).

## 3. Оператор XOR (`^`) на одном байте

XOR сравнивает биты: `1`, если они различаются, иначе `0`.

```
  0x0F = 0000 1111
  0x42 = 0100 0010
  ---------------- ^
  0x4D = 0100 1101   ('M')
```

Главное свойство — самообратимость: `(A ^ K) ^ K = A`. Тот же ключ отменяет XOR. Поэтому одна операция и шифрует, и расшифровывает — этим ты пользуешься с этой серии и до конца сезона.

Другие тождества: `A ^ 0 = A`, `A ^ A = 0`, коммутативность, ассоциативность.

## 4. Почему сначала один байт

Прежде чем декодировать 75 байт, проверяют ключ на одном: если первый байт превращается в осмысленный символ (`'M'`) — ключ верный, данные настоящие. Это дешёвая проверка гипотезы перед дорогой работой (декодом всего сообщения в s01e02).

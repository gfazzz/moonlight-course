## Теория: структуры и сборка

### `struct` + `typedef`

Одна расшифрованная запись — это несколько связанных полей. Держим их вместе:

```c
typedef struct {
    const char   *label;
    int           len;
    unsigned char sum;
    char          text[128];
} Message;

Message msgs[2];        // массив структур = таблица записей
```

Поля — через точку (`m.len`), а через указатель — через стрелку (`p->len`). Структуру можно вернуть из функции по значению — копируются все поля:

```c
Message decode(const char *label, const unsigned char *enc, int len, unsigned char key);
```

### Сборка `.c → .o → бинарь`

Makefile делает раздельную компиляцию явной:

```make
artifacts/%.o: artifacts/%.c
	$(CC) $(CFLAGS) -c $< -o $@

moonlight_decoder: artifacts/crypto.o artifacts/decoder.o
	$(CC) $(CFLAGS) -o $@ $^
```

`-c` компилирует в объектный файл без линковки; `$<` — исходник, `$^` — все зависимости, `$@` — цель. `make` пересобирает только изменённое. Так собирается весь настоящий C-софт. (Подробнее — [`theory.md`](theory.md).)

## Проверка на канале

```
[LUNA] Последние три вопроса сезона. Соберись.
```

**1.** LUNA: «`m.len` или `m->len` — когда какой?»

<details><summary>Ответ</summary>

`m.len` — когда `m` это структура. `m->len` — когда `m` это указатель на структуру (сокращение для `(*m).len`).
</details>

**2.** LUNA: «Что копируется, когда `decode()` возвращает `Message` по значению?»

<details><summary>Ответ</summary>

Все поля структуры целиком, включая массив `text[128]`. Для маленькой записи это нормально; для больших предпочитают указатель, чтобы не копировать много.
</details>

**3.** LUNA: «Зачем `-c` и объектные файлы, если можно `gcc *.c -o bin` одной строкой?»

<details><summary>Ответ</summary>

`make` пересобирает только изменённые `.o`. На двух файлах разницы нет, на двухстах — это минуты против секунд. И линковка становится отдельным, понятным шагом.
</details>

## Разбор типичных ошибок

1. **Точка вместо стрелки (и наоборот).** `p.len` на указателе — ошибка компиляции. На указателе — `p->len`.
2. **`text` без `'\0'`.** Кладёшь байты в `m.text`, но забыл терминатор — `printf("%s")` поедет. Всегда `m.text[n] = '\0'`.
3. **Переполнение `text[128]`.** Сообщение длиннее буфера — обрежь до `TEXT_MAX-1`, иначе затрёшь соседние поля структуры.
4. **`make` без правил на `.o`.** Если цель зависит от `crypto.o`, а правила его сборки нет — «No rule to make target». Опиши шаблон `%.o: %.c`.

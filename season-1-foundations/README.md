# Season 1 — Foundations

**Основы C через расследование. 8 коротких серий, ~4.5 часа.**

> *«Всё начинается с простого. Но ничто не кончается так, как начиналось».*

Ты — Александр «Морфеус» Соколов, специалист по кибербезопасности. В 23:47 на старый канал приходит сообщение от Виктора Петрова — напарника, который два года как мёртв. Расшифровав его, ты втягиваешься в операцию MOONLIGHT. Твой напарник по коду — **LUNA**, ИИ Виктора; в реальности это твой ассистент в Cursor.

Season 1 закладывает фундамент C: от байтов и XOR до функций, структур и сборки. К финалу собран первый инструмент — `moonlight_decoder` — и он вскрывает файл, меняющий всё.

## Как проходить

Оболочка — **Cursor в режиме IDE**. LUNA из сюжета = чат Cursor в реальности: спрашивай «почему», а не «сделай за меня».

```bash
cd s01e01-strange-message
cat README.md
cp starter.c artifacts/bytecheck.c   # в s01e06/s01e08: cp -r starter/* artifacts/
# ... пишешь код ...
make test                            # зелёный тест = серия пройдена
# из корня сезона: make test — прогон всех 8 серий
```

Эталон в `solution/` открывай только после честной попытки.

## Season Project: `moonlight_decoder`

Артефакты серий не выбрасываются — они собираются в сквозной инструмент сезона: модуль `crypto` (XOR, checksum), классификатор записей, искатель паттернов, отчёт на структурах. В следующих сезонах он переиспользуется через `#include`.

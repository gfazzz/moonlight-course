# Инструменты курса

Скрипты для тех, кто курс сопровождает или проверяет. Проходящему курс они не
нужны: ему хватает `make test` в папке серии.

| Команда | Что делает |
|---|---|
| `make links` | проверяет внутренние ссылки во всех `.md` |
| `make test` | прогоняет весь курс (80 серий) |
| `make test SEASON=…` | один сезон |
| `make projects` | собирает сквозные проекты всех сезонов |
| `make progress` | сколько серий пройдено и какая следующая |
| `make check` | `links` + `test` — то же, что гоняет CI |
| `make list` | сезоны и серии |
| `make clean` | убрать собранные бинарники |

---

## `check_links.sh`

Ручная вычитка не ловит ссылку на несуществующий файл: глаз читает текст
ссылки, а не её цель. Здесь так пережили несколько вычиток ссылки на
`solution/sorts.c` при фактическом `sorting.c`.

Скрипт обходит все `.md`, достаёт markdown-ссылки и проверяет, что
цель существует относительно файла-источника. Внешние ссылки, якоря и
плейсхолдеры пропускаются.

```bash
bash tools/check_links.sh    # 0 — чисто, 1 — есть битые
```

## Обстановка

Второй файл перебором не взять: 26! ключей. Но шифр замены не убирает информацию о тексте — он лишь переименовывает буквы.

Частоты остаются на месте. Значит, ключ искать не нужно — нужно сравнить профили.

## Приказ

Написать `artifacts/freq.c`: посчитать частоты букв в шифротексте, сравнить с эталонным распределением английского через хи-квадрат, выбрать вариант с минимальным значением.

## Дано

Шифротекст и таблица эталонных частот английского языка (в коде).

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Частоты **нормированы**: сравниваются доли, а не абсолютные количества.
- [ ] В подсчёт попадают только буквы; пробелы и знаки препинания исключены.
- [ ] Регистр приведён к одному — иначе `E` и `e` окажутся разными буквами.
- [ ] Метрика считается как `Σ (набл − ожид)² / ожид`; деление на ожидаемое присутствует.
- [ ] Выбирается вариант с **минимальным** значением — метрика измеряет расхождение, а не сходство.
- [ ] Деления на ноль нет: буквы с нулевой ожидаемой частотой обработаны.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/freq.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| метрика огромна у всех вариантов | частоты не нормированы |
| выбран заведомо неверный вариант | ищется максимум вместо минимума |
| результат зависит от регистра исходника | буквы не приведены к одному регистру |
| редкие буквы не влияют на результат | пропущено деление на ожидаемое |
| `inf` или `nan` в метрике | деление на нулевую ожидаемую частоту |

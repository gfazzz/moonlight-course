## Теория: язык оставляет отпечаток

### Частоты неизменны

Замена переименовывает буквы. Если в тексте `E` встречалась в 12.7% случаев, то после замены на `Q` буква `Q` будет встречаться в тех же 12.7%.

Эталонное распределение английского:

| Буква | % | Буква | % |
|---|---|---|---|
| E | 12.7 | N | 6.7 |
| T | 9.1 | S | 6.3 |
| A | 8.2 | H | 6.1 |
| O | 7.5 | R | 6.0 |
| I | 7.0 | D | 4.3 |

Задача криптоанализа сводится к сопоставлению профилей — вместо поиска ключа среди 4·10²⁶ вариантов.

### Хи-квадрат: насколько похоже

```c
double chi2 = 0.0;
for (int i = 0; i < 26; i++) {
    double expected = total * ENGLISH_FREQ[i];
    double diff = observed[i] - expected;
    chi2 += diff * diff / expected;
}
```

Каждое отклонение возводится в квадрат (чтобы знак не имел значения) и делится на ожидаемое (чтобы редкие буквы не перевешивали частые). Сумма — одно число: **чем меньше, тем ближе к языку**.

Дальше алгоритм тривиален: посчитать метрику для всех кандидатов, взять минимум. Решение принимает число, а не человек, — и в этом смысл: глаза устают, статистика нет.

### Где метод перестаёт работать

| Условие | Последствие |
|---|---|
| текст короче ~100 символов | статистика недостоверна |
| текст не на ожидаемом языке | эталон не тот |
| текст не естественный (код, base64) | распределение другое |
| шифр многоалфавитный (Виженер) | одна буква шифруется по-разному |

Последняя строка объясняет, куда развивалась криптография после аль-Кинди: если использовать не один алфавит, а несколько по кругу, частоты размазываются. Виженер продержался три века именно поэтому.

## Проверка: LUNA задаёт вопросы
```
[LUNA] Два вопроса про статистику.
```

**1.** LUNA: «Почему в хи-квадрат отклонение делят на ожидаемое значение?»

<details><summary>Ответ</summary>

Чтобы уравнять вклад частых и редких букв. Отклонение в десять вхождений для `E` (ожидается около 127 на тысячу) — это шум, а для `Z` (ожидается меньше одного) — гигантское расхождение. Без деления сумму определяли бы только частые буквы, и метрика потеряла бы чувствительность. Деление на ожидаемое превращает абсолютное отклонение в относительное.
</details>

**2.** LUNA: «Частотный анализ не сработал на перехвате в сорок символов. Шифр стойкий?»

<details><summary>Ответ</summary>

Нет, просто данных мало. На коротком тексте наблюдаемые частоты — это шум: буква `E` может не встретиться вовсе, а `Z` попасться дважды. Метод требует достаточной выборки, обычно от сотни символов, и его провал говорит о размере перехвата, а не о качестве шифра. Ровно поэтому в криптоанализе всегда сначала спрашивают, сколько материала доступно.
</details>

## Разбор типичных ошибок

1. **Частоты не нормированы.** Сравнивать абсолютные количества с процентами бессмысленно.
2. **Небуквенные символы попали в подсчёт.** Пробелы исказят распределение.
3. **Регистр не приведён.** `E` и `e` окажутся разными буквами.
4. **Деление на ожидаемое пропущено.** Метрика станет нечувствительной к редким буквам.
5. **Выбирается максимум вместо минимума.** Хи-квадрат — мера расхождения, а не сходства.

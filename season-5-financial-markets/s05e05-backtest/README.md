# s05e05 — Бэктест и overfitting

**Season 5: Financial Markets · Серия 5 из 8 · ~55 мин**
Концепт: стратегию нельзя оценивать там же, где её настраивали. Задача: бэктест SMA-crossover и разоблачение подгонки на out-of-sample.

> *«Любую кривую можно нарисовать по прошлому. Вопрос — что она сделает завтра».*

## Previously

У тебя есть индикаторы: средние, crossover, RSI. Организация показывает красивую доходность своей стратегии на истории. Но красивая история — ещё не доказательство.

## Сцена

NYSE. Отчёт организации: их алгоритм даёт стабильный плюс на исторических данных. LUNA не спешит верить — она предлагает единственную честную проверку.

```

[LUNA] Даже на чистом шуме. Это не навык, это подгонка под уже известный ответ.
[LUNA] Честно — так: настрой на одной половине данных, проверь на другой, которую не видел.
[LUNA] Если на новых данных всё разваливается — перед тобой overfitting. Как у них.
```

Сегодня — самый важный урок квантового трейдинга: как отличить работающую стратегию от красивой иллюзии.

## Теория: подгонка против навыка

Бэктест: держим позицию, пока `SMA(fast) > SMA(slow)`, считаем итоговую доходность.

**Grid search** на in-sample обязательно найдёт «лучшую» комбинацию — даже на случайных данных. Проверка честна только на **out-of-sample** (данных, которых модель не видела при настройке):

```
best in-sample: fast 8 slow 21 -> +3.91%
same params out-of-sample     -> -5.72%
```

Разрыв между IS и OOS — это и есть переобучение. Чем больше вариантов перебрал, тем выше шанс поймать случайного победителя (множественное тестирование). Бороться: IS/OOS-разделение, walk-forward, меньше параметров, benchmark (buy&hold), учёт издержек. Подробнее — [`theory.md`](theory.md).

</details>

## Разбор типичных ошибок

1. **Оценивать на in-sample.** Главная ошибка индустрии. Честна только OOS.
2. **Заглядывание в будущее (look-ahead).** Сигнал на день `i` должен использовать данные **до** `i`, иначе бэктест «жульничает».
3. **Игнорировать издержки.** Комиссии и проскальзывание превращают бумажный плюс в минус (в модели их нет — помни об этом).
4. **Больше параметров = «лучше».** Наоборот: больше свободы = больше подгонки. Простые стратегии обобщаются лучше.

## Debriefing

Иллюзия разоблачена: стратегия организации даёт +3.91% на прошлом и −5.72% на будущем. Их «алгоритм» — не навык, а подгонка, и она маскирует настоящую схему: деньги делаются не на торговле, а на манипуляции риском. Пора посчитать, чем они на самом деле рискуют.

```
[LUNA] Их доходность — фикция. Но убытки, которые они прячут, — реальны.
[LUNA] Портфель на $50M. Сколько можно потерять за один плохой день? Это измеримо.
[LUNA] Value at Risk. Дальше — s05e06. И тут снова важна честная статистика.
```

**Навык разблокирован:** бэктест, in-sample/out-of-sample, распознавание overfitting.

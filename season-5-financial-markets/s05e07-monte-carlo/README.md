## Что ты освоишь

- Идею Monte Carlo: распределение исходов вместо точечной оценки.
- Свой seeded PRNG и почему библиотечный `rand()` не подходит для воспроизводимости.
- Нормальную величину по ЦПТ (сумма равномерных) — без `-lm`.

Глубже — в [`theory.md`](theory.md).

---

## Теория: разыграть будущее

```c
// один сценарий: 20 дней случайных доходностей
value = START;
for (d = 0; d < HORIZON; d++) { r = SIG * normal(); value *= (1 + r); }
pnl = value - START;
```

Повторяем 10000 раз → распределение P&L. VaR — это его перцентиль:

```c
qsort(pnl, ...);  var95 = -pnl[0.05*N];  var99 = -pnl[0.01*N];
```

**Случайность:** свой seeded LCG (библиотечный `rand()` не переносим между системами). **Нормаль:** сумма 12 равномерных минус 6 (ЦПТ) — без `log`/`cos`, значит без `-lm`. Подробнее — [`theory.md`](theory.md).

> Порядок курса: параллельный Monte Carlo (`pthread`) — Advanced после Season 7; честный ГПСЧ и Knuth shuffle — Season 8. Здесь версия секвенциальная.

## Проверка на канале

```
[LUNA] Два вопроса про симуляцию.
```

**1.** LUNA: «Почему для теста мы берём свой LCG, а не `rand()` из stdlib?»

<details><summary>Ответ</summary>

`rand()` даёт разные последовательности на разных системах (glibc/BSD/macOS) при одном сиде. Тест на детерминированный вывод тогда не воспроизведётся. Свой seeded LCG одинаков везде.
</details>

**2.** LUNA: «Как из равномерного генератора получить нормальную величину без `log` и `cos`?»

<details><summary>Ответ</summary>

По центральной предельной теореме: сумма 12 равномерных из [0,1) имеет среднее 6 и дисперсию 1, поэтому `сумма − 6 ≈ N(0,1)`. Просто и без `-lm` (в отличие от Box–Muller).
</details>

```
[LUNA] Верно. Разыгрывай сценарии.
```

## Разбор типичных ошибок

1. **Библиотечный `rand()`.** Невоспроизводимо между системами — тест не сойдётся. Свой seeded LCG.
2. **Box–Muller ради нормали.** Тянет `-lm` (`log`, `sqrt`, `cos`). Сумма равномерных проще и без библиотеки.
3. **Складывать доходности, а не компаундить.** Портфель растёт мультипликативно: `value *= (1+r)`, не `value += r`.
4. **Перцентиль без сортировки.** VaR — это порядковая статистика; сначала `qsort`, потом индекс.

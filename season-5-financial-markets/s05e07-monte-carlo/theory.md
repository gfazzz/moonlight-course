# Теория (углублённо) — s05e07

## 1. Идея Monte Carlo

Вместо одной формулы — тысячи случайных «прогонов» будущего. Каждый сценарий: смоделировать 20 дней случайных доходностей, скомпаундить, получить один исход. 10000 исходов дают **распределение** P&L, а не одно число. VaR, вероятность разорения, ожидаемая потеря — всё читается из этого распределения.

Метод назван в честь казино в Монако; придуман Уламом и фон Нейманом для расчётов в Манхэттенском проекте.

## 2. Генерация случайности и воспроизводимость

```c
// свой seeded LCG: детерминированная последовательность
rng = rng * 1103515245 + 12345;
double u = (double)((rng >> 16) & 0x7FFF) / 32768.0;   // [0,1)
```

Почему не библиотечный `rand()`: его результат **не переносим** — glibc, BSD и macOS дают разные последовательности при одном сиде. Для воспроизводимого теста берём свой LCG (идея та же). В реальном риск-моделировании LCG недостаточно — нужны генераторы вроде Mersenne Twister или PCG.

## 3. Нормальное распределение без `-lm`

Дневную доходность моделируем как N(0, σ). Нормаль получаем по **центральной предельной теореме**: сумма 12 равномерных из [0,1) имеет среднее 6 и дисперсию 1, значит `Σ - 6 ≈ N(0,1)`:

```c
double z = 0; for (int i = 0; i < 12; i++) z += uniform(); z -= 6.0;
```

Просто и без `log`/`cos` (в отличие от Box–Muller, который тянет `-lm`). Для учёбы точности хватает.

## 4. Секвенциально сейчас, параллельно потом

Сценарии **независимы** — идеальная задача для распараллеливания: раздать потокам по куску, каждый со своим сидом, потом объединить. Но потоки — это Season 7. Здесь версия секвенциальная: один цикл, один поток. Это осознанный порядок курса, а не упрощение «по лени»:

- **T1 (план):** параллельный Monte Carlo на `pthread` — Advanced после Season 7.
- **T2 (план):** честное перемешивание Кнута и качественные ГПСЧ — Season 8.

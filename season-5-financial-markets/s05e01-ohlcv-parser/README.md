## Теория: свечи и их разбор

Свеча (bar) агрегирует торговлю за интервал: `Open` (первая сделка), `High/Low` (диапазон), `Close` (последняя, главная для индикаторов), `Volume` (объём).

Разбор строки CSV:

```c
if (sscanf(line, "%ld,%lf,%lf,%lf,%lf,%ld",
           &b.ts,&b.open,&b.high,&b.low,&b.close,&b.volume) == 6) {
    bars[n++] = b;   // 6 полей распознаны -> строка валидна
}
```

Заголовок пропускаем отдельным `fgets`. Хранение в массиве `Bar` — данные лежат подряд, что и делает C быстрым на больших фидах (подробнее — [`theory.md`](theory.md)).

**Аномалия объёма** (> 3× среднего) — грубый, но рабочий маркер манипуляции: pump разгоняет цену вверх, dump обваливает вниз, и то и другое — на всплеске объёма.

## Разбор типичных ошибок

1. **Не пропущен заголовок.** Первая строка — имена колонок; `sscanf` на ней вернёт не 6 (если не пропустить — тихо потеряешь свечу или получишь мусор).
2. **`%d`/`%f` вместо `%ld`/`%lf`.** Для `long` и `double` в `sscanf` нужны `%ld` и `%lf`, иначе UB.
3. **Деление на ноль в проценте.** `(close-open)/open` — если `open == 0` (битые данные), защитись.
4. **Целочисленное среднее объёма.** `total/n` в `long` округлит; для сравнения приводи к `double`.

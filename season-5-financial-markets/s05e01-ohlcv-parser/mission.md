# Mission — s05e01 «OHLCV-парсер»

## Что сдать
`artifacts/parse.c`: читает рыночные CSV-свечи (OHLCV) в структуры, считает сводку и отмечает бары с аномальным объёмом.

## Дано
- `data/prices.csv` — 10 свечей формата `timestamp,open,high,low,close,volume` (со строкой заголовка).
- Аномалия объёма: `volume > 3 * средний`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Строка заголовка пропускается; разбор через `sscanf` с проверкой `== 6`.
- [ ] Свечи хранятся в массиве `Bar`; посчитаны диапазон цен, суммарный и средний объём.
- [ ] Бары с объёмом > 3× среднего помечены с процентным изменением close/open.
- [ ] Вывод совпадает с `tests/expected.txt` (2 аномалии: bar 4 и bar 8); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/parse.c
make test
```

## Оценка времени
~35–40 минут.

## Результат в сюжете
Среди 47 подозрительных тикеров данные наконец читаемы. Два бара выбиваются: резкий скачок вверх (bar 4, +12%) и обвал (bar 8, −15%) на объёме в разы выше нормы. Классический след манипуляции.

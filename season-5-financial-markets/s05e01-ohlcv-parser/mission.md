## Обстановка

Сорок семь тикеров, все связаны с операцией переводами. Сто восемьдесят миллионов строк — глазами не прочитать.

Кто-то очень старался, чтобы это выглядело нормальной торговлей.

## Приказ

Написать `artifacts/parse.c`: разобрать CSV со свечами в массив структур, проверить инвариант цен, посчитать средний объём и найти аномалии.

## Формат данных

```
timestamp,open,high,low,close,volume
2026-01-15T09:30,142.10,143.85,141.90,143.20,1250000
```

Инвариант настоящей свечи:

```
low ≤ open ≤ high      и      low ≤ close ≤ high
```

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Разбор идёт **построчно**; файл не читается в память целиком.
- [ ] Свеча с нарушенным инвариантом **отбрасывается**, а не «исправляется», и попадает в отчёт как битая.
- [ ] Результат преобразования числа проверяется: `atof` на мусоре молча вернёт `0.0`.
- [ ] Базовый объём считается по **спокойному** периоду, а не по всей выборке вместе с аномалиями.
- [ ] Порог аномалии задан явной константой, а не подобран под конкретные данные.
- [ ] Вывод совпадает с `tests/expected.txt`: 20 свечей разобрано, 2 отброшены, 3 аномальных объёма.
- [ ] `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/parse.c
make test
```

Эталон — в `solution/`. Открывай после честной попытки.

## Диагностика

| Симптом | Причина |
|---|---|
| битая свеча прошла проверку | сравниваются не все пары полей инварианта |
| в данных появились нулевые цены | не проверен результат `atof` |
| аномалии не найдены | базовый объём посчитан по всей выборке — всплеск поднял планку |
| найдены лишние аномалии | порог подобран под конкретные данные |
| падение на длинной строке | фиксированный буфер без ограничения длины |

## После выполнения

## Что ты освоишь

- SMA (равные веса) и её лаг; когда окно ещё не набралось.
- EMA как рекуррентное соотношение (`alpha = 2/(period+1)`).
- Crossover быстрой и медленной средней как бычий/медвежий сигнал.

Глубже — в [`theory.md`](theory.md).

## Теория: сгладить и сравнить

```c
// SMA: среднее окна
SMA(i) = (price[i-period+1] + ... + price[i]) / period;   // не определена, пока окно < period

// EMA: рекуррентно, свежее важнее
alpha  = 2.0 / (period + 1);
EMA(i) = alpha * price[i] + (1 - alpha) * EMA(i-1);
```

EMA реагирует быстрее (меньше лаг), но сильнее шумит. **Crossover** — пересечение быстрой SMA и медленной:

```c
if (prev_fast <= prev_slow && fast > slow) /* bullish */;
if (prev_fast >= prev_slow && fast < slow) /* bearish */;
```

Это «golden/death cross» в упрощённом виде. Важно: средние **не предсказывают**, а сглаживают прошлое — на боковике дают ложные сигналы (whipsaw). Подробнее — [`theory.md`](theory.md).

</details>

## Разбор типичных ошибок

1. **SMA до набора окна.** Считать среднее по неполному окну — искажение; верни 0/пропусти, пока `i+1 < period`.
2. **EMA без стартового значения.** `EMA(0)` надо чем-то инициализировать (первая цена или SMA), иначе первые значения врут.
3. **Crossover по одному шагу.** Нужны `prev_fast/prev_slow` — пересечение это смена знака `fast - slow`, а не «fast > slow».
4. **`2/(period+1)` в целых.** `2/(period+1)` в `int` даст 0; пиши `2.0/(period+1)`.

# Mission — s05e03 «Скользящие средние»

## Что сдать
`artifacts/ma.c`: считает SMA и EMA по ряду цен и находит пересечения быстрой и медленной SMA (crossover).

## Дано
- Ряд из 20 цен (рост → шумная полка → разворот).
- SMA period 5, EMA `alpha = 2/(period+1)`, crossover SMA(5) × SMA(10).

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] `sma(price, i, period)` возвращает 0, пока окно не набралось.
- [ ] EMA считается рекуррентно: `ema = alpha*price[i] + (1-alpha)*ema`.
- [ ] Пересечения детектируются по смене знака `fast - slow` между шагами.
- [ ] Вывод совпадает с `tests/expected.txt` (медвежий crossover на i=15); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/ma.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
Под шумом проступает разворот: быстрая средняя уходит под медленную на i=15 — рынок начал падать. На этом строятся сигналы почти любой торговой стратегии организации.

# Теория (углублённо) — s05e03

## 1. SMA — простое скользящее среднее

Среднее последних `period` цен:

```c
SMA(i) = (price[i-period+1] + ... + price[i]) / period;
```

Все значения с равным весом. Плюс — простота и понятность; минусы — «лаг» (реагирует с задержкой на `period/2`) и одинаковая чувствительность к старым и свежим данным. Первые `period-1` точек SMA не определена (окно не набралось).

## 2. EMA — экспоненциальное скользящее среднее

Свежие цены важнее старых; вес убывает экспоненциально:

```c
alpha = 2.0 / (period + 1);
EMA(i) = alpha * price[i] + (1 - alpha) * EMA(i-1);
```

Одно рекуррентное соотношение — не нужно хранить окно. EMA реагирует быстрее SMA (меньше лаг), но и шумит сильнее. Старт обычно берут от первой цены (или от SMA первых `period`).

## 3. Crossover как сигнал

Две средних — «быстрая» (короткий период) и «медленная» (длинный):

- **fast пересекает slow снизу вверх** → бычий сигнал (тренд вверх);
- **сверху вниз** → медвежий сигнал (тренд вниз).

Детектируется по смене знака `fast - slow` между соседними шагами:

```c
if (prev_fast <= prev_slow && fast > slow) /* bullish */;
if (prev_fast >= prev_slow && fast < slow) /* bearish */;
```

Это «golden cross / death cross» в упрощённом виде — основа множества трендследящих стратегий.

## 4. Границы и ловушки

- **Лаг** — сигнал приходит после того, как движение началось; на боковике даёт много ложных пересечений (whipsaw).
- **Подгонка периодов** под историю — прямой путь к overfitting (s05e05).
- Скользящие средние **не предсказывают** — они сглаживают прошлое. Полезны как фильтр шума, а не как оракул.

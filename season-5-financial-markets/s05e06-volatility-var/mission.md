## Обстановка

Фонд утверждает, что в плохой день теряет меньше процента портфеля. Средняя дневная доходность при этом `−0.19%` — число, которое не объясняет ничего.

Интересно не среднее. Интересен разброс и то, насколько плохо бывает в худших случаях.

## Приказ

Написать `artifacts/var.c`: посчитать среднюю доходность, дневную и годовую волатильность и Value at Risk двумя способами для портфеля в 50 миллионов.

## Дано

40 дневных доходностей. Уровень доверия 95%, коэффициент нормального квантиля `z = 1.645`. Торговых дней в году — 252.

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Дисперсия считается с делением на **`n − 1`** — поправка Бесселя.
- [ ] Годовая волатильность — умножение на `sqrt(252)`, а не на `252`.
- [ ] `sqrt` реализован **вручную** методом Ньютона: библиотеки `-lm` в курсе нет.
- [ ] Параметрический VaR считается как `−(mean + z·vol)`.
- [ ] Исторический VaR берёт квантиль **отсортированного** ряда; способ выбора индекса зафиксирован явно.
- [ ] VaR выводится как **положительная** величина убытка.
- [ ] Оба значения печатаются и в процентах, и в долларах.
- [ ] Вещественные — с фиксированной точностью, вывод детерминирован.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

```bash
cp starter.c artifacts/var.c
make test
```

Ожидается: волатильность `1.368%` в день и `21.72%` в год; исторический VaR `2.800%` против параметрического `2.438%`. Эталон — в `solution/`.

## Диагностика

| Симптом | Причина |
|---|---|
| волатильность занижена | деление на `n` вместо `n − 1` |
| годовая волатильность в разы больше ожидаемой | умножение на 252 вместо корня |
| `undefined reference to sqrt` | попытка использовать библиотечный корень |
| исторический VaR совпадает с минимумом ряда | взят не тот индекс квантиля |
| VaR отрицательный | не изменён знак: убыток по соглашению положителен |

## После выполнения

Исторический квантиль окажется хуже параметрического — хвосты тяжелее, чем предполагает нормальная модель. И оба числа окажутся порогом, а не ответом на вопрос «сколько теряется, когда порог пробит».

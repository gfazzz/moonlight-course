# Теория (углублённо) — s05e06

## 1. Волатильность

Волатильность — стандартное отклонение доходностей: насколько сильно цена «дёргается».

```c
mean = Σ ret / N;
var  = Σ (ret - mean)^2 / (N - 1);   // выборочная дисперсия (n-1, поправка Бесселя)
vol  = sqrt(var);                    // дневная волатильность
```

**Годовая:** `vol * sqrt(252)` (252 торговых дня). Множитель — корень, потому что дисперсия складывается линейно по времени, а отклонение — как корень (гипотеза независимых приращений).

Почему делим на `N-1`, а не на `N`: среднее оценено по той же выборке, что «съедает» одну степень свободы; деление на `N-1` даёт несмещённую оценку.

## 2. Value at Risk (VaR)

VaR отвечает на вопрос: «какую потерю мы **не** превысим с заданной вероятностью за горизонт?». 95% VaR за 1 день = «в 95% дней однодневный убыток меньше этого; в остальных 5% — может быть хуже».

## 3. Два способа

**Исторический** — эмпирический перцентиль доходностей:

```c
сортируем доходности; k = 0.05 * N; VaR = -sorted[k];
```

Ничего не предполагает о распределении — берёт реальные хвосты как есть.

**Параметрический** — считаем распределение нормальным:

```c
VaR = -(mean - z * vol),  z(95%) = 1.645;
```

Быстрый, но **занижает** риск, если у доходностей «толстые хвосты» (крупные потери случаются чаще, чем предсказывает нормаль). В задаче исторический VaR ($1.4M) выше параметрического ($1.22M) именно поэтому.

## 4. Ограничения VaR

- **Ничего не говорит о размере потерь за порогом.** «Хуже, чем VaR» может быть катастрофой. Поэтому смотрят и на **Expected Shortfall** (средняя потеря в худших 5%).
- **Хвостовой риск.** Нормальная модель недооценивает редкие обвалы (2008, 2020). Занижение VaR — классический способ спрятать риск в отчётности.
- **Не аддитивен просто.** VaR портфеля ≠ сумма VaR активов (диверсификация; корреляции — s05e07-далее).

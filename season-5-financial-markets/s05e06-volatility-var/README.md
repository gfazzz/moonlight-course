## Теория: измерить риск

```c
mean = Σ ret / N;
var  = Σ (ret - mean)^2 / (N - 1);   // n-1: поправка Бесселя
vol  = sqrt(var);                    // дневная волатильность
vol_annual = vol * sqrt(252);
```

**VaR 95%** — потеря, которую не превысим в 95% дней:

```c
// исторический: 5-й перцентиль реальных доходностей
sort(ret); k = 0.05 * N; VaR_hist = -ret_sorted[k];

// параметрический: нормаль, z = 1.645
VaR_param = -(mean - 1.645 * vol);
```

Параметрический **занижает** риск при толстых хвостах — обвалы случаются чаще, чем предсказывает нормаль. Про Expected Shortfall и почему VaR не аддитивен — [`theory.md`](theory.md).

## Проверка на канале

```
[LUNA] Два вопроса про риск.
```

**1.** LUNA: «Почему годовую волатильность считают как дневную × sqrt(252), а не × 252?»

<details><summary>Ответ</summary>

Складывается линейно по времени **дисперсия**, а волатильность — это её корень. За 252 независимых дня дисперсия × 252, значит отклонение × sqrt(252). Умножать на 252 — грубо завысить риск.
</details>

**2.** LUNA: «Historical VaR получился выше parametric. Кто из них ближе к правде и почему?»

<details><summary>Ответ</summary>

Historical — он берёт реальные хвосты выборки, включая крупные потери. Parametric предполагает нормальное распределение и недооценивает редкие обвалы. При толстых хвостах правдоподобнее исторический (или Expected Shortfall).
</details>

## Разбор типичных ошибок

1. **Деление на `N` вместо `N-1`.** Смещённая оценка дисперсии; для риска берут выборочную (`N-1`).
2. **`× 252` вместо `× sqrt(252)`.** Годовая волатильность — корень из времени, не время.
3. **Линковка `-lm` ради `sqrt`.** Реализуй `sqrt` сам (Newton) — тест собирает без `-lm`.
4. **VaR со знаком.** VaR — это потеря (положительное число). `-(mean - z*vol)`, не наоборот.

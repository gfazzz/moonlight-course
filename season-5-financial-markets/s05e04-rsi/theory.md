# Теория (углублённо) — s05e04

## 1. Что меряет RSI

RSI (Relative Strength Index, Уайлдер, 1978) — осциллятор в диапазоне 0..100, отражающий **соотношение** силы роста и силы падения за период:

```
RS  = средний прирост / среднее падение   (за period)
RSI = 100 - 100 / (1 + RS)
```

Если растёт сильнее, чем падает — RSI → 100; если падает сильнее — RSI → 0. Обычно `period = 14`.

## 2. Инициализация и сглаживание Уайлдера

Первое значение — простое среднее по первым `period` изменениям:

```c
avg_gain = сумма приростов / period;
avg_loss = сумма падений  / period;
```

Далее — сглаживание Уайлдера (родственник EMA):

```c
avg_gain = (avg_gain * (period - 1) + gain_i) / period;
avg_loss = (avg_loss * (period - 1) + loss_i) / period;
```

Важно: `avg_loss == 0` (только рост) даёт деление на ноль — тогда RSI полагают равным 100.

## 3. Зоны и интерпретация

- **RSI > 70** — перекупленность: движение вверх «перегрето», растёт риск отката;
- **RSI < 30** — перепроданность: возможен отскок;
- дивергенция (цена растёт, RSI падает) — ранний признак разворота.

Но: в сильном тренде RSI может «залипнуть» выше 70 надолго, и покупатель, шортящий «перекупленность», разоряется. RSI — не команда «продавай», а мера состояния.

## 4. Осцилляторы vs трендследящие

MA (s05e03) следят за трендом и запаздывают; RSI — осциллятор, ловит экстремумы и развороты. Их часто комбинируют: тренд по MA, вход/выход по RSI. Любой индикатор — это функция от прошлого; на подгонке параметров под историю строится ложная уверенность (overfitting, s05e05).

## Книги под эту серию

- **J. Welles Wilder, «New Concepts in Technical Trading Systems»** — первоисточник RSI.
- **«Technical Analysis of the Financial Markets» (Murphy)** — осцилляторы, дивергенции.
- **Shiller, «Financial Markets» (Yale)** — пределы технического анализа.

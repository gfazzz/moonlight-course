# Mission — s05e04 «RSI»

## Что сдать
`artifacts/rsi.c`: считает RSI (Relative Strength Index) по методу Уайлдера и отмечает зоны перекупленности/перепроданности.

## Дано
- Ряд из 22 цен (сильный рост → обвал), period = 14.
- `RSI = 100 − 100/(1+RS)`, `RS = avg_gain / avg_loss`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Начальные `avg_gain`/`avg_loss` — среднее по первым `PERIOD` изменениям.
- [ ] Сглаживание Уайлдера: `avg = (avg*(PERIOD-1) + текущее) / PERIOD`.
- [ ] `avg_loss == 0` обрабатывается (RSI = 100).
- [ ] Зоны: `>70` OVERBOUGHT, `<30` OVERSOLD, иначе neutral.
- [ ] Вывод совпадает с `tests/expected.txt` (RSI 97.62 на пике); `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/rsi.c
make test
```

## Оценка времени
~40–50 минут.

## Результат в сюжете
На пике RSI = 97.62 — сигнал крайней перекупленности перед обвалом. Индикатор ловит момент, когда «умные деньги» готовятся выйти, а толпа ещё покупает.

## Теория: сила движения

```c
// стартовые средние по первым PERIOD изменениям
avg_gain = сумма приростов / PERIOD;
avg_loss = сумма падений  / PERIOD;

// далее — сглаживание Уайлдера
avg_gain = (avg_gain * (PERIOD - 1) + gain_i) / PERIOD;
avg_loss = (avg_loss * (PERIOD - 1) + loss_i) / PERIOD;

RS  = avg_gain / avg_loss;              // avg_loss == 0 -> RSI = 100
RSI = 100 - 100 / (1 + RS);
```

Зоны: `>70` перекуплен (риск отката), `<30` перепродан (возможен отскок). Но RSI — **мера состояния, а не команда**: в сильном тренде он «залипает» выше 70 надолго, и шорт «перекупленности» разоряет. Подробнее — [`theory.md`](theory.md).

## Разбор типичных ошибок

1. **Деление на ноль.** `avg_loss == 0` не обработан → `inf`/`nan`. Отдельный случай RSI = 100.
2. **Простое среднее вместо Уайлдера.** После инициализации нужно сглаживание `(avg*(n-1)+x)/n`, а не среднее заново.
3. **Знак изменения.** `gain = max(ch, 0)`, `loss = max(-ch, 0)`; перепутаешь — RSI инвертируется.
4. **RSI как оракул.** Экстремум — предупреждение, не приказ. В тренде «перекупленность» живёт долго.

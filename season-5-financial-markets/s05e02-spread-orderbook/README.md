## Что ты освоишь

- Стакан: bid/ask, best bid (максимум) и best ask (минимум).
- Спред, mid-price и перевод в базисные пункты (bps).
- Дисбаланс объёмов как сигнал давления.

Глубже — в [`theory.md`](theory.md).

## Теория: bid, ask, спред

```c
best_bid = max по bids[].price;   // самая высокая цена покупки
best_ask = min по asks[].price;   // самая низкая цена продажи
spread   = best_ask - best_bid;
mid      = (best_bid + best_ask) / 2;
spread_bps = spread / mid * 10000; // 1 bp = 0.01%
```

Спред — стоимость мгновенного входа-выхода (купил по ask, продал по bid — потерял спред). В bps спреды сравнимы между инструментами разной цены.

**Дисбаланс:**

```c
imbalance = (V_bid - V_ask) / (V_bid + V_ask);   // [-1, +1]
```

`> 0` — больше покупателей, давление вверх; `< 0` — вниз. Порог ±0.05 отсекает шум. Про маркетмейкеров и spoofing — [`theory.md`](theory.md).

## Разбор типичных ошибок

1. **best bid как минимум.** Наоборот: bid — максимум (лучшая цена покупки), ask — минимум.
2. **`sscanf("%s")` для side.** `%s` съест и запятую; используй `%7[^,]` (до запятой).
3. **Спред в bps от best_bid.** Нормируй на mid, а не на одну из сторон.
4. **Целочисленное деление в imbalance.** Приводи объёмы к `double`, иначе получишь 0.

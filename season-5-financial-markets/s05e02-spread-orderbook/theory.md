# Теория (углублённо) — s05e02

## 1. Стакан заявок (order book)

Две стороны:

- **bid** — заявки на **покупку**; лучший bid — самая **высокая** цена, по которой кто-то готов купить;
- **ask** (offer) — заявки на **продажу**; лучший ask — самая **низкая** цена продажи.

Стакан обычно отсортирован (bid по убыванию, ask по возрастанию), но полагаться на это нельзя — best bid/ask ищут явно (max по bid, min по ask).

## 2. Спред и mid-price

```
spread = best_ask - best_bid
mid    = (best_bid + best_ask) / 2
```

Спред — стоимость **мгновенного** входа-выхода: купил по ask, тут же продал по bid — потерял спред. Узкий спред = ликвидный рынок; широкий = мало участников или высокий риск.

**Базисные пункты (bps):** `spread / mid * 10000`. 1 bp = 0.01%. Спред в bps сравним между инструментами с разной ценой — 10 bps на акции за $100 и на акции за $10 000 «одинаково узкие».

## 3. Дисбаланс объёмов (order book imbalance)

```
imbalance = (V_bid - V_ask) / (V_bid + V_ask)   // в диапазоне [-1, +1]
```

Больше заявок на покупку → `imbalance > 0` → давление вверх (краткосрочный сигнал роста), и наоборот. Это один из простейших предикторов направления следующей сделки в HFT. Порог (±0.05) отсекает шум.

## 4. Кто зарабатывает на спреде

**Маркетмейкеры** ставят одновременно bid и ask и зарабатывают спред на потоке сделок, принимая риск. Манипулятор может искусственно сдвигать стакан (spoofing — заявки без намерения исполнить), создавая ложный дисбаланс. Резко перекошенный imbalance при странном объёме — повод присмотреться.

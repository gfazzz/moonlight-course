# Mission — s05e02 «Спред и стакан»

## Что сдать
`artifacts/book.c`: читает биржевой стакан, находит лучший bid и ask, вычисляет спред, mid-price и дисбаланс объёмов.

## Дано
- `data/book.csv` — уровни стакана `side,price,size` (side = `bid`/`ask`).
- Спред в базисных пунктах: `spread / mid * 10000`.

## Критерии приёмки
- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] Разбор `sscanf(line, "%7[^,],%lf,%ld", ...)`; уровни разложены по bid/ask.
- [ ] `best_bid` = максимум цен покупки; `best_ask` = минимум цен продажи.
- [ ] Посчитаны spread (в bps), mid-price, дисбаланс объёмов с порогом ±0.05.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Как проверить
```bash
cp starter.c artifacts/book.c
make test
```

## Оценка времени
~35–45 минут.

## Результат в сюжете
Спред узкий (10 bps), стакан почти сбалансирован — на этом тикере манипуляции нет. Но метрика работает: там, где дисбаланс резко перекошен, кто-то давит рынок в одну сторону.

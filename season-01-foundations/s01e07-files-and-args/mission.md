Декодер должен принимать данные снаружи.

## Приказ

Переписать `artifacts/decoder.c`: имя файла берётся из `argv[1]`, содержимое читается через `fopen`/`fread`, расшифровывается XOR-ключом `0x42` и выводится.

## Дано

| Что | Значение |
|---|---|
| файл | `message.enc`, 75 байт, бинарный |
| ключ | `0x42` |
| запуск | `./decoder message.enc` |

## Критерии приёмки

- [ ] Компилируется с `-Wall -Wextra -std=c11` без предупреждений.
- [ ] При `argc < 2` печатает `usage` **в `stderr`** (имя программы берётся из `argv[0]`) и возвращает ненулевой код.
- [ ] Открывает `fopen(argv[1], "rb")` — обязательно с `b`.
- [ ] При `NULL` от `fopen` — `perror` и выход с кодом 1, без обращения к `f`.
- [ ] Обрабатывает ровно `n` байт, где `n` — возврат `fread`, а не размер буфера.
- [ ] Файл закрывается `fclose` на всех путях выхода.
- [ ] Вывод совпадает с `tests/expected.txt`; `make test` → `PASS`.

## Выполнение

cp starter.c artifacts/decoder.c
make test
make run          # запуск вручную: decoder message.enc

# Season 1 — Foundations

**Основы C через одну ночь расследования. 8 серий, ~4.5 часа.**

## О чём сезон

Москва, 23:47. На канал, которым не пользовались два года, приходит зашифрованный файл. Подпись — «V.». Виктор Петров, твой напарник, похоронен два года назад в закрытом гробу.

Ты — **Александр «Морфеус» Соколов**, 34 года, специалист по кибербезопасности. Позывной остался с операции, которую официально не проводили.

За одну ночь — с 23:47 до рассвета — ты пройдёшь от единственного байта до собранного инструмента. По дороге появится некто с подписью `:)`, который знает твой закрытый канал, и обнаружится, что сообщений не одно, а восемь. Последнее из них наберут вручную, пока ты смотришь на экран.

Твой напарник по коду — **LUNA**, ИИ Виктора. В реальности это чат вашего редактора: спрашивайте у неё «почему», а не «сделай за меня».

## Как проходить

```bash
cd s01e01-strange-message
cp starter.c artifacts/bytecheck.c   # в s01e06 и s01e08: cp -r starter/* artifacts/
# ... пишете код в artifacts/ ...
make test                            # зелёный тест = серия пройдена
```

Из корня сезона `make test` прогоняет все восемь. Эталон в `solution/` открывайте только после честной попытки — иначе теряется весь смысл.

> **LUNA работает в режиме `Ask`, а не `Agent`.** В режиме `Agent` ассистент сам правит файлы — тест позеленеет, а вы не напишете ни строки. В `Ask` он объясняет и разбирает, но код пишете вы. Весь курс построен на этом различии.

> **Читайте `README.md`, `mission.md` и `theory.md` в режиме предпросмотра.**
> `Cmd+Shift+V` (macOS) или `Ctrl+Shift+V` — предпросмотр в отдельной вкладке, `Cmd+K V` — сбоку от кода.
> Так корректно рисуются таблицы и работают сворачиваемые ответы в блоке «Проверка на канале»: в сыром тексте они видны сразу, и вопросы теряют смысл.

Всё, что вы пишете, живёт в `artifacts/`. Исходники оттуда отслеживаются git — работайте в своей ветке, и у вас останется история прохождения. Собранные бинарники в репозиторий не попадают.

Нашли ошибку в самом курсе или хотите дополнить теорию? Ветка **от чистого `main`** и pull request: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Season Project: `moonlight_decoder`

Артефакты серий не выбрасываются. К финалу они собираются в один инструмент:

| Из серии | Что даёт проекту |
|---|---|
| s01e06 | модуль `crypto` — XOR и контрольная сумма |
| s01e03 | классификация и валидация записей |
| s01e04 | поиск периода и аномалий |
| s01e07 | чтение данных из файла по аргументу |
| s01e08 | `struct Message`, отчёт, многофайловая сборка |

Собирается в [s01e08](s01e08-assemble-tool/) командой `make`.

**Что уходит дальше.** Модуль этого сезона стабилизирован в [`lib/ml_crypto.h`](lib/ml_crypto.h) и линкуется в проектах следующих сезонов — не пересказом, а настоящей сборкой из нескольких единиц трансляции:

| Проект | Сезон | Использует из S1 |
|---|---|---|
| [`crypto_toolkit`](../season-04-crypto-and-algorithms/project/) | S4 | `ml_xor_crypt`, `ml_checksum` |
| [`stealth_agent`](../season-07-system-programming/project/) | S7 | `ml_xor_crypt` |
| [`moonlight_core`](../season-10-final-mission/project/) | S10 | косвенно, через цепочку модулей |

Проверить, что это не декларация:

```bash
grep -rn "ml_crypto.h" --include=*.c ..
```
